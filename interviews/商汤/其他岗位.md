## 2年硕社招碎碎念

#牛客AI配图神器# 先说下楼主背景，硕2社招，目前某大厂后端在职，后期也做了些AI相关的内容。简历项目是Agent + 后端相关，投递也是这个方向，手撕hot100水平（再难就寄了）。
看了下面试情况姑且从7月初开始正式面，前期一天一面，8月基本一天2面，也面了大大小小的40+场。
总结：
正常交流（项目 + 引申的一些八股 + 手撕）：umu一二面、商汤二面、360二面、快手一面、腾讯高德PDD阿里国际一面，还有一些想不起来了。这些面试基本拿下，因为项目对方会耐心交流，八股也较常规，手撕在hot100之内。
有深度的面试（确实我菜了）：腾讯某部门三面，技术总监压力面，全程质疑项目做的深度，反思其实需要结构化表达，以及很快的把项目的深度表明，总监时间很赶，没有耐心盘完细枝末节的情况，面试官喜欢问亮点和难点（还想吐槽一下就是场景题没有说清楚限制，后来反问的时候说我没考虑，或许站在他们的视角上确实应该天然就是这样的，所以要么就提前多问一下确定题目）。类似的还有快手三面（但是对方给过了应该是缺人把）。阿里控股一面，面试官人也很好，肯定了我做的项目，但是偏后端搜索，分布式问穿了（其实实践中有涉及，差的就是那临门一脚系统的归纳，后面面试官也说再系统补充一下这方面的知识应该很棒了），搜索问了跳表（没说清楚结构），其实这两点讲清楚应该能过，部门还挺核心的。PDD二面（对方应该是leader级别，后端 + Agent都挺了解，引导式逐渐深挖，问到不会为止。最后手撕lc100之外的一个，还好提示下做出来了，祈祷能过）
实际Agent岗、面试内容以后端为主：懂车帝一二面（问后端项目为主，并涉及一些MySQL、Redis八股场景题）、小红书二面（感觉不是leader级别，但是也不关心Agent，上来就问Agent有什么难点，这里确实应该加强一下结构化表达，要学会讲故事，对面后面没兴趣就随便问问结束了），滴滴某一面（这个确实没法就是后端岗，比较关心上亿数据的解决方案，没有涉及过，问穿了）
看不起项目（否定+外行式提问）：某想车企（说你直接用框架就能完成任务，觉得没难度）、一个小厂leader（搞不懂SSE，解释了很多遍无果）、懂车帝二面（说你做这些Agent架构是不是用大而全的模型能直接解决）、某ka（据说是AI驱动HR的科技公司，但是对面质疑项目深度，复盘发现对方全程一问一答问外行内容，厌蠢症犯了靠）。
很奇怪不好分类：高德一面、阿里国际二面都聊得差不多，但是流程一周后结束了。字节面得相对早，面试官主要还是问后端，但是前期表述真的很烂，以致于后续面试官问了个go八股（下去复盘其实我答对了，但是他觉得有问题也没继续讨论了），以致于后续都受影响，最后出了个场景图（要求写设计模式，没get到，第一次发现原来字节不写lc）。后续不出所料寄了，然后简历反复被锁，问了内部人就说在某个流程中，一释放马上又被其他人捞然后锁住（所以到目前就面过那唯一一次，点名表扬一下这个机制，宇宙厂不缺人）。

总结就是现在我的感受就是大厂招Agent，但是还是有很多会问传统后端八股（至少5层吧，也可能因为我项目有后端，但是比校招要深挖，有项目相关经验结合讲很加分），手撕基本大厂一面都有，后续看面试官心情。然后对于一些面试确实越看重发挥会越不稳定（参考腾讯三面，当时想着是临门一脚，结果表述确实紧张了有很多内容其实当场可以说的），需要提前反复练习，然后强化表达。最后就是最近面试转化率好低啊！！！去年和同级别同学交流外面没这么难，AI真的改变了很多！！！

## 商汤二面 8.25

来源：牛客网 ｜ 类型：面经 ｜ 发布：2025-08-25 ｜ [原文链接](https://www.nowcoder.com/feed/main/detail/937372db012044e7ad04572ce8cadc07)

试用了一下 notion 的会议纪要功能，还挺厉害的👍
岗位：ai 云计算大装置

面试概况
自我介绍。面试涵盖了计算机基础知识、项目经验和编码能力，最后讨论了商汤公司的新人培养体系。
计算机基础知识
* 网络层面：详细讨论了从浏览器输入域名到页面响应的整个过程，包括DNS解析、建立TCP连接、HTTP请求等
* NAT（网络地址转换）：将私有内网地址转换为公网地址的机制
* HTTPS安全机制：通过证书和数字签名验证服务端身份
* RPC与HTTP对比：RPC可支持自定义方法名，并且性能优于HTTP
* 操作系统：讨论了程序从磁盘加载到内存成为进程的过程，包括缺页中断、上下文切换等概念
* 数据库隔离级别：MVCC(多版本并发控制)机制解决幻读问题
* CAP理论：分布式系统只能同时满足一致性(C)、可用性(A)、分区容错性(P)中的两项，实际应用中金融系统选择CP，视频服务选择AP
容器与Kubernetes
* 容器概念：通过CNAME、Cgroup等实现资源隔离和限制
* 容器与虚拟机区别：虚拟机可实现CPU架构级别的虚拟化，而容器只能在同架构下运行
* Kubernetes调度机制：详细讨论了Pod从创建到运行的完整过程，包括API Server、Controller、Scheduler等组件的作用
微服务调度项目
* 项目描述：为上千个微服务进行资源调度，目标是使用最少的机器运行所有服务
* 输入输出：输入为服务资源需求(CPU、内存、副本数)，输出为每台机器上运行的微服务列表
* 调度算法：尝试过启发式算法(蒙特卡罗、DRF公平分配)，最终使用整数规划求解
* 资源碎片问题：通过DotProduct方法匹配资源特征相似的服务和机器，减少碎片化
* 迁移限制：由于IP地址写死的问题，微服务无法在运行后迁移
编码能力
* 算法题：实现查找两个字符串的最长公共连续子串
* 解题思路：使用动态规划算法，构建二维DP矩阵来记录两个字符串的匹配情况
* 代码改进：在初始实现后发现问题，通过添加最大长度记录完成了正确解法
公司信息
* 新人培养：主要通过项目实践进行成长，而非系统化的培训体系
* 部门情况：所在部门是AI语音计算团队，规模约20-30人，属于新兴业务
* 市场地位：商汤在AI语音市场排名第三，仅次于”阿里云”和字节跳动的火山
* 技术方向：部门主要负责K8s系统上的Pod级别调度，为用户提供训练和推理任务

## 末流211本小白的计算机实习校招之路

来源：牛客网 ｜ 类型：面经 ｜ 发布：2024-12-07 ｜ [原文链接](https://www.nowcoder.com/discuss/694699318065774592)

鼠鼠的实习求职历程开始于大二下学期，靠着一个黑马程序员上的点评项目和一个学校的项目以及少的可怜的八股储备打算冲一冲互联网，结果可想而知，全军覆没。3月在电信招聘官网上投递了实习并幸运地获得了面试机会，经过了一轮简单的面试，开启了在电信研究院实习的经历。

 电信研究院在我学校附近，走路大概十分钟，那边的实习任务是基于区块链技术的6G网络落地方案研究。由于是研究型项目，没有严格的时间排期，而且那边允许我在学校完成，每周去同步一下进度。因此，我可以在学校上课之余进行实习。虽然感觉这次实习的产出不大，但是让我的简历不那么空洞，并为以后面试互联网公司铺路。

 在中国电信实习了四个多月后，开始针对性地复习面试的手撕算法题和刷题，同时在小林coding和 JavaGuide 上看八股文。大三上学期一直在BOSS直聘等招聘软件投递日常实习，无数次投递都石沉大海。

 一次次点开沟通，一次次没有下文，希望一次次落空。当时不禁怀疑自己能否找到互联网中厂的日常实习。到了十二月上旬，字节飞书给予我了一次面试机会，这也是我的第一次互联网公司面试。字节的面试让我感受到了来自互联网大厂的拷打强度。期望有多大，失望就有多大，二面后过后几天还是挂了。经过这次拷打，我也更加全面地整理实习和项目经历。

 一月也陆续经历了商汤科技，连连支付，字节懂车帝等面试也都挂了。百度幸运地面完三面，并加了面试官的微信，HR也告知了面试通过，当时有种苦尽甘来的感觉，觉得终于获得了大厂的实习。但是过了两个星期，百度流程一拖再拖，最终加了HR面后挂了，心情又跌到了谷底。泡池子横向比较是互联网大厂给我上的第一课，春节前拿到offer的希望已经破裂。

 2024年新年后，我陆续面了momenta, 字节商业化，小红书，美团，滴滴，快手和百度的日常实习。2月底，惊喜地获得了快手电商技术部和百度网盘商业化的日常实习offer，考虑到实习base地，实习待遇和技术栈（百度是golang技术栈）最终选择了接受快手的offer。在杭州的快手实习，成为我一段难忘经历。

 实习期间边实习边投递面试暑期实习，面了腾讯，美团，阿里淘天，阿里国际等公司，实习工作之余还要做无尽的测评和笔试，最终收获了阿里灵犀互娱的暑期实习offer。

 快手的实习是我第一次互联网实习，感谢mentor包容了我的种种失误，也让我学会了互联网大厂的项目开发规范。结识了许多优秀的同事和朋友，他们也给我后面的求职路提供了许多的帮助和指引。

 阿里灵犀互娱实习期间开始了秋招的投递，实习叠加无尽的测评和笔试面试成为了秋招人的至暗时刻。九月初拿到了灵犀互娱的实习转正offer和美团的秋招offer。后续经历了字节，快手面试无限复活无限挂（很遗憾，面的次数最多的公司都没有给offer）和虾皮泡池子。在此期间也面试了中广核和工行软开等国企（工行软开的笔试在十一月中，后面没有参加）。

 十月底到十一月初等开奖的过程是很煎熬的，怕收到的都是白菜价。十一月初时灵犀互娱第一个给我开奖，很可惜开的是白菜价。当时其实是有一点失望的，毕竟被实习过的老东家开了很低的价格。后续我也催美团的HR，看看能不能尽快开奖（当时距离美团开始开奖已经过了三个星期）。不久后，美团给我开了ssp，一个让我非常惊喜的价格，我最终也和美团签了三方。十一月底的时候虾皮也给我开了sp，综合考虑还是拒绝了。

 签约美团后，秋招也尘埃落定。回顾整个校招求职历程，希望和失望并存。对于我们普通人而言，校招的时间线总是拉的很长，只能以「尽人事，听天命」的心态满怀希望地面对每一次挑战。「欲取其中必求其上，欲取其上必求上上」，对于大多数在校的同学们而言特别是计算机相关专业，要有进入大厂的目标和梦想，并为之规划自己的大学生活。

 对于一名25届计算机应届生，一路走过深知校招的艰难。如果有任何问题，或者你想要获取更多的实用干货都可以私信我找我玩耍！一起分享成长进步过程中的经历和体验

 堆、栈:

 栈：自动分配内存空间，系统自动释放,一级缓存，被调用时处于存储空间，调用完释放
堆：动态内存分配，大小不定不会自动释放，存放二级缓存，生命周期由垃圾回收算法决定。

 js中基本数据类型和引用数据类型

 基本类型：存放栈内存，数据大小确定，内存空间可分配
Undefined Null Boolean Number String 按值存放，可以直接访问
引用类型： 存放堆内存，每个空间大小不一样，特定分配
访问引用数据类型（对象、数组、函数），首先从栈中获得该对象的地址指针，再从堆内存中获得所需数据。

 var a = function ( ){}; var b = function ( ){}; a==b 为 false 
 
 变量a实际保存的是指向堆内存对象的一个指针，b保存的另一个对象的指针，虽然两个对象值一样，但是他们是两个独立对象，占两份内存空间

 如果

 var a = {}; var b = a 
 
 它们都指向堆内存中同一个对象；所以 a==b 为 true。

 传值与传址

 var a = [ 1 , 2 , 3 , 4 , 5 ] ; 
var b = a ; 
var c = a[ 0 ] ; 
console.log(b) ; // [1,2,3,4,5] 
console.log(c) ; // 1 
 
b [4] = 6 ; 
 c = 7 ; 
console.log(a [4] ) ; //6 
console.log(a [0] ) ; //1 

 
 b变a变，c变a不变，这就是传值与传址的区别。a是数组属于引用类型，a传给b的是栈中地址不是堆内对象，c仅是a堆内存的一个数值保存在栈中。
b修改时会根据地址取a堆内存修改，c直接在栈中修改。

 对于基本数据类型的拷贝， 并没有 深浅拷贝的区别

 2. 堆和栈的区别

 堆和栈即涉及内存又涉及数据结构层面。

 （1） 在内存层面，分为堆内存和栈内存。

 
 什么时候会用到堆内存，我们在代码上通过malloc或者new开辟堆内存，通过delete或free释放堆内存，是我们手动开辟释放的，否则会出现内存泄漏；栈内存什么时候会用到，就是调用一个函数会用到栈内存，出函数的}栈内存会进行回收，栈内存是系统自动开辟释放的。

 堆内存的大小远远大于栈内存，所以在分配比较大的内存时尽量分配到堆上而不是栈上。

 堆分配是由低地址到高地址；栈分配是由高地址到低地址。

 
 （2）在数据结构中堆（二叉堆、大根堆和小根堆）和栈的区别。

 
 栈是属于一个线性表，堆不是线性的，相当于一个二叉树。

 栈是一个可以满足先进后出，后进先出的线性表，堆常用的就是一个二叉堆，二叉堆在数据结构里经常用的就是大根堆和小根堆，大根堆就是二叉树里所有节点的值最大的值在堆顶（根节点），小根堆就是这个二叉树里所有节点值最小的在堆顶，比如优先级队列（priority_queue）

 
 3. 函数调用参数是怎么传递的？

 实参把值传递给对应的形参
先将参数从右向左压栈，然后将下一行指令的地址压栈，把调用方的ebp压栈，再将ebp指向esp，到时候访问对应的参数是通过ebp指针的偏移。

 4. 为什么函数调用的参数要从右往左压栈？

 C和C++要支持可变参函数，所以要从右向左压栈。为什么可变参函数要从右向左压栈？
eg:

 //可变参函数 
 void func ( int a,...) 
 {

}
 int main () 
 {
 func ( 10 , 20 , 30 );
 func ( 10 , 20 , 30 , 40 , 50 );
}

我们的代码是从上往下依次进行编译的，在编译上面func函数的时候，高级语言代码都要编译成汇编指令，汇编指令进入{：

 
 push ebp

 move ebp,esp

 sub esp,4Ch

 rep stos 0xCCCCCCCC（在vs下才有这个操作，gcc下没有）

 
 在func函数里有参数，要访问里面的参数a，假设压栈顺序是从左向右的，那么先后压入10,20,30，关键是指令的生成是在编译的时候生成的，编译的时候func在取参数的时候该如何取a，栈上的变量都是通过ebp的偏移来取的，func函数在编译的时候根本没有办法访问a，因为你是从左向右压栈的，那么就意味着第一个参数在栈底，后面的参数才在栈顶，将参数压栈后紧接着是下一行指令的地址，接着是func函数的ebp，在编译阶段它是不知道将来用户会传入多少个参数，所以是不知道把ebp偏移多少才能到第一个参数a的，这里是根本没有办法来访问func中所有的参数，因为编译阶段根本不知道将来用户会传入多少个参数。

 所以必须要把左边已知的参数必须放在离ebp最近的地方，也就是反着压栈，依次是30,20,10，这样编译器在编译的时候就会知道 ebp+4 就是 第一个参数的内存 ，接着向下访问就是后面所有可变参的所有参数，以这样的方式就可以给可变参生成指令了，就可以把下面所有参数访问完。

上来两道算法题

 
 
 删除链表的倒数第n个节点
 

 
 xA 表示有 x 位数字出现在秘密数字中，且位置都与秘密数字一致。

 yB 表示有 y 位数字出现在秘密数字中，但位置与秘密数字不一致。

 请注意秘密数字和朋友的猜测数都可能含有重复数字，每位数字只能统计一次。

 示例1:

 输入: secret = "1807", guess = "7810"

 输出: "1A3B"

 解释: 1 公牛和 3 奶牛。公牛是 8，奶牛是 0, 1 和 7。

 示例2:

 输入: secret = "1123", guess = "0111"

 输出: "1A1B"

 解释: 朋友猜测数中的第一个 1 是公牛，第二个或第三个 1 可被视为奶牛。

## 找工作和择业经验分享

来源：牛客网 ｜ 类型：面经 ｜ 发布：2020-08-05 ｜ [原文链接](https://www.nowcoder.com/discuss/353156697801826304)

写这个帖子的主要原因还是在19年春天的时候在牛客网上看了很多别人找工作的经验贴，感觉挺有帮助的，然后把自己找工作和最后工作的选择写一下，供大家参考也作为自己的一个记录。

 
 

 
 
 
 我找工作的时候可以说找了很多类型的工作，从公司的类型来说，包括：
 

 
 
 
 
 
 互联网和人工智能类企业（商汤、海康威视）
 

 
 

 
 
 
 研究所（航天科技、兵器工业、中电28所） 
 

 
 

 
 
 
 外企（AMD） 
 

 
 

 
 
 
 国企（上汽安吉） 
 

 
 

 
 
 
 学校（深圳南科大附中、上海华二）
 

 
 

 
 
 
 事业单位（某新区管委会）
 

 
 

 
 

 
 从岗位上来说主要是软件开发岗、信息科技老师、事业单位人员。上面只说了拿到offer的单位，也有很多投递之后挂了的公司，例如中电14所（简历挂）、大疆（二面挂）、微软（笔试挂）等，但是我主要投递的几个行业里基本上都有公司给了offer。也有很多到后来叫过去二面的公司就没去，比如商汤和海康给了sp后oppo和华为的面试就没去了。
 

 
 

 

 
 最后的选择是去了新区管委会，这个决定可能前前后后拖了有半年。身边很多人听说我会去管委会工作也是挺震惊的，我导师也和我说他觉得我更适合研发类的工作。硕士期间，我大多数时间其实也一直在准备软件开发类的工作，研一研二都利用暑假去相应的公司实习过，《剑指offer》刷了两遍，leetcode周赛最好的时候排过300多名，组成原理、操作系统这些计算机基础书籍和课程也都看过好些。 
 

 
 

 
 

 
 至于为啥一个一直准备的软件开发岗，也拿到了理想offer的人最后为啥没有去，简单说有两个原因吧，第一个是自己在华为实习后身体对这样高强度的加班非常抵制，实习加班一个月身体出现了不适（我是真的按照他们正式员工的作息在实习），而目前行业加班的趋势有越来越卷的趋势，经历了这一次身体不适后我觉得健康对我很重要；第二个是我觉得我在本科和硕士七年里，我太多关注学习和技术了，对自身的其它素质几乎没有关注。所以我希望能换一个环境，体验一下不一样的生活模式。 

 

 
 

 

 
 具体的面试内容我就不详细说了，下面说一些经验性的东西吧。
 

 
 

 

 
 第一个就是 不要怂，就是投！ 不要怂，就是投！ 不要怂，就是投 ！ 找工作最怕的心态就是被挂了几个公司以后就开是否定自己，其实很多时候找工作和抽奖似的，除了少部分简历逆天的大佬，剩下真的就是看概率。比如我有同学实习的时候面华为跪了，优招给了15级；然后说是去年算法岗没顶会论文简历都过不了，我室友什么都没有论文也拿了狗东的SLAM算法岗offer。大家都觉得教师岗一定要教师资格证，但是实际上很多学校对应届生是允许入职一年以内考到就可以的。
 

 
 

 

 
 第二个就比较玄学了，就是 选择一个 适合自己的工作 ，我知道在牛客网上的网友大多数的目标一定是软件类或者算法类，确实可以说这是现在国内最有前途和钱途的工作了，但是我还是希望大家有机会先去这类公司实习一下，实习的时候让自己和正式员工同步一下作息，多和正式员工聊一聊，看看这样的工作强度自己是不是能适应，这个是最重要的。例如我就有同学在菊厂，人家就觉得加班使我快乐 🤣 ，我觉得他在菊厂就很适合这样的氛围。当然，适合自己的工作也不是一步就能找到的，我也有很多师兄师姐在毕业后一年内飞速跳槽的，反正硕士毕业大家也就是二十四五岁的年纪，给自己两年时间调整一下也不是不可以。
 

 
 

 

 
 感谢一些秋招过程中对我有帮助的人，很多牛友都在牛客网上写了很多高质量的帖子，还有商汤、AMD等公司的招聘工作人员们在秋招过程中也对我帮助很大（给他们做个广告，大家可以去试试呀，他们的hr小姐姐解答和处理问题真的很及时的），最后祝大家今年找工作顺利~
