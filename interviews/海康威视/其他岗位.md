五月份填的网申，八月份约了一面，个人简历还是第一版的简历，没有实习经历

 一面-专业面试 

 1.你之前做过开发是吗

 2.你之前有了解过海康威视吗？有了解过安防行业不？就是比如说，有哪些场景或者说设备你有了解过的吗？

 3.你之前做的是开发，那技术支持的岗位。你大概了解是做什么的吗？就咱们面试的这个岗位

 4.就是我其实是担心你对开发的这个事情会不会很有执念？

 5.咱们这边对这个基础这一块的，比如说 06 系统熟悉吗？

 6.数据库的话，咱们有接触过哪一类数据库

 7.咱们就是你是提到的一些数据库，你通常是，比如说我要查询某个表的某个字段，这些东西有接触过吗？

 8.咱们 Postman 主要去拿来做哪一块的应用啊？我看你也有用 Postman 

 9.就是 postman 的一些基础入仓有哪些？

 10.交换机网络这一块有，有学过吗？

 11.简单的这些ping包测试应该有了解过吗？

 12.你上一任实习的过程中有，就是比如说我在项目问题处理的过程中有内部出现过什么，你觉得认为特别困难的事情，或者说有什么冲突的事情吗？然后你是怎么解决的？

 13.你跟项目，比如说项目操作应用过程中，肯定有哪一块的就是基础知识是薄弱的，那针对这一部分薄弱的东西，你是有去怎么学习，或者说怎么去去给它操作起来吗？

------------------------------------------------------------
从年初开始准备，刷题/八股/项目回顾交替，没参加实习，力扣题量200+
8月投递最集中，9月面试最集中，10月开奖最集中
 
 今年应该是目前为止过得最累的一年了，从年初本打算想找个实习充实一下简历，结果被老师项目打乱，被项目折磨了快半年，关键和自己就业方向、研究方向都没关系，没能按计划完成实习科研复习计划，到7月开始梳理漏洞发现很多不足，加上刷题没有连续性形成不了思维惯性，就很焦虑，好在8月开始可以专注于求职了，虽然很累，尤其是看到一起复习的同门早早的收到2个大厂offer，不亚于给我来了两棒子，但庆幸及时做出调整，稳住了节奏，吸收经验，然后反思，边面边改，后面做了能充分展示自己的PPT，最终拿到了几个offer，虽然不是大厂，但平均总包也不低，给了我很大的自信，最高兴的是在10月底收到梦司的offer，宣告秋招正式结束，算是对这快一年努力的最好回馈吧，最后给这一年努力奋斗的自己说一声辛苦了～～

总结几点秋招经验！(嵌入式软件)
1. 尽早刷题：主要应对笔试和部分企业的手撕(如华为，小马智行，CVTE等)
2. 不断完善简历：多去看别人的简历，找优缺点，然后完善自己的简历
3. 尽早投递，把控节奏：参考往年情况，简历均匀投递，大厂分开投递，尽可能控制节奏以避免笔面过度集中
4. 扩充展示面(这里指做PPT)：极少企业会要求，从察觉看较多同学比较抗拒，我最初也是，后来觉得简历文字不足以充分展示自己的优势，便做了成果展示PPT（我的思路是：结合视频+图片讲述技术栈发展过程和相关经历，尽量减少PPT上不必要的文字，简洁明了）
5. 情绪管控(关键)：控制自己的微表情微动作，展现沉稳的自己

希望牛友们都能找到自己满意的工作～ 加油～

 双向绑定是常考题，下面这张图片是官方有过的，每次问到这道题就应该想起这张图片。

 

 
 
 是什么 

 模板层的数据变更会导致视图层的更新。视图层的数据更新也会导致模板层的数据改变

 
 原理 （ViewModel 的原理） 

 
 监听器：对所有的数据进行监听

 解析器：对每个元素节点的指令进行解析

 

 
 双向绑定的原理 

 
 
 vue的数据源会被劫持，在劫持的过程中为属性做依赖收集，vue中的观察者Watcher负责更新视图，依赖收集到的是观察者Watcher的实例对象。当属性值发生变更时会触发依赖，进而触发视图更新函数。

 在数据劫持的同时，vue会编译模板，解析指令，当视图层的数据发生变更时，编译器中绑定的函数会被触发，进而获取到最新的数据值，再次通知Watcher去触发依赖。

 
 加密算法

 项目里的加密算法用的是md5。但是为了安全性应该使用其他加密算法。

 
 
 md5是一个哈希函数，用于将任意长度的输入转换为固定长度的输出，可用于加密。

 
 
 缺点：碰撞攻击：用两个不同的输入值经过md5算法得到相同的散列值

 
 预图攻击：通过已知的散列值，找到对应的原始数据。

 

 
 AES（对称加密算法）

 
 使用它需要引入CryptoJS库，基础加密使用
 const ciphertext = CryptoJS.AES.encrypt(content, key).toString(); content是需要加密的内容，key为密钥。

 

 
 RSA（非对称加密算法）

 
 需要引入jsencrypt库，需要创建jsencrypt实例并且定义公钥和私钥

 用于数据加密和数字签名，密钥太简单安全性不足。

 

 
 HMAC

 
 需要引入crypto模块，用于验证消息的完整性和真实性。

 需要选择合适的哈希函数和密钥，需要填充消息，其实就是确保消息长度达到算法要求。

 计算属性有哪些？区别是什么

 严格来讲只有computed是计算属性，watch是侦听器，methods是用来处理事件。
但是他们都能对数据处理和计算。 

 
 
 computed 

 
 用于创建派生数据，即基于已有的响应式数据进行计算

 会对相关依赖进行缓存，只有在相关依赖发生改变时才会重新计算。

 

 
 watch :

 
 用于监听数据的变化，当监测的数据发生变化时执行指定的回调函数。

 适合用于需要在数据变化时执行一些异步操作、复杂逻辑处理或者非响应式数据的监控。

 

 
 methods :

 
 用于定义可以在 Vue 实例中调用的方法，这些方法可以包含任意的 JavaScript 代码。

 适合用于处理用户交互或者执行一些逻辑操作，方法中的逻辑不会被缓存，每次调用方法都会重新执行其中的逻辑。

 

 
 因此，它们的本质区别在于 computed 用于派生数据的计算，watch 用于监听数据的变化并执行相应操作，methods 用于定义可以在 Vue 实例中调用的方法。

 Promise处理异步？.all方法

 在处理多个异步操作时可能会存在函数里面调用其他函数的嵌套情况，代码量一多就会出现回调地狱。这样代码维护困难，排查错误困难。

 通过 Promise 的 then 方法，你可以按顺序连接多个异步操作，并在每个 then 方法中处理对应操作的结果，而不需要层层嵌套回调函数。

 
 
 all方法 

 他是一种处理异步的操作，是一种静态方法，接收Promise对象组成的数组作为参数，可以将多个Promise包装成一个新的Promise对象，
Promise.all可以并行执行多个异步操作，这是其最大的优势。它不会等待每个Promise依次完成，而是同时开始所有的异步操作。，都成功会返回一个对象，其中有一个失败整个调用都会失败。

 这个我们使用的时候只用安装引入就可以了，可以用它对我们的接口请求进行封装，也可以用于对服务器返回的数据异常捕捉等。功能非常强大。

 
 Axios 是一个流行的基于 Promise 的 HTTP 客户端，可以在浏览器和 Node.js 环境中使用。它可以用于进行 HTTP 请求并处理响应数据，提供了许多功能，比如拦截请求和响应、转换请求和响应数据等。 

 以下是 Axios 的一些主要特点和用法：

 
 
 Promise API：Axios 使用 Promise API 处理异步请求，支持 async/await 语法，使得处理异步操作更加简洁和易读。

 
 浏览器和 Node.js 都可用：Axios 可以在浏览器和 Node.js 环境中使用，这使得它成为编写跨平台应用程序的理想选择。

 
 拦截器：Axios 允许你在请求或响应被 then 或 catch 处理之前拦截它们。这意味着你可以对它们进行修改、日志记录或错误处理等操作。

 
 请求和响应转换：Axios 允许你在请求和响应时对数据进行自定义转换，例如将 JavaScript 对象转换为 JSON 数据或将 JSON 数据转换为 JavaScript 对象。

 
 取消请求：Axios 允许你使用取消令牌来取消请求，这对于需要在用户离开页面时取消请求非常有用。

 
 客户端支持防止 CSRF 攻击：Axios 可以支持在浏览器中防止跨站请求伪造（CSRF）攻击。

## 校招质量岗位详细面经（海康威视）

回顾去年秋招的路程真的是一把心酸泪，最后接了海康供应商质量管理工程师的offer。（以内容为主，格式啥的没有太注意，大家不要介意哈，谢谢。） 

 大背景：本人双非普通一本本科机械狗,不想考研一心工作，本科各方面表现综合来说良好，因为之前有质量工程师的企业实习经验并且工作体验还不错，毕业之后打算从事熟悉的质量行业，所以秋招投的岗位多为与质量有关.且因好友在杭州海康总部，所以铁了心主攻海康的面试，一开始投的是杭州总部质量体系工程师这一岗位，后被调岗为杭州桐庐供应链供应商质量管理工程师。（全程面试以及沟通都是线上进行）。 

 面试流程： 

 1.投递简历：9.8除了投递个人准备好的简历外，还需要去官网上补充详细资料，如果想增大通过面试概率，建议在项目经历，实习经历，竞赛经历这方面写的丰富些，不要懒，避免简历筛选步骤就被pass。 

 2.笔试：9.13笔试内容通过测试链接发过来，网上在线答题，没有专业问题，（是否有专业考试类型的测试，以不同岗位为准）包含几大方向，数学计算题，文章段落大意总结题，几何空间规律题，还有关于个人性格测试题。总体来说有一定难度，每道题都有30－120s的答题时间，我自己是没有准备直接开干，做题的过程中怀疑人生，感觉无了，没想到最后过了。面试结束发现知乎上有人总结了海康笔试链接的题目，童鞋们如果想稳妥一点可以提前去刷刷题，心里有个准备。 

 3.一面专业面：9.28 面试官应该是对应部门的领导，全程聊下来还是蛮轻松快乐的，主要问的都是我的实习工作经历，时长20分钟，把我能记得的问题都写下来吧。 

 （1）举一个之前在公司实习遇到的应用8D流程来解决的实际例子 

 （2）身边的人都是怎么评价你的？ 

 （3）之前在公司，你日常工作的主要内容是什么？ 

 （4）你对海康这个企业的理解怎么样？海康的主要业务？ 

 （5）QC7大手法是否了解吗，实习的时候应用过吗？请描述一下 

 （6）在校科技竞赛中，你在团队扮演什么样的角色，做了什么？ 

 4.二面HR面：10.11 hr面试的问题都是比较简单的，主要看你表达能力以及临时反应吧，面试时长8分钟，以下问题总结 

 （1）为什么来杭州？为什么选择海康？ 

 （2）你觉得相比其他的竞争者，你的优势是什么？ 

 （3）你的期望薪资是多少?为什么提出这个数字？ 

 （4）描述一下你的性格？ 

 （5）目前手上拿了多少offer，是哪几家的？ 

 （6）本科成绩怎么样？ 

 5.三面综合面：10.21面试官气场强大，面试前托同在海康任职的好朋友查了一下，确为总部质量部门的大boss，问的问题非常灵活且详细，而且下一个问题基本是根据她问你的上一个问题的回答来展开深问的，没有固定模板，难度较大。据我了解询问，同批面试的人有被深问实验室经历的，硕士项目，工作经历的，非常详细，一直让展开讲，面试比较专业，有压迫感，但也不是故意为难，只是到了终面想选出最佳候选人，肯定要有些干货。所以大家如果走到这一面，其实已经不错了，要对自己自信，其次的话要对自己简历上的东西要熟悉，问起来要经得起推敲，同时也要对你面试的岗位熟悉，应聘岗位的工作内容，在企业中的角色？以前有没有做过与岗位匹配的工作，怎么运用专业知识解决特定问题，以下是当时提问的一些问题，面试时长28分钟。 

 (1)举出之前你在企业实习时运用质量体系管理解决问题的例子

 C/C++常问问题 

 
 C和C++的区别 

 
 C语言是面向过程的语言，而C++是面向对象的过程。

 C++比C语言的增强点：

 1、命名空间；

 2、实用性加强；

 3、register关键字；

 4、变量检测加强；

 5、struct 加强。

 
 面向对象和面向过程 

 
 面向过程 就是分析解决问题的步骤，然后用函数把这些步骤一步一步的进行实现，在使用的时候进行一一调用就行了，注重的是对于过程的分析。

 面向对象 则是把构成问题的事进行分成各个对象，建立对象的目的也不仅仅是完成这一个个步骤，而是描述各个问题在解决的过程中所发生的行为。

 
 面向对象的三大特征 \

 
 （1） 封装 ：将一类事物的属性和行为抽象为一个类，使属性私有化，行为公开化，提高数据隐蔽性，复用性高

 对于封装来说就是数据与具体操作实现的代码都放在某个对象的内部，使这些代码的具体细节不被外界发现，只留下一些接口供外部来使用，而不能一任何的形式来对象内部的实现。使用封装能够隐藏具体的实现的细节，使代码更加易于维护并且保证了系统的安全性。

 （2） 继承 ：进一步将属性和行为抽象为一个父类，每一个子类拥有父类的行为和属性，也有自己的行为和属性

 继承机制是面向对象程序设计使代码进行复用的最重要的手段，允许在保证类原有类特性的基础上进行扩展来增加功能。这样新产生的类就被称为派生类，继承就可以表现面向对象机制的的层次结构。

 （3） 多态 ：接口复用

 多态简单点说就是“一个接口，多种实现”，就是同一种事物表现出的多种形态。多态在面向对象语言中是指：接口多种的不同实现方式。也就是复用相同接口，实现不同操作。

 
 static与const的区别 

 
 （1）const定义的常量在超出其作用域之后其空间会被释放，而static定义的静态常量在函数执行后不会释放其存储空间

 （2）在C++中，static静态成员变量不能在类的内部初始化。在类的内部只是声明，定义必须在类定义体的外部，通常在类的实现文件中初始化，如：double Account::Rate = 2.25;static关键字只能用于类定义体内部的声明中，定义时不能标示为static

 （3）在C++中，const成员变量也不能在类定义处初始化，只能通过构造函数初始化列表进行，并且必须有 构造函数 

 （4）const数据成员只在某个对象生存期内是常量，而对于整个类而言却是可变的；const数据成员的初始化只能在类的构造函数的初始化列表中进行

 （5）const成员函数主要目的是防止成员函数修改对象的内容。即const成员函数不能修改成员变量的值，但可以访问成员变量。

 static成员函数主要目的是作为类作用域的全局函数。不能访问类的非静态数据成员。

 
 指针和引用的区别 

 
 相同点： 

 1). 都是地址的概念；

 2). 都是“指向”一块内存。指针指向一块内存，它的内容是所指内存的地址；而引用是某块内存的别名；

 3). 引用在内部实现其实是借助指针来实现的，一些场合下引用可以替代指针，比如作为函数形参。

 不同点： 

 （1）指针：一个变量，存储的内容为一个地址；引用：给一个已有对象起的别名

 （2）指针是一个实体，需要分配内存空间；引用知识变量别名，不需要分配内存空间

 （3）可以有多级指针，不能有多级引用

 （4）自增（++）运算结果不一样

 （5）指针是间接访问，引用是直接访问

 （6）“sizeof 引用" = 指向变量的大小 ， "sizeof 指针"= 指针本身的大小

 （7）引用不能为空，指针可以为空

 
 指针与数组的区别 \

 
 （1）数组对应着一块内存，而指针是指向一块内存。数组的地址和空间大小在生命周期不会发生改变，内容可能会发生改变，而指针指向的内存大小可以随时发生改变。当指针指向常量字符串时，它的内容不可以改。

 （2）计算容量的区别：用sizeof计算出数组的元素个数，无法计算指针所指向内存的大小

 （3） 数组名 是常量指针，指针是变量指针

 （4）对数组用&和对指针&的意义不同，此时数组名不在当成指向一个元素的常量指针来使用

 
 C/C++内存有几种类型 

 
 1、 栈 （如局部变量、函数参数）― 由编译器自动分配释放，存放函数的参数值，局部变量的值等。其操作方式类似于数据结构中的栈。

 2、 堆 （malloc）― 一般由程序员分配释放，若程序员不释放，程序结束时可能由OS回收 。

 3、 全局区 （静态区）（static）― 全局变量和静态变量的存储是放在一块的，初始化的全局变量和静态变量在一块区域， 未初始化的全局变量和未初始化的静态变量在相邻的另一块区域。- 程序结束后有系统释放

 4、 常量存储区 ― 常量字符串就是放在这里的。程序结束后由系统释放

 5、 程序代码区 ― 存放函数体的二进制代码。

 
 线程与进程 

 
 1、 线程是进程的一部分，所以线程有的时候被称为是轻权进程或者轻量级进程。

 2、 一个没有线程的进程是可以被看作单线程的，如果一个进程内拥有多个进程，进程的执行过程不是一条线（线程）的，而是多条线（线程）共同完成的。

 3、 系统在运行的时候会为每个进程分配不同的内存区域，但是不会为线程分配内存（线程所使用的资源是它所属的进程的资源），线程组只能共享资源。那就是说，出了CPU之外（线程在运行的时候要占用CPU资源），计算机内部的软硬件资源的分配与线程无关，线程只能共享它所属进程的资源。

 4、 与进程的控制表PCB相似，线程也有自己的控制表TCB，但是TCB中所保存的线程状态比PCB表中少多了。

 5、 进程是系统所有资源分配时候的一个基本单位，拥有一个完整的虚拟空间地址，并不依赖线程而独立存在。

 
 多线程 同步与互斥 

 
 线程同步 是指线程之间所具有的一种制约关系，一个线程的执行依赖另一个线程的消息，当它没有得到另一个线程的消息时应等待，直到消息到达时才被唤醒。

 线程互斥 是指对于共享的进程系统资源，在各单个线程访问时的排它性。当有若干个线程都要使用某一共享资源时，任何时刻最多只允许一个线程去使用，其它要使用该资源的线程必须等待，直到占用资源者释放该资源。线程互斥可以看成是一种特殊的线程同步

 
 静态链表和动态链表 

 
 静态链表和动态链表是 线性表链式存储结构 的两种不同的表示方式。

 1、 静态链表 是用类似于数组方法实现的，是顺序的存储结构，在物理地址上是连续的，而且需要预先分配地址空间大小。所以静态链表的初始长度一般是固定的，在做插入和删除操作时不需要移动元素，仅需修改指针。

 2、 动态链表 是用内存申请函数（malloc/new）动态申请内存的，所以在链表的长度上没有限制。动态链表因为是动态申请内存的，所以每个节点的物理地址不连续，要通过指针来顺序访问。

 
 链表与数组的关系 

 
 数组 存放数据时，必须事先定义数组长度，如果不知道具体长度，只能定义一个足够大的长度

 链表 则没有这种缺点，他能根据需要开辟内存单元

 
 指针数组和数组指针 

 
 指针数组 ：指针数组可以说成是”指针的数组”，首先这个变量是一个数组，其次，”指针”修饰这个数组，意思是说这个数组的所有元素都是指针类型，在32位系统中，指针占四个字节。int *p[n]

 数组指针 ：数组指针可以说成是”数组的指针”，首先这个变量是一个指针，其次，”数组”修饰这个指针，意思是说这个指针存放着一个数组的首地址，或者说这个指针指向一个数组的首地址。int (*p)[n]

 
 函数指针与指针函数 

 
 函数指针 ：与整型指针类似，整型指针为指向整型的指针，函数指针为指向函数的指针，是指针变量，他与函数名无关，只与参数列表和返回类型有关；

 指针函数 ：本质是函数，返回值为一个指针。

 
 内存泄漏和内存溢出 

 
 内存溢出 是指程序在申请内存时，没有足够的内存空间供其使用。原因可能如下：

 （1）内存中加载的数据量过于庞大，如一次从数据库取出过多数据

 （2）代码中存在死循环或循环产生过多重复的对象实体

 （3）递归调用太深，导致 堆栈溢出 等

 （4）内存泄漏最终导致内存溢出

 内存泄漏 是指向系统申请分配内存进行使用（new），但是用完后不归还（delete），导致占用有效内存。常见的几种情况：

 （1）在类的构造函数和 析构函数 中没有匹配的调用new和delete函数

 两种情况下会出现这种内存泄露：一是在堆里创建了对象占用了内存，但是没有显示地释放对象占用的内存；二是在类的构造函数中动态的分配了内存，但是在析构函数中没有释放内存或者没有正确的释放内存

 （2）在释放对象数组时在delete中没有使用方括号

 方括号是告诉编译器这个指针指向的是一个对象数组，同时也告诉编译器正确的对象地址值病调用对象的析构函数，如果没有方括号，那么这个指针就被默认为只指向一个对象，对象数组中的其他对象的析构函数就不会被调用，结果造成了内存泄露。

 （3）没有将基类的析构函数定义为虚函数

 
 new与malloc以及delete与free 

 
 都可以用于申请动态内存和释放内存

 1.malloc与free是C++/C的标准库函数，可以覆盖。

 2.new/delete是C++的运算符,可以重载。

 3.new调用构造函数，delete会调用对象的析构函数,对非内部数据类型的对象来说，malloc/free无法满足动态对象的要求。

 4.new/delete返回的是某种类型的指针，malloc/free返回的是void指针

 5.new建立的是一个对象，malloc分配的是一块内存

 
 delete与delete[] 

 
 1.delete只调用一次析构函数，delete[]会调用每个成员的析构函数。

 2.new与delete、new []与delete[]配套使用

 3.对于内置数据类型，2者无区别。对于复杂的数据类型，delete和delete[]不能互用。

 
 变量的声明和定义 

 
 为变量分配地址和存储空间的称为定义，不分配地址的称为声明。

 一个变量可以在多个地方声明，但是只在一个地方定义。

 加入 extern 修饰的是变量的声明，说明此变量将在文件以外或在文件后面部分定义。

 说明：很多时候一个变量，只是声明不分配内存空间，直到具体使用时才初始化，分配内存空间，如外部变量。

 
 简述strcpy/sprintf/memcpy的区别 

 
 操作对象不同 ，strcpy 的两个操作对象均为 字符串 ，sprintf 的操作源对象可以是多种数据类型，目的操作对象是字符串，memcpy 的两个对象就是两个任意可操作的内存地址，并不限于何种数据类型。

 执行效率不同 ，memcpy 最高，strcpy 次之，sprintf 的效率最低。

 实现功能不同 ，strcpy 主要实现字符串变量间的拷贝，sprintf 主要实现其他数据类型格式到字符串的转化，memcpy 主要是内存块间的拷贝。

 
 深拷贝与浅拷贝 

 
 浅拷贝 ：只是拷贝了基本类型的数据，而引类型数据，复制后也是会发生引用，浅拷贝只是指向被复制的内存地址，如果原来对象呗修改，那么浅拷贝出来的对象也会被修改。

 深拷贝 ：在计算机中开辟一块新内存用于存放复制的对象。因此要用new或者malloc等。

## 海康威视～海外技术销售～校招~面经

来源：牛客网 ｜ 类型：面经 ｜ 发布：2020-03-06 ｜ [原文链接](https://www.nowcoder.com/discuss/353156104777572352)

十月中旬面的海康威视海外技术销售储备生岗位。 

 本来投的面试地点是北京，但是当时有事情，就没有去成北京，想着估计也就这么错过机会了。 

 后来知道杭州还有一场面试，于是就发邮件咨询HR，最后又拿到了远程面试。 

 
 

 远程面试是用的qq，提前安排好的时间。 

 为了保险起见，我用的手机，因为wifi出问题还可以切换到4G。 

 建议正式着装，这样精神很多。而且一定要提前测试房间的光线，因为远程面试，视频质量本来就不高，光线好一些，能提高很多印象分！ 

 
 

 远程面试，只有一场，HR和一个业务主管一起面的。估计线下面试除了群面还有两场。 

 
 

 连线开始，首先是HR问我，问了我最基本的一些情况： 

 介绍一下自己，没有时间限制，我是提前准备的2mins。 学校以及学习的专业。 为什么要投销售岗，而不是研发岗。 家庭情况，家是哪里人。 问我为什么不读研。 其他问题都很简单，提醒一下本科找工作的同学，一定不能说工作两年再读，这样的话公司肯定不会愿意要，我就说家里没钱，所以需要我出来工作了。 

 
 

 HR提问的很短，业务主管是主角。对方应该比较懂技术，在前线也应该做过。 

 
 

 因为我是学通信的，估计和主管学的专业接近。一开始就问我们专业都学什么课程，我大概介绍了我们学习的课程。什么单片机，学过的编程语言，各种网络协议以及不同的通信编码等。估计这个技术销售的岗位需要招理工科背景的同学，所以借此验证了一下。 

 
 

 接下来就很直接地问我还有没有面其他的，我的回答比较老实，就回答也面了华为，也是销售岗位。 

 
 

 然后对方问我更想选择哪里，毕竟是面海康，但也还是没有说华为的坏话，只是陈述了一下华为受到美国制裁的现状，所面临的困境。 

 
 

 因为面试前一个星期，海康也被美国制裁了。所以顺带说了，虽然海康被美国制裁，但是并不伤元气，因为海康有自己的高端摄像模组以及芯片。 

 还陈述了海康与华为的关系，海康在自己的产品中，已经用海思替换掉了很多美国厂的芯片，然后又开始和德州合作建立研发中心，开发自己的芯片。 

 
 

 当时说了很多，都是提前在网上看的，知乎什么的。 

 
 

 因为提到了美国制裁的关系，主管竟然一下子兴奋了起来，告诉我他们内部做了市场分析，美国的影响并没有很大。 

 
 

 我也顺水推舟符合到，阐述了海康海外业务和整体业务的比例，又分析了美国市场占海外的比例，提到美国市场主要是消费者零售业务，整体占比不高，所以影响肯定不会大。 

 
 

 
 

 在此，我建议同学，面这种非研发岗位之前，一定要调查好公司，在知乎上搜一搜，去官网看看企业自己的介绍，以及每年的财务报告。 

 面试官一定想听到你是对这个公司做过充足了解的，而且非研发岗位一定要展现出你的格局来。 

 
 

 主管很满意，又问我这个岗位是要海外出差或者常驻的，问我是否愿意。 

 
 

 我当然愿意了，海康的海外补助是很高的，而且我也愿意趁着年轻到处走走。 

 
 

 刚好话题来了，我就说我更愿意去非洲中东等欠发达地区，又分析了一波中国一带一路对海康海外市场是一个顺风车的机遇。以及中国的一带一路战略投资对国家是多么的重要。 

 
 

 这时候主管问我，如果公司有需求，让你去尼泊尔开发业务，你是否愿意。可能因为我说又明确的目的地，所以主管怕我不服从安排。 

 我回答说，肯定服从安排，市场和公司需要我去哪，我就去哪！ 

 对方似乎很满意。 

 
 

 似乎没什么问题了，因为是海外岗位，主管让我用英语介绍一下自己做过的一个项目。大概三到五分钟的样子。

## 明天双十一***——辛酸的秋招总结

来源：牛客网 ｜ 类型：面经 ｜ 发布：2019-11-10 ｜ [原文链接](https://www.nowcoder.com/discuss/353155885860069376)

1. 写在前面 
 

 
 自己读研之前也没想过以后会从事软件，大学本科期间学过的计算机编程相关课程基本都是 60 飘过，所以对编程没什么兴趣。后面由于各种原因吧，研究生两年基本从零开始走这条路，由于基础太差，时常达不到老板要求，每次被 push 任务进度的时候，总是焦虑失眠。两年下来感觉自己性格都变了，可能只会在熟人面前展现出自己开朗活泼的一面，大多数时间可能都是一个负能量团，所以很多时间状态都很低，对所有事情都提不起兴趣。前面这些其实跟秋招没有太大关系，只是自己由感而发，三个月的秋招终于结束了，希望毕业后可以早点找到，以前那个阳光自信的自己。以下对秋招做一个简单总结，主要谈下三个月自己心态上的一些起伏变化，还有过程中一些自己的理解，希望可以帮到下届的学弟学妹们吧。提前给大家预警下，帖子可能有点长，感兴趣的各位就权当看故事书了吧。 
 

 
 
 

 
 2. 秋招三部曲 
 

 
 忙碌的 8 月 
 

 
 老板那边任务压的紧，给的压力很足，之前其实准备 5 月份开始刷题，准备秋招的，后来自己却不得不面对现实，开始可以腾出手的时候，时间已经来到了 8 月。这个时候其实老板还在压项目任务，看着实验室同届的小伙伴都是早早开始刷题了，我终于按奈不住了，跟老板挑明了，说自己接下来要找工作，项目暂时是做不了的，他倒是也没难为我，因为之前说给我三个月时间找工作，最后也算是信守约定了，还是很感激他的。 
 

 
 就这样自己的秋招开始了，首先从剑指 offer 刷起，之前很天真的认为，只要 C 够熟练，不用 C++ 也能够轻松应付这些，后来做了才发现自己是真的作死，也发现自己数据结构算法知识掌握的很差。所以不得不把刷题的工作暂时放下，在大学生慕课网上找了两个课程学习，一个是数据结构与算法，还要一个程序设计与算法。由于之前用 C++ 不多，本科也没学过，所以 C++ 知识简单了解，大概也就是只能看懂代码的水平吧，在网上买了本《 C++ primer plus 》系统地学习了一下。之后刷题就感觉不一样了，我也不清楚自己的方法是否科学，但是还是想谈下自己对刷题的理解，首先面对一道题的时候，先自己想，觉得差不多可行，就动手敲出来，答案没问题的话，也建议看下答案，对比下答案代码是否更简洁，效率更高，当然如果答案特别难理解，也可以放弃答案思路，毕竟时间很宝贵，在自己都有其他方法解决的情况下，再去抠有点得不偿失。如果自己调不出来，或者根本没思路，建议多看几个参考答案，综合算法的优越性与是否容易理解，选出一个适合自己的答案，这里我不建议直接把答案 copy 一遍，而是理解答案之后，在草稿纸上画下示意图，然后在答题区自己注释里面简单写下解题思路步骤，然后根据思路自己敲，这样的好处有两点：一是对自己思路的一个梳理，理解更深刻；二是方便以后自己回看复盘。 
 

 
 刷完剑指 offer ，时间已经来到了 8 月底，这时候自己才开集中投简历，这一波大概集中投了近 30 份简历吧，卡着最近要进行的笔试，在牛客上找找以前的真题做做。然后开始陆续收到一些笔试通知，本来以为自己准备的挺不错的，没想到实战时候被无情打脸。首先简单说下自己对笔试试题的分析，对于非编程题，主要是选择吧，大多数公司有可能多个岗位共用一套卷子，所以知识面涉及交广，会遇到很多知识盲区，但是自己应该清楚哪些是自己该掌握没有掌握到的，哪些是公司试题不合理的地方，有针对性地总结跟查漏补缺。记得自己做过的卷子有的就离谱，应聘个 C++ 开发，还考 JAVA 和 Python ，也是无语了。至于编程大题，没什么好说的，就是考基本算法与 coding 能力，除了堆时间多刷没什么太好的办法，准备这块也是整个秋招最占时间的，所以要早点准备啦。 
 

 
 灰色的 9 月 
 

 
 从 9 月开始一直到月底，基本处于每天或者隔天就有一场笔试的状态，我的运气比较好，笔试冲突的不多。可是做了一个又一个笔试，一个接一个的挂掉，要不就杳无音信了，所以陷入了一次又一次的自我否定。 9 月 9 号晚上做完欢聚时代的笔试，自己的心态彻底爆炸了，自己前两天才看过的背包问题，最后都没能 AC ，那一刻是自己第一次想放弃了，没刷过的题不会，刷过的稍微变下形式又不会，刷过的原题做起来都会出幺蛾子，真的觉得自己已经无药可救了。那天晚上自己像一个没有思想的躯壳一样，在学校亭子的长椅上躺了许久。那天晚上回去自己睡的特别死，或许是真的累了，或许是真的想放弃了，第二天起的特别晚，手机又没电了。一个转折也从 10 号上午优必选的笔试开始，也是自己收到第一次面试邀请的公司，虽然最后过程又被搞了心态（详细情况可以看我之前的帖子），但是后面可能是心态变好了一点吧，笔试状态也有明显回暖，接着又收到了 CVTE 的面试邀请，跟优必选面试正好冲突，可是当时各种原因，自己很脑残的选择了去中科大面优必选，放弃了 CVTE 的杭州面试机会，其实当时想的是 CVTE 后续应该还有机会安排面试的，自己还是太天真了，对于一面难求的孩子来说，这个抉择仿佛是要从自己身上割掉一块肉，因为最后优必选那边给的体验太差，所以这一点一直让我耿耿于怀，也是让自己对它一生黑的原因。还没从之前的阴影中出来，又让自己漆黑的秋招路笼罩了一层重重的阴霾，心情简直到了谷底。 18 号早上面完优必选，下午就赶车回了杭州，心力憔悴，情绪很低落，身体也有点不舒服，但是好朋友还是拉我去参加了那天晚上学校的军工企业的宣讲会，自己也没抱什么希望的投了两份现场简历，后续都收到了面试通知，面试难度不大，以项目还有基础知识为主，但是也不确定会不会像优必选那样，欢声笑语中打出 GG 。 20 号中兴在学校举办宣讲会，参加宣讲会前 50% 进场可以免笔试，直达面试，因为害怕到时候人多，轮不到自己，所以自己很傻叉的吃过中饭就过去排队了，还把好朋友一块拉上了，现在想想觉得自己好坑，不过幸好周围有坐的地方，不然要哭了。 
 

 
 时间来到 9 月 22 号，这一天是自己最值得铭记的一天，晚上收到了中电 28 所的 offer ，自己人生中的第一个 offer 。清楚记得那天晚上，自己是有多么激动，多么开心，夹杂着各种情绪的泪水夺眶而出，自己迫不及待的把这个消息告诉了家人，告诉了身边的好朋友。在这之后自己心态又一次地发生了变化，因为终于有 offer 可以保底了，毕业即失业的梦魇也好像离自己远去。 23 号自己又迎来了改变自己整个秋招的一天，后面的一切都源于这次面试，这天下午要面试字节跳动，是视频面的形式，这是自己收到的第一次大厂面试邀请，也是第一次以视频的方式进行面试，自己紧张到不行。对于一个菜鸡来说，最后结果可想而知，当然这个结果是自己早就能预见到的，简单来说就是实力差距太大。记得刚开口自我介绍，自己就紧张到说话毫无逻辑，断断续续，介绍完就知道自己大概率凉了。其实自己内心当时就想给自己两巴掌，一个自我介绍都不会说，太不争气了，不过面试官人很好，也很耐心，问的知识面很广，由浅及深，不愧是大厂面试，没有低于自己的预期。虽然第二天就收到了感谢信，但表示体验很好，找到了自己真正的不足，也学到了很多东西，也正是这次面试，后面的几场面试再也没有紧张过，都能很从容的应对。 
 

 
 后续时间就来到了月底，由于学校对军工开放三方较早，所以军工那边开始逼签了，果然捡来的山芋最烫手，自己那几天纠结的要死，有点心神不宁的。因为之前的笔试不管发挥好坏，都没信了，眼看金九就这样过去了，自己还是这么狼狈，其实对我来说也看不到银十的希望，真的是想签了，然后结束这熬人的秋招了，但是就这样结束了，自己又不太甘心。于是那几天，像吃错药了一样，碰见好朋友就想让他们给我出出主意，也在牛客上发了贴，也因此认识了一些人很 nice 的牛油，他们给的意见也都不同，其实自己也都是可以预想到的，自己心里早就有了明显的倾向，无非是想让别人给自己的想法投一票而已，我想大多数人纠结的时候都有类似的经历吧。马上就十一假期了，想回家再跟家人商量下，因为大半年没回家了，也确实累了，想回家调整下，在回去之前，自己又集中投了一波简历，因为好多都笔试完了，也有投了好久没消息的，感觉如果想 10 月再战，余额已然不足，投完自己投递简历数量已经来到 50 左右，自己甚至这是自己最后一波撒网了，所有的希望都在这了，灰色的九月就这么过去了。 
 

 
 金色的 10 月 
 

 
 假期并没有像之前想的那样，继续刷题备战 10 月，在家过的很慵懒惬意，每天醒来只不过是身体从床上挪到了沙发，除了躺着还是躺着。有跟家人商量到底签不签的问题，他们也知道我秋招走的很艰难，说国企挺好的啊，压力还小，不知道是不是不想给我太大压力，而在极力安抚我。之前也有人跟我说，觉得我的性格跟国企还蛮配的哈哈，可能自己真的适合作条混吃等死的咸鱼吧。简单聊了之后，自己也不想过多的想了，就下回了自己卸载了一年多的王者荣耀，这几天没事就跟家人或者朋友开黑，发现自己久别峡谷，操作显得生疏了很多，可是那一刻真的觉得自己回去了，又变成了之前那个没心没肺的铁憨憨，回学校的那天临走时，家人跟我说，想签就签了吧，去哪不是干啊，怕后面没好 offer 了你后悔。我笑了笑回答，不会的，放心吧，我每次都会得到幸运女神的庇护，这次也不例外。 
 

 
 一路上自己想了很多，就想着第一个 offer 能多拖一天是一天吧，自己心心念念的华为一直都没敢笔试，因为太在乎她了，总觉得自己没有准备好，事实也是如此，但是哪有准备好的时候啊，也正是这个原因，才会觉得签了军工，自己会不甘心，因为自己懦弱的都还没朝着她努力呢。节后军工那边又一次催签，自己也是抱着最后的希望尝试再拖一下，自己都没想到竟然拖住了，并且之后再也没催过我，之后自己终于可以放下所有包袱备战十月了，没有任何负担，没有一丝紧张。这是自己心态的有一次变化，这或许才是秋招该有的心态，应有的状态吧。 
 

 
 自己也没想到， 10 月的面试机会似乎比 9 月要好拿，可能是很多大佬选择都已尘埃落定了吧，自己也有了更多的面试机会。这次机会来了，没有给自己太大压力，过多的有针对性的准备太多，就是真的以一颗平常心去对待，经历了这么多，自己真的可以承受任何结果了，也没想到这个月的面试都进行的如此顺利，都走完了最后的流程。时间也来到了这个月下旬了，这段时间主要出于焦急等待结果中，虽然还是稍微有点焦虑的，但是不再像之前吃错药一样了，心想自己再衰也能开个奖吧。最后结果蛮出乎我意料的， 10 月的面试都拿到了 offer ，虽然相比牛客上的很多大佬，自己拿的都是很一般的 offer ，但是对比上个月的情况，自己已经不能再满足了，投了 50 个左右简历，收到 13 个面试邀请，参加了 10 场面试，拿到了 8 个 offer ，现在对此稍作总结，真的很开心这次幸运女神又站到了自己这边。

 3. 写给学弟学妹们 
 

 
 自己秋招一路走来磕磕绊绊，踩过很多坑，也有很多不明智的决定，想在这里简单聊下。 
 

 
 关于投简历 
 

 
 说到投简历，当然首先是简历了，自己的简历一定要写好，不然就可能投了半天，莫名其妙的连笔试都没有，所以如果遇到这个情况，就要考虑是不是自己简历有问题了。网上有很多简历模板，可能也有一些简历制作的教程，我个人其实搞的比较简单了。我想的是简洁美观，重点突出就行。然后其次就是投简历这块了，建议自己早点想清楚想应聘什么岗位，然后就具体了解下，需要的技术栈，就可以早点学起来了。免得像我一样投的岗位乱七八糟，准备的时候也东打一枪西打一枪的，记得为了面字节，自己临时啃了一本视频编解码的书，然而事实证明明没有什么卵用。这样你会很难受，效率也会很低，时间都会白白的浪费。早点能想清楚最好，越具体越好，决定了就不要轻易变了。 
 

 
 关于提前批 
 

 
 我开始准备的比较晚，准备的时候甚至好多公司提前批都已经结束了，虽然当时还有一些提前批的机会，但是觉得自己都没怎么准备，并且提前批强者如林，参加了也没什么希望，只不过是白白浪费时间，还断自己刷题节奏，就完全放弃了提前批。到了后面自己一面难求，四处碰壁的时候，才觉得自己的想法可能过于片面，因为提前批好多都是面笔试的，可以直达面试，其实这个很关键，因为面试这种东西虽然主要还是实力说话，但是比起笔试会有很多偶然因素的，想想看如果提前批有个保底的 offer ，秋招过程该是多么从容啊。退一步讲即便面试不过，又不影响后续正式批投递，一次免死的机会不好吗，从中也可以累计到宝贵的面试经验，这个比各种面经效果要好太多，还有很多东西是面经没办法学到的，只有经历过才能学到，也能锻炼你的心态，我大概就是面了字节之后，才真的学会了面试的吧。当然因为提前批都比较早，一般集中在 6-8 月吧，可能 7,8 月最多，所以这里要敲黑板了，一定要提早准备，尤其对于非科班的童鞋来说，平常写的逻辑代码跟做题考的算法编程差异很大，不靠时间堆是不行的。另外就是如果有时间，能有一段不错的实习经历是很必要的，对比没有实习经历来说优势很明显。 
 

 
 关于刷题和面试 
 

 
 对于一个程序员来说，通用基础就是 C/C++ 、数据结构与算法、 Linux 有关知识，操作系统、网络有关知识，当然对于具体的岗位，还有一些针对性的基础知识需要夯实才行。个人建议先打牢基础再刷题，特别是与编程相关的基础，这样效率才能更高。刷题的话建议先剑指 offer ，这上面的题总体来说不是太难，但是却很典型，也是一些公司常考的面试题目。后面呢就是 LeetCode 了，这个重要性就不用多说了，有很多企业的笔面试题都出自这里，相比前者题库更全，难度也稍大。后面能尽量多刷点题就多刷点，这个是决定你最后拿几个 offer 的关键所在，最起码把热度 TOP 前 100 刷了吧。面试的话首先就是简历上的东西了，上面写的每一个东西，都务必要张口就来，这上面的东西绝对不能有问题。再有就是面试前针对性地搜下相应公司对应岗位面经，做到心中有数，其实后期你面经看多了，基本相同岗位问的很多东西都是重合的，并且你只要基础扎实，是没什么太大问题的，因为里面好多都在前面说的那些基础里面了。可能对于大家来说考验最大的就是手撕代码环节了吧，这个是真正体现编程功底的时候了，除了多练还是多练吧。 
 

 
 关于心态 
 

 
 心情如过山车般起伏不定，用来形容每个人的秋招再合适不过了。原本可能满怀信心，现实接着可能就是几盆冷水扑面而来，在你瑟瑟发抖的时候，可能看到远处仿佛有火苗，走近了一看却又发现只是幻觉，这个时候要自暴自弃，放弃治疗吗，答案肯定是否定的，这个时候如果你选择退出，可能一无所有，秋招只能以惨败收尾，遇到打击伤心难过自闭都是正常的，毕竟大家都是有血有肉的平凡人，这个时候呢，累了就放纵两天，委屈了就好好哭一场，压抑了向好朋友吐槽一下。人生哪有不坎坷啊，关键是怎么调整状态，夹着眼泪向前奔跑啊。如果还苦于没有 offer ，就先小公司，国企或者银行搞一下嘛，特别如果你有学历上的优势，一定不要把这个优势在这个时候浪费掉。什么事情都是从 0 到 1 很难，但是有了之后，随着心态什么的变化，真的就没那么难了。总是就一句话，任何时候都不要放弃，努力了，结果不一定是最好的，但也一定不会差的。 
 

 
 
 

 
 4. 写给各位牛油 
 

 
 秋招结束了，想说的有点多，真的只因经历太多，就说这么多吧，虽然可能没什么人可以耐心看完。但是还是希望能帮助到有需要的人吧，也正好借此记录下自己三个月的秋招生活，这可能真就是自己的最后一帖了，接下来也要赶自己的论文了，在此最后许愿自己顺利毕业！ 
 

 
 感谢牛客给大家提供这么好的交流平台，秋招真的是遇事不决问牛客，期间也得到了很多牛油的帮助，也有幸结识了其中的一些。秋招一路走来，有你们陪伴，真的好幸运，感恩这里的每一个人。可能接下来要暂别牛客了，说真的还是挺不舍的，这里有一群跟自己一样的人，虽然大家来自全国各地，彼此素未蒙面，但是以为共同的目标，相似的经历，都活跃在对方的世界里，一路走来给了我走下去的勇气，谢谢你们。今日一别，不知何时才能在这里重逢，不过相信大家都会越来越好的，希望我们昔日抱首取暖，来日我们华山论剑，祝福各位，我们下一站见！

岗位研究院的算法，一面是八月份的电面，面试官是个学术大牛，也是做强化学习的，问了很多强化学习和论文的细节，和百度的实习，说一个项目中你最优成就感和最失败的点，问了论文接收的情况。二面今天现场面，主要问了论文，问了百度实习，问论文是自己独立完成的吗，我说是啊就我一个人搞，不然老师也不会给一作，问了batchnormalization在训练和测试的时候有什么不同（项目介绍提到过），然后让写了sigmod 及其导数，还有他的值域，这个比较简单，还顺带说了一句，就是他导致的梯度消失。然后问了一个老概率题一根筷子掰两次，组成三角形的概率，这个题我从找实习算起遇到大概四次了。然后又让写了冒泡和快排，问了如何优化，冒泡就是加个计数器，为0就break循环，快排就是随机选取pivot。然后就让hr面，hr还问了项目，包括难点，你怎么解决的，承受压力的情况怎么样，工作地点的倾向，我就说我是南方人，非杭州不去，喜欢南方气候，很喜欢杭州。然后就让出来等通知了。。这岗位竞争太大，一面瞄了一眼旁边简历，清华大学，不出意外我这渣渣学校肯定被淘汰。唉

## 2019校招海康威视技术支持工程师（总部）面试经验

来源：牛客网 ｜ 类型：面经 ｜ 发布：2018-09-15 ｜ [原文链接](https://www.nowcoder.com/discuss/353154556735463424)

一共两轮，技术面和HR面，十分庆幸没有群面，最担心的就是群面，否则自己准备的东西就全部无用了，而且理工科男生，嘴皮子还是稍微欠缺点的。 

 面试前一天的晚上10点多通知我第二天早上去面试，一下子紧张得不行，哈哈哈哈，导致当天晚上3点才睡着。。。。。第二天穿好正装去酒店后等待（我觉得服务类职位还是最好穿个西服，整个人看起来也精神很多！！不过也有一部分技术支持的没有穿，海康好像不是很看重吧，反正记得当时没有穿西服的人最后在签约现场看到他了），有工作人员接待、签到、茶水瓜子伺候，等着叫你就行了。 

 第一轮：技术面（持续时间25分钟） 

 提醒！！！简历上写的东西一定要会，即使不会也应该说个七七八八，不要让面试官感觉你在滥竽充数，我前面那个姑娘写了会TCP/IP等计算机网络知识，结果被逮住一顿问，还有三次四次握手协议，叫她画图。。。。其实她不是很清楚，所以回答的不是很好。下面说我自己的过程： 

 （1）“介绍你做的这个比赛”。其实是小伙伴做的，我只是划水，但是小伙伴给我讲了大概过程和用到的算法，所以我自信而流畅的回答了。“画一下具体的流程图”。。。。。瞎画吧。。。。还好面试官不太懂。 

 （2）关于项目。你的任务，你的职责，组内人数，完成情况。这个时候不要谦虚了，就说你是组内的核心人物，把你的能力描述一下，要让面试官觉得你很优秀！！ 

 （3）你组内的同学有没有闹过矛盾，你怎么解决的？我猜测这个是考察如何维系团队良好运行的一个能力吧。回答问题的时候要注意体现自身的协调组内人员的能力，而且要以团队为重，保证团队的良好运行。 

 （4）你是如何看待技术支持这个工作的？ 

 百度相关内容，很多，结合具体公司业务内容谈谈自己的理解就好，要表现出自己对公司的热爱，对这个工作的热爱。 

 （5）我看你写的熟悉C和C++编程，那你说说二者区别？C++的三大特性吧。 

 虽然问题很简单，但是还是需要意识到，自己简历上的内容要真的会呀！！ 

 （6）你觉得今天面试整个过程，有没有我没有注意到的你的闪光点？ 

 我回答的是我成绩很好，说明我的学习能力和态度认真。这个环节就继续夸夸自己就好了！ 

 （7）四六级成绩具体分数，籍贯。由于我简历上没有写，所以都问了一下。 

 （8）你当时做笔试题的时候，怎么一共登陆了6次？ 

 这个问题大家也要好好注意啊！你从投递简历的那一刻起，所有操作全被后台记录，包括你的笔试分数、做题用时、登陆次数等等，大家不要因为这个被面试官怀疑。 

 面试官会一直在你简历上做一些记录，最后会对你的整个面试过程进行打分。 

 
 

 然后，第一轮面试结束，工作人员把我带了出去。。。。“恭喜你，通过了第一轮！！”哈哈哈哈，自己当时还是很开心的！！！ 

 
 

 第二轮：HR面（25分钟左右） 

 HR面试总体来说，要诚实、好好回答，但是不要太大白话太随性了，HR可谓是看人的老油条了，不要想着耍滑头！ 

 （1）为什么想着做技术支持，而不是研发呢？ 

 （2）用一个词语形容你自己的特质？为什么要用这个词呢？ 

 （3）憧憬一下五年后的你和生活 

 （4）为了达到这个目标，你觉得最大的限制阻力是什么？用一个词语描述。理由是什么？ 

 （5）你怎么看待技术支持这个工作？ 

 （6）形容一下你的家庭？ 

 （7）你可以向我提问三个问题 

 第一问：您怎么看待我今天的表现？答：无法回答 

 第二问：您觉得在海康成长为一个优秀的员工需要哪些特点？ 

 面试官挺有意思，问我难道你就没有想了解海康深层次的内容嘛?哈哈哈哈，所以有了第三问。 

 第三问：您怎么看待加班问题？ 

 
 

 个人感觉HR面的问题是层层深入的，要是有的回答不好，接下来的问题就很难回答。比如一个同学对五年后的憧憬是：吃喝玩乐，有很多钱。。。。。我觉得略微缺乏思考。HR看似在和你聊天，主要是通过你的说话了解你的性格，所以不要张口就来。 

 
 

 面试结束后感觉自己的HR面不是很好，因为自己中途有一些磕磕绊绊，而且最后这三个问题略显幼稚，所以面试结束后觉得自己可能凉了。面试结果是第二天就给，很开心，第三天中午理发的时候接到了短信和邮件，恭喜我成为海康人~~~哈哈哈，非常开心了！！ 

 一个渣渣的面经，希望对大家有一点点帮助吧

## 秋招结束，来波面经！希望可以帮助大家！

来源：牛客网 ｜ 类型：面经 ｜ 发布：2017-10-30 ｜ [原文链接](https://www.nowcoder.com/discuss/353154243278348288)

本人非计算机科班，非985，211普通一本！由于大二对计算机感兴趣，学习java这门语言，感触良多！

秋招可算是结束了，本人目前拿到的offer有51信用卡，海康威视，魅族，去哪儿十一贝，360，最后经过慎重考虑，签约51信用卡！下面是面经！我分享下！

面试一个java工程师必备！

1.集合源码，分析数据结构，可以计算时间复杂度

2.基本的数据结构，比如数组，链表，二叉树，avl树，红黑树

3.基本的算法，比如剑指offer，还有排序，比如快排，基本的算法优化，比如二分查找

4.基本的设计模式，比如单例，观察者，迭代器，适配器

5.反射原理，如何优化分析

6.缓存原理，比如redis，如何解决同步问题，如何解决冲突，如何自己实现lru缓存！最好可以写出代码

7.多线程，要求深入了解，比如lock源码，aqs

8.网络，要求最基本的模型能够说出，分析tcp优点，如何实现长连接。。。。

9.操作系统，大概就是银行家算法，要求能够写出，还有就是死锁，死锁检测，死锁如何避免，还有就是内存分配问题，比如new byte数组最大可以多大

10.数据库，建议了解mysql就可以，还要了解非关系数据库，比如mongdb，学习方向比如数据库如何优化，主从，分库分表，索引原理，b 树要求可以分析。数据库存储引擎，悲观锁，乐观锁，事物隔离级别，从本质去分析，比如数据库执行update操作，都干啥了？

11.负载均衡 nginx，lvs分析，高并发架构，数据容灾分析

12.javaweb要求会spring，mybatis要求可以分析源码！理解

13.rpc如何实现

14.如果会大数据会加分

15.思维能力测试，比如如何设计一个类似于redis的缓存！

16.垃圾回收 jvm 从设计，类加载，垃圾回收算法去考虑。

大概就是这些，希望大家也都能找到心仪的offer！谢谢关注！
