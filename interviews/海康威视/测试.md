## 海康威视-测试开发工程师-面试经验

来源：牛客网 ｜ 类型：面经 ｜ 发布：2023-03-02 ｜ [原文链接](https://www.nowcoder.com/discuss/460749606381502464)

面试场景：一个隔音很好的房间，一张桌子，两个面试官做你对面，你坐在桌子的另一侧，他们每个人拿着你的简历，看着简历一个一个点的问，然后根据你的回答拿笔做记录和标记，时不时扩展问题深度，所以请广大同学们千万不要写虚假的（本人没有）

 1.进行自我介绍！

 简单的说了基本信息，然后往校内活动和实习经历上说

 2.为什么从上一家公司离职？

 讲述了频繁出差。其实有很多，不敢说太多，比如007。（但其实实习公司挺好的，团队氛围非常nice，吃住行全部包，工资应该来说算实习生中顶尖的，转正的话福利超好，工资属于中等。）

 3.算法培训经历中问算法方面有什么会的？认为学到的算法中最好的最优的是哪个？为什么学算法？

 我回答培训是那种学好学费全返的，而我确实做到全返了（这个有同学知道的），主要是跟着船长看网课学典型的常用算法，在大二大三过渡期，算法最实用以及最优的是动态规划、回溯算法，说了两个算法基本原理，dp的重叠子问题和回溯的暴力排序组合之后的剪枝，然后简单的讲了一下递归，分治等。回答因为笔试压轴题需要用到算法，且学其他都快，所以学了算法的培训

 4.问我在上一家公司担任的角色？具体在测试方面做过哪些优化？

 我回答面试的是开发工程师，但实习是测试工程师，毕竟老板不会让实习生负责的，但我经过一个多月的业务了解，可以单独规划和开发业务流程，一直让我介绍那个系统在客户那边的作用（面试官想让我表达清楚，当时没讲清，只说了管控硬件和下层，数据显示等等），优化方面介绍了异常流的处理

 5.遇到bug会如何解决？

 我回答肯定进行初步定位后进行提交，让开发去改，但自己可能也会进行修改（面试官说此岗位不用你改bug，后面才知道测试开发是写测试工具的，比如之前遇到的多线程，读取仪器等等都是自己写一个Demo测试，可惜没说）

 6.看到简历里面会自动化测试，问怎么测试？网络爬虫爬哪些数据？

 我回答用python+selenium，rf，这些都是暑假帮助领导写写脚本，目前在上一家实习单位主要进行异常流测试以及用postman进行接口测试，网络爬虫爬图片、文字、视频，还简单介绍python的scrapy框架，并且说很多企业面试的信息也是用爬虫进行爬的，然后放到excel中统一查看

 7.问大学经历以及学业方面，绩点，竞赛

 我说大一刚上大学，玩心比较大，参加很多社团活动，看望老年人，还有百里毅行（这个其实是大二，嘴瓢），大二开始参加竞赛，跟着学校很厉害的算法老师搞，参加美赛遇到困难，第二年继续搞，参加蓝桥杯等一些比赛，大三大四就开始实习，又回答绩点确实低，但是我是这样回答的：大学综测确实较低，毕竟简历上也没有说获得过奖学金。（这个类似于我年薪不到一个亿）

 8.问我上一家公司的系统怎样和硬件连接的？走哪些协议？TCP吗？用了串口线吗？（面试问题不是笔者这个顺序，且是两个面试官轮流问，所以读者不用觉得突然问校内，又突然问实习）

 这个问的是软硬件方面的，我回答比如扫码枪有手嗯式和机器控制的，手嗯式用串口线连接，走485，机器控制的是分配了ip，发送指令即可，比如/xLOFF/x这些，然后还有一些仪器的指令是16进制的一串，因为和下位机通讯还有硬件方面，这个项目没有和主机其他软件通讯，没走TCP（这个不应该下结论的，因为接触才几个月），和上一层全部交互的主机走HTTP协议，我也一直在做这方面的接口测试。

 9.问还有其他office没？秋招为什么没有？

 我回答上一个星期才离职，投简历，暂无其他office，秋招也去了实习单位等等很多问题

 总结：其实问的非常多，比如学的非常杂，问我之后以哪个为主，也问面试官业务方面，大概就是C++写汽车上面的系统，需要招聘测试开发工程师进行软硬件测试（我半知半决），我也真诚回答C++只会在做算法时用到STL容器里面的结构，因为C刷写的代码太多了，但C++没有两年经验很难去进行开发，其实这一切的前提是实习生转正的希望很小，后面面试官对我说的，说编制没下来，我说这个回答估计所有面试者都会失望的，毕竟来应聘还是非常希望进海康威视的，虽然到毕业时候又得找工作，但成长我个人觉得包括学历、阅历、技术，所以这几个月还是想试试（笔者无奈，但没办法，面试官说大环境不好，我赞同）

 ① 索引怎么建立

 ③ 有哪些索引 

 l 普通索引：创建表的时候直接指定 

 ALTER TABLE tbl_name ADD INDEX index_name (column_list) 

 l 唯一索引：索引的值必须唯一且允许有空值

 l 主键索引：索引值必须唯一且不能为 NULL

 ⑤ 数据结构中常用的算法 

 排序算法 

 l 堆排序（ O(nlogn) ）： 堆排序在满足完全二叉树的同时，父节点都要大于子节点 。堆排序分为大顶堆和小顶堆——大顶堆每个节点的值都大于等于其子节点的值，用于升序排列；小顶堆每个节点的值都小于等于其子节点的值，用于降序排列 

 l 快速排序（ O(nlogn) ）： 首先找到一个数字作为基准数，定义一个左指针和一个右指针，左指针往右遍历，右指针往左遍历，将小于基准数的值放在左边，大于基准数的值放在右边，直到左右指针相遇得到一次以基准数为中心的快排结果；对基准数左边和右边的数值分别进行快排。 

 l 归并排序（ O(nlogn) ） : 将要排序的元素分成两份，用合并排序法对两个序列递归排序，对两个已排序的子序列再排序得到结果 

 l 希尔排序（ O(nlogn) ）： 插入排序的高效版，先将整个待排序的记录序列 分割成为若干子序列分别进行直接插入排序 ，待整个序列中的记录 " 基本有序 " 时，再对全体记录进行依次直接插入排序。 

 l 插入排序（ O(n ² ) ）： 把第一个元素看成是一个有序序列的首位，把第二个元素看成末尾，从头到尾遍历后续数，把他们插入到合适的位置 

 l 冒泡排序（ O(n ² ) ）： 重复的走访过要排序的数列，一次比较两个元素，如果顺序错误就把他们交换过来，知道没有再需要交换为为止。 

 l 选择排序（ O(n ² ) ）： 先找到在排序序列中最小（大）的元素，存放到起始位置，再找第二个，每次都遍历一遍（只适合数据量少的时候） 

 
 

 24、 HTTP和 HTTPS 

 l HTTP 明文传输 ， 数据 都是未加密的，安全性较差； HTTPS 数据传输过程是加密的，安全性好 

 l 使用 https 协议 需要到 CA （ Certificate Authority ，数字证书认证机构）申请证书，一般要 收费 

 l http页面 响应速度 比 https 快，（因为 http 使用 三次握手 建立连接，客户端和服务器需要交换 3 个包； https 除了 TCP 的三个包，还要 加上 SSL 握手 需要的 9 个包，一共是 12 个包） 

 l http和 https 使用完全不同的 连接方式 ， 端口号 也不一样，前者 80 ，后者 443 

 l https是建构在 SSL/TLS 上的 HTTP 协议，所以， https 比 http 更 耗费服务器资源 

 
 

 25、 数据库有哪些范式，三范式是什么？ 

 第一范式、第二范式、第三范式 

 l 一范式：数据库中的所有字段都不可再细分，确保每列保持原子性。 强调的是列的原子性，即数据库表的每一列都是不可分割的原子数据项； 

 l 二范式：有主键，确保表中的每列都和主键相关。 而不能只与主键的某一部分相关（主要针对联合主键（外键）而言）。也就是说在一个数据库表中，一个表中只能保存一种数据，不可以把多种数据保存在同一张数据库表中。 

 l 三范式：确保每列都和主键列直接相关， 不能间接相关。比如在设计一个订单数据表的时候，可以将客户编号作为一个外键和订单表建立相应的关系。而不可以在订单表中添加关于客户其它信息（比如姓名、所属公司等）的字段。

## 2022海康威视秋招：笔试/专业面试经验

来源：牛客网 ｜ 类型：面经 ｜ 发布：2021-10-29 ｜ [原文链接](https://www.nowcoder.com/discuss/353158838008356864)

我投的海康威视的测试工程师。海康威视的回复速度特别快，我是10.26号在官网上投的简历，然后10.27收到了认知测试的链接，10.28号收到了笔试的链接，10.29号就参加了第一场专业面试。 

 在线测评（认知测试） 

 在线测试不用开摄像头，但是过程中不能跳出当前页面，否则取消成绩。这一测评分为四个部分。第一部分是阅读理解，会给你一段中文，然后让你找出对于这段话的正确/错误选项。第二部分是图表计算题，看图表找出信息，然后计算（比如占比多少，比上个月增加了多少之类的）。第三部分是图形题，有点像行测里面出现的，根据前几个图片，找出接下来的这个图形长什么样。最后一部分是性格测试，这个就按自己选就行。这四个部分每一道都只有1分钟左右的选择时间，特别快，我建议一上来就先随便选择一个选项，然后再看题。否则你可能在不知不觉中错过时间都没来得及选择选项。 

 笔试 

 笔试也是分为四个部分。第一部分单选题，第二部分多选题，都是问一些测试相关的问题。具体可以在【牛客网 - 题库 - 专项练习 - 软件工程 - 软件测试】 里面练习。第三部分是让你叙述如何测试学校里使用的饭卡（充值，消费功能，仅用于食堂）。第四部分编程题，给你输入10条学生的学号和成绩，然后让你根据成绩从大到小输出学生的学号和成绩。很奇怪的是第四部分不是在编程环境下写的，就是一个类似笔记本txt的环境，硬写编程。 

 专业面试 

 问了好多问题，我感觉我都没怎么答上来。但是面试官很和蔼，不会的问题他都能解答。 

 （关于软件测试的问题） 

 做软件测试你的优势在哪方面？（因为我简历上项目没有关于软件测试的） 

 软件的质量要从哪些方面去考虑？ 

 软件在转测试之前有哪些方面/活动可以去提高它的质量？（做一些评审活动） 

 测试用例的设计方法你有了解过吗 

 白盒测试里面你需要考虑哪些呢 

 黑盒测试里面的测试用例的设计方法的概念有了解吗 （边界值、等价位） 

 说一下集成测试和系统测试的区别，最大的区别是什么，这两个测试分别是由什么样的人去负责 

 你了解测试用例应该包含什么样的元素吗 

 你了解过单元测试吗，你知道怎么开展吗（由开发人员去做） 

 你觉得开发人员的测试和专门的软件测试，这两者在考虑范围上有什么不一样？ 

 你清楚有哪几个测试阶段吗？过程是怎么样的？大致的工作流程 

 给你一个软件/网站，你觉得要怎么开展测试（开发有哪些资料给到，开始测试之前需要了解什么：系统/需求，再规划要去测试哪些方面，怎么去做，怎么执行） 

 软件缺陷（bug）包含哪些东西？发现bug后你要记录下哪些东西？如果你知道是哪个函数报错，你应该去看什么东西？怎么看/看哪些地方 

 （关于Python的问题） 

 python2和3有什么区别？（比如列表和元组） 

 字典是有序的还是无序的？（无序的） 

 你用的比较多的内置模块/内置函数是什么 

 正则匹配、字符串匹配查找，要用什么函数/操作

## 海康威视测试一面（钉钉面）面经 2020.9.16

来源：牛客网 ｜ 类型：面经 ｜ 发布：2020-09-16 ｜ [原文链接](https://www.nowcoder.com/discuss/353156988806832128)

全程25min，没有问技术问题，全程都是围绕测试的思维、测试的基础理论和简历中的项目展开的。 

 
 

 0. 自我介绍 

 1. 因为我不是科班，所以问了一下测试的知识是如何学习的？有没有系统学过？面试官希望看过相关的专业书籍，有系统学习过测试的经历。我说自己是通过博客和视频学习的，不是面试官想要的答案。 

 2. 你认为测试流程中最关键的环节是什么？ 

 3. 测试用例里面包括哪些部分？ 

 4. 如何提升测试工作的效率？面试中几次谈到测试效率，面试官好像很看重提高效率。 

 5. 因为我在简历中写了一个自动化测试的项目，所以问了一下在设计测试用例的过程中用过哪些方法？自己印象最深刻或觉得设计最巧妙的用例是什么？测试中有没有发现缺陷？ 

 6. 再有就是关于项目的问题，这些问题不涉及技术，更像hr面。为什么找测试工作？什么时候开始准备找测试工作的？举例说明项目中最有挑战的地方。项目中最难的地方是什么？ 

 7. 最后，时间比较紧就反问了一个问题。 

 
 

 因为大多是开放性的问题，整个流程走下来心里仍然是没底。

## 海康威视 测试工程师面经（菜鸟的面经）

来源：牛客网 ｜ 类型：面经 ｜ 发布：2019-10-17 ｜ [原文链接](https://www.nowcoder.com/discuss/353155746651119616)

长沙站，楼主双非一本
 9.6 网申海康，然后当天收到了测评
 9.12 收到海康测试工程师在线笔试邮件
 9.14 进行在线笔试，忘记内容了，印象比较简单，很多基础的测试问题
 9.21 收到面试通知
 9.24 在酒店进行了技术面+HR面，技术面过了等了二十分钟就安排HR面。面试氛围不错，没有cvte的赶集的感觉
 
 😅😅
 技术面是一个很温和的大叔，问的问题也没有刁难人，不会笑里藏刀（面试cvte的阴影）。大部分问题照着简历上的项目一一地展开。
 技术面大概的内容:
 ①做了那么多项目都使用了嘛？没有交付使用？为什么？（我简历上的项目都是课程期末作业）
 
 😅
 ②还使用了sqlite?sqlite的优点?
 ③解释一下MVC
 ④为什么使用oracle？为什么使用项目中的模拟器
 ⑤哪些是合作完成的，在合作的项目中负责什么内容，具有什么优势
 ⑥怎么学习测试的
 ⑦测试QQ邮箱的登录，说出大概的步骤
 ⑧在Linux和Windows下接口测试怎么选择测试用例
 ⑨Java中class文件的生成？
 ⑩还有一些问题忘了，反正我答的很水，最后问了我有什么问题想问的
 最后让我去外面等一下（意思是面试过了）
 
 等了二十分钟左右就开始HR面，HR小姐姐很干练，以下是面试内容:
 ①自我介绍，我没有说完就打断我问问题了
 ②你用Java写的项目挺多的啊，怎么不走开发
 ③最近在学什么语言吗
 ④为什么做测试，为什么不考研
 ⑤最难忘的一段经历（我说了我的项目，然后HR就紧接着我的项目问下去）
 ⑥项目成果如何?觉得项目还有什么待完善的吗
 ⑦收到了offer了嘛？投的其他公司的岗位都是测试岗吗
 ⑧未来规划
 ⑨有没有男朋友?在哪工作?
 ⑩期望的薪酬与工作地点
 最后还问了奖学金的情况，问我有什么问题想问的，HR小姐姐说两周内出结果，结果第三天就收到了签约邮件，整体面下来感觉不错，有希望拿offer，果然面试结果还是能预感到的，其实技术面过了还蛮出乎意料的，聊了很多项目内容，项目我做得很简单，很惭愧。
 
 9.28 参加了签约答疑会，当场逼签了两方
