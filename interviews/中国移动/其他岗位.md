## 中国移动物联网 校园招聘面试全记录

来源：掘金 ｜ 类型：面经 ｜ 发布：2025-02-23 ｜ [原文链接](https://juejin.cn/post/7474219832273207330)

本文介绍 2024届春招 中， 中移物联网有限公司 的 软件研发类 岗位 2 场面试的具体流程、提问问题等。

    2024 年 04 月投递了 中移物联网有限公司 的 软件研发类 岗位，暂不清楚所在部门。目前完成了笔试、一面、二面，并有幸获得 Offer ；在这里记录一下面试的相关经历。

   首先，简单谈一谈笔试。中移物联网是和中国移动其他单位或部门一起统一笔试的，这个和我们之前分享的 # 中国联通软件研究院：校园招聘面试记录 还不太一样，当时的 中国联通软件研究院 是其单独笔试的，没有和整个中国联通一起组织笔试。秋招的时候我没有报中国移动，不知道笔试是线上还是线下，但是春招的笔试则是线上，而且不需要双机位（很多单位，尤其是事业单位，总喜欢搞需要双机位的考试，太麻烦了，还好我不想去事业单位），所以相对更为方便。不得不说中国移动笔试的题量是真的大，笔试结束后很多同学都说没有做完——尤其是那个心理测试，最后的七、八十道题很多同学最后都来不及仔细看，只能随便瞎选。所以这样的笔试，也包银行的笔试（银行的笔试经历我们后面也会再分享），一定需要控制好时间，遇到不会的题目就蒙一个答案然后跳过，后面有时间的话再回过头来看看。此外，中国移动的笔试会有很多类似于脑筋急转弯的开放题，比如这次的大胃王吃了几碗米饭的问题，实在是让大家百思不得其解哈哈哈；遇到这种题目，就按照自己的理解选择就好，说不定连官方都没有一个准确的唯一答案呢。

   关于面试，这 2 场面试均为线上视频面试。其中，每 1 次面试都非常迅速， 15 分钟内就结束；但可能是由于面试的人比较多，导致公司预估的面试时间不太准确，每次都是进入会议室后等待了很久才开始面试的。其中，每 1 次面试都需要对着摄像头展示自己的身份证——我在第 1 次面试时忘记拿身份证了，所以用了手机上的身份证照片；第 1 次面试时，还需要对着摄像头转一圈，应该是来检查面试人是否有夹带小抄的现象哈哈哈哈（虽然我感觉面试应该也不会有人用这种方式作弊）。

   这 2 场面试都是一对多，即 1 位面试人对应着多位面试官。面试官都非常和蔼，其虽然人数比较多，但是每 1 位面试官提问的问题并不是很多，大概都只是 1 至 3 个问题（所以每 1 次面试都会进行得很快）。从我个人角度而言，感觉面试官没有问得很深入，也没有专门对算法、计算机八股知识开展提问，更多还是对个人实习、项目经历的提问；此外，还会结合物联网公司的一些实际情况来提问。这个前面我们也分析多次了——对于国企、事业单位等的计算机开发岗位而言，确实不会提问过多科班的专业内容，更多还是对个人综合能力的考量。不过，在网上有很多朋友也提到，这 1 次该单位的春招面试时，还是提问了一些专业、比较困难的算法或计算机知识的——这个可能和个人专业方向也有关系，毕竟我不是科班，可能面试官也就不想再提问专业问题了。

   此外，我面试的这个岗位有很多城市所在地，一面的时候面试官也会问有没有自己更有意向的城市。当时面试官关于这个问题问了 2 次——第 1 次时，面试官列举了很多个城市，问我对其是否有倾向，我说都可以；第 2 次，也就是面试结束时，面试官则是具体问了 重庆 和 深圳 这两个城市我更偏向于哪一个，我则回答了 深圳 。最后，下发的 Offer 确实也将我分配到深圳去了。其实对于这家单位，我感觉更适合所在城市的本地人：福利据说不错，工作整体强度也还好（当然也要看部门据说），所以对于本地那些住房压力不是很大的同学而言，就是一个很香的选择了——尤其是其位于重庆的部门，吃饭免费，工作强度还行，待遇在当地也还可以，所以就相对适合重庆、四川等地的同学去；而对于外地的同学而言，那就最好再综合考量、权衡一下了。

 1 一面

 面试情况 

 
 
 下午 16:20 开始，持续 15 分钟左右。

 
 线上面试， 3 位面试官，为部门领导或员工；面试官很和蔼。

 
 首先做自我介绍；随后提问 15 分钟。

 
 提问问题 

 
 对于岗位所在的几个城市有何倾向？

 研究生期间主要是做什么的？毕业论文的内容是什么方向的？

 毕业论文中，遥感数据重建是如何实现的？都用到了哪些算法或模型？

 分类与回归有什么区别？对于数值型变量，如何在模型中对其值加以预测？

 你所处理的数据都有哪些维度？数据是如何组成的？

 对于数据库的了解如何？都参与过哪些和数据库有关的项目？

 多维度数据都有哪些分析方法？

 假设目前有一个物联网的湿度计数据，你认为可以如何获取、组织、分析、预测数据？

 是否经常接触数据处理、数值分析？都有哪些相关的项目、实习经历？

 还接触过哪些机器学习、深度学习算法？接触过哪些空间分析算法？

 个人技术栈如何？用过哪些代码做过哪些项目？

 如何解决过拟合问题？

 对于重庆和深证这两个城市，你更倾向于哪一个？

 
 算法题目 

 
 无。

 
 面试结束反问 

 
 无。

 
 反馈情况 

 
 3 天后，收到二面通知短信。

 
 2 二面

 面试情况 

 
 
 下午 14:20 开始，持续 10 分钟左右。

 
 线上面试， 4 位面试官，为部门领导或员工；面试官很和蔼。

 
 首先做自我介绍；随后提问 10 分钟。

 
 提问问题 

 
 平常都用哪些代码语言？个人技术栈如何？

 用 C++ 的场景主要有哪些？用 Python 的场景主要有哪些？

 是否用过 MATLAB ，主要用来做什么？

 在滴滴实习中，主要做了什么工作？主要应用什么代码语言？

 在导航实习中，主要做了什么工作？通过什么实现的多线程？线程之间是如何通信的？进程、线程通信方式有哪些？

 毕业论文具体是做什么的？其中神经网络模型是如何训练的？如何将 Python 训练好的神经网络模型运用至 C++ 代码？

 准确率与召回率有什么区别？

 如何看待创新的意义？在你的学习或项目经历中，有哪些创新的实践？

 
 算法题目 

 
 无。

 
 面试结束反问 

 
 岗位主要的工作方向，是偏向于嵌入式开发，还是传统的后端、软件研发？

 
 反馈情况 

 
 1 周后，收到预录用邮件。

## 25届中国移动一面（15min）

来源：牛客网 ｜ 类型：面经 ｜ 发布：2024-04-09 ｜ [原文链接](https://www.nowcoder.com/discuss/607350658445897728)

#软件开发2024笔面经# 鼠鼠抱着试一试心态投的，过了简历初筛收到笔试通知，做完笔试收到面试通知就参加了，面试才知道只招应届生（主要是云计算方向的，我是投Java的），面试官人很好，把面试流程过完了（涨经验了）。

 1.自我介绍

 老生常谈的自己的技术栈优势等，然后是项目介绍相关的。

 2.主键索引和唯一索引的区别

 主键索引 ：

 定义与用途：主键索引用于唯一标识表中的每一行数据，确保数据的完整性和准确性。

 强制性与非空约束：主键索引具有强制性，一个表只能有一个主键。主键字段的值必须是唯一的，且不允许为空。

 产生聚集索引：主键索引总是产生唯一的聚集索引。聚集索引决定了表中数据的物理存储顺序，按照主键字段的值进行排序。

 外键关联：主键常用于与其他表建立外键关联，以维护表之间的引用完整性。

 性能考虑：由于主键索引是聚集索引，它通常能够提供更高效的范围查询和排序操作，因为数据本身就是按照索引顺序存储的。

 唯一索引 ：

 定义与用途：唯一索引也用于确保索引列的值组合在表中是唯一的，但它不像主键那样具有强制性。

 强制性与非空约束：唯一索引不具有强制性，一个表可以有多个唯一索引。唯一索引的字段允许有空值。

 产生非聚集索引：默认情况下，唯一索引产生唯一非聚集索引。非聚集索引与数据分开存储，包含一个指向数据行的指针。但如果表已经存在聚集索引，也可以选择创建唯一聚集索引。

 外键关联：唯一索引不常用于外键关联，因为主键更适合用于这种场景。

 性能考虑：唯一非聚集索引主要用于快速定位到具有唯一值的行，但对于范围查询和排序操作可能不如聚集索引高效，因为数据不是按照索引顺序存储的。

 3.线程的状态

 编辑

 新建(New)

 创建后尚未启动。

 # 可运行(Runnable)

 可能正在运行，也可能正在等待 CPU 时间片。

 包含了操作系统线程状态中的 Running 和 Ready。

 # 阻塞(Blocking)

 等待获取一个排它锁，如果其线程释放了锁就会结束此状态。

 # 无限期等待(Waiting)

 等待其它线程显式地唤醒，否则不会被分配 CPU 时间片。

 没有设置 Timeout 参数的 Object.wait() 方法

 Object.notify() / Object.notifyAll()

 没有设置 Timeout 参数的 Thread.join() 方法

 被调用的线程执行完毕

 LockSupport.park() 方法

 # 限期等待(Timed Waiting)

 无需等待其它线程显式地唤醒，在一定时间之后会被系统自动唤醒。

 调用 Thread.sleep() 方法使线程进入限期等待状态时，常常用“使一个线程睡眠”进行描述。

 调用 Object.wait() 方法使线程进入限期等待或者无限期等待时，常常用“挂起一个线程”进行描述。

 睡眠和挂起是用来描述行为，而阻塞和等待用来描述状态。

 阻塞和等待的区别在于，阻塞是被动的，它是在等待获取一个排它锁。而等待是主动的，通过调用 Thread.sleep() 和 Object.wait() 等方法进入。

 4.start（）和run（）的区别

 start 方法：这是 Thread 类的一个方法，用于启动线程。当你调用一个线程的 start 方法时，它会创建一个新的线程，并在新的线程中调用该线程的 run 方法，这意味着 start 方法负责线程的启动和调度。

 run 方法：这是 Runnable 接口中的一个方法，或者可以直接在继承自 Thread 的类中被重写。它定义了线程应该执行的具体任务或操作。当线程启动后，它会自动调用 run 方法来执行其中的代码。

 总结来说， start 方法用于启动线程，并在新的线程中执行 run 方法的内容；而 run 方法则定义了线程应该执行的具体任务。

## 国企面试记录

来源：牛客网 ｜ 类型：面经 ｜ 发布：2022-08-12 ｜ [原文链接](https://www.nowcoder.com/discuss/387572018533724160)

记录一下我面过的国企和银行 

 中国商飞 

 投递简历以后，一天内就会收到邮件回复，要求做一个IQT智力测评+AI面。 

 IQT智力测评：图像题和数字题，难度不高，大部分都是小学初中数学题难度。 

 AI面：五个问题，每个问题五分钟。 

 1.回忆一次用不熟悉的技能或者知识解决问题，你是如何让这些知识有效应用。 

 2. 回忆一次你的团队在合作中陷入僵局. 

 3.回忆一次你是如何完成一次紧急且急切的任务的。 

 4. 回忆一次你压力很大的经历。 

 5.回忆一次你与他人合作难以达成一致的时候。 

 
 

 在测评之前我查过面经，牛客有一个朋友提到了AI面的题目内容（ 链接在此 ），但我没想到商飞的题目是完全不换的，所以我也没有按照那个朋友给的面经去准备，而是去网络上查看了AI面试注意事项就去面试了。 

 其实可以做得更好的，所以有点可惜。 

 
 

 做完测评以后就没有回应了，我大胆猜测这个测评只是走流程，后续的面试才是真的有影响的。 

 
 

 南方电网：计算机岗 

 这个公司是面试体验感蛮好的一个，我详细说说。 

 招聘的时候，南方电网的官网很清楚写了广告和招聘的各种注意事项，流程也写了——几号会笔试，一周前会发通知等。 

 公告写得很清晰，并且通知也很到位，邮箱+短信。 

 
 

 我参加了机试，计算机岗位的机试内容：30分行测+70分专业知识。 

 专业知识考得很广泛，数据结构、操作系统、计算机网络、计算机组成原理、计算机网络安全和密码学。 

 但是难度都还好。 

 
 

 机试用的APP是易考，需要双机位考试，朋友们非常建议你们买个手机支架。 

 因为监考老师很严格，一定要拍到你两只手。所以手机要放得高高的。 

 
 

 南方电网面试流程：机试+面试。 

 
 

 
 

 华润万家 

 投递简历以后五分钟就收到了邮件，邀请做测评。 

 太久了，我查看了影响测评链接，推测应该是心理测评（反正不难），时间是37mins。 

 
 

 中国移动： 

 我投递了三个岗位，面试官也没说我是哪个岗位。然后跟我一起面试的人也是不知道自己是啥岗位。（可能三个岗位都是一起面试然后随机分配吧，我也不懂） 

 
 

 面试体验不太好的一家。 

 机试：行测+企业文化+游戏。 

 行测的内容跟银行的机试差不多，都是考语文的选词题、语义分析题，数学的找规律之类的。 

 企业文化：首先，网络上提供的中国移动的企业文化，大家最好别看了，要看也尽量看今年的。我是认真看了也稍微整理了一下资料，然后发现没考那些。 

 有一道每年必考题，分享给大家。到时候你就会在考试的时候看见这道题，和我一样忍不住哈哈大笑。 

 “中国移动是全球 网络规模最大 ， 客户规模最大 ，市值排名领先的电信运营企业。”
 

 
 

 如果有朋友想要中国移动的企业文化之类的资料，我可以分享。不过我个人的建议是：不要复习这个机试了，浪费时间。 

 
 

 一面：小组面，一组30mins内。 

 首先，还挺烦人的，一般小组面的话，Hr会跟你约一个大概的时间，就是按照每组xx分钟，你是第几组，就会跟你约好一个固定的时间。 

 但是因为Hr拉了个群，然后说9.开始面试，每组多少时间，不知道。 

 所以虽然我是末尾的组，但我随时要警惕着动静，从9.等到11.才面试上。 

 这段时间虽然我在看面经，但我体验感不太好。我觉得，如果HR更关心面试者的话，完全可以采取更好的方法。 

 （只是表达个人感受，不能骂我） 

 
 

 一面内容：
 ①自我介绍 

 ②为什么选择中国移动？为什么选择中国移动的这家分公司。 

 ③如果薪资和你心里预期的有落差，你会怎么样？ 

 
 

 说个趣事，当时小组面，我前面的男孩子是一个非常“不官方”的人，他说自我介绍都紧张了1mins才开口，全都是口头表达，一看就知道没背稿子。 

 我后面那个男生反而是非常"官方"的，他看起来就像是对着电脑读稿子的机器人，全都是书面表达，非常官方。 

 然后问到为什么要选择中国移动的时候，我后面那个男孩子就开始背诵面试前两天的机试中企业文化的内容。 

 我当时都要笑出来了（可是在视频 我不敢哈哈哈哈！） 

 “我会选择中国移动，是因为中国移动是中国五百强企业，注册资本3000亿人民币.....blabla” 

 面试官都笑了。 

 
 

 另外，如果一面就提到了薪资，而且还暗示很低，估计就会比行业内平均水平还要低。 

 大家遇到这种情况就最好做好run的心理准备，把精力放在其他公司的面试上更好。 

 
 

 二面约了我朋友，我的群说还没出结果。 

 我朋友说面试官讲：加班费没有! 

 然后问了：“如果明天给你发Offer，会来的举手。” 

 太离谱了。 

 
 

 如果要面中国移动的话，我建议朋友们选择比较好的城市。 

 因为这种国企在非一线城市的待遇，其实也不怎么样。不过具体情况具体分析嘛！ 

 
 

 广州银行 总行系统运维岗 base佛山 

 这个是我面试体验最差的一家，我要大骂特骂！！ 

 一面是短信约的，给了大概时间+腾讯会议号码。 

 跟我约的是16.，要求提前15mins进入会议室，所以我15.30就在调试摄像头和光线啥的，等到15.45准时进入会议室等待。

 我晕，我当时都打开江苏银行的机试APP易考软件，搭建好双机位摄像头了，结果他突然来这一手，我就只能面试，然后祈祷快点结束，我要赶着去做机试。

## 厦门国际银行、岛津仪器、中国移动社招市场营销面经

来源：牛客网 ｜ 类型：面经 ｜ 发布：2021-02-19 ｜ [原文链接](https://www.nowcoder.com/discuss/353157531797233664)

厦门国际银行 

 

 面试过程： 

 1、首先由招聘负责人引入一个会议室做题，笔试的题目包括银行基础知识、英语测试和职业能力测试。 

 2、在笔试的过程中会一个个去另外一个小会议室面试，采取 2 对 1 的形式，一名面试官主要问问题，另一名主要记录。 

 3、首先是自我介绍。建议不要介绍简历上能看到的东西。最好是能对自己做一个理性的总结，给面试人员留下一个初步的印象。 

 4、然后是面试官就着你的简历提问题。他会有意识地把你引到一个矛盾的境地，看你在矛盾的情况下反应能力和气场如何。不要刻意地表现你有多么契合岗位。多说一下感性的知识，让人家从感觉上信任你。要突出自己对岗位的兴趣和初步了解，所以得在面试前做一些准备。 

 
 

 岛津仪器 

 

 面试过程： 

 分为两次面试。 

 1、第一次是公司人事和部门的一个主管面试，先是自我介绍，然后问到以前工作内容是什么？以前工作和现在面试工作的联系？我是怎么来公司面试的？ 

 2、第二次是群面，有老总，管理部经理，市场部经理，人事。我和另外一个哥们一起面，主要问了以前工作经验的事，还有对现在工作的认识。因为准备充分，所以很顺利的通过了。 

 
 

 中国移动 

 

 面试过程： 

 1、首先做自我介绍。 

 2、然后就简历问了问家是哪的，户口是不是本地。 

 3、对应聘的市场口岗位了解多少。 

 4、接着问一下关于这个岗位的看法或建议，说一下你的优缺点 

 5、一线岗位，就是去小区驻点等，薪水税后 3500 能接受吗？并且近期不会上涨多少。

 广州思酷信息科技有限公司

 然后直接取消我们下一个讨论环节，面试结束。总之就是感觉，HR态度很凶，讲话期间语气很不友好呀。而且再怎么差，也不要把人的面试环节取消嘛。唉，不过也是面试经验不够吧，对时间的把握不好。感觉我们一整组的同学都要凉凉了。唉一个应聘财务管培生的去面这种问题，也是很不容易。

## 客服管培生 中国移动 电讯盈科 面试经验分享

来源：牛客网 ｜ 类型：面经 ｜ 发布：2020-09-27 ｜ [原文链接](https://www.nowcoder.com/discuss/353157081366732800)

中国移动 

 

 客服管培生 

 

 移动的客服人员一点都不好当，回想起当时心态真的很矛盾，很怕休息又很想休息，怕的是休息回来就必须提前回到公司做准备工作了，因为在你休息的时间就会有很多新的公告，你必须把他好好的消化掉，要不然正式在线的时候说错话就惨了。 

 上班的时候连上洗手间的时间都变奢侈了，因为会因为你帮客户处理问题的时间快慢会占用到你的休息时间。正因为他的工资高所以要求自然就高了，我也是参加了两次初试，第二次才进入复试的。问听一个童话故事后简单概括故事内容。 

 

 电讯盈科 

 

 客服管培生 

 

 首先我是网上投的简历， hr 电话去面试，面试第一面很简单， hr 问一些你的基本情况，首先是自我介绍，之后就比如哪里毕业，为什么打算在这工作之类的问题，比较简单 

 二面就是笔试了，比较简单，一些常识问题，最后一题是英语，不过也不难，人多了一起笔试，是可以互相借鉴的。 

 三面有点难，是和相关组长的对话，会首先再让你自我介绍，他手里会有你的简历和之前的笔试成绩，然后问一些，问题，比如，是否熟悉你打算从事的工作（这个不重要，因为有培训，可以自己根据实际情况说明）再比如就是问你对职业的规划，这个一定要清晰，说明你的来意和规划，不能说是来挑战自己或者是短期工作，一定要说明你能给公司带来什么和你的相关规划（没有规划，就编一个，比如打算找稳定的长期工作）问你对你的职业或者工作有什么规划吗？

## 江苏移动，中国移动，广西移动财务校招面经

来源：牛客网 ｜ 类型：面经 ｜ 发布：2020-09-19 ｜ [原文链接](https://www.nowcoder.com/discuss/353157013473533952)

江苏移动 

 面试过程： 

 1. 在休息室等待叫名字，苏州移动终面人仍然是非常多，不知道最后招收几个。 

 2. 面试官4个，主要有一个来问。自我介绍只介绍名字和专业就好了，面试官好着急…… 

 3. 相关实习经验讲一下，问了家庭情况，想做财务哪方面。非常快，前后大概5分钟。 

 一些问题: 

 问给你想做的财务工作排序。 

 我的回答: 

 答首先是成本会计，对企业内部审计也比较感兴趣。 

 
 

 中国移动 

 面试过程或经历: 

 看好自己的组别和序号，签到，交简历。 

 面试分为两轮，第一轮是单面，两位面试官，首先做自我介绍，然后面试官会根据简历问一些问题，面试官对考生的实习经历比较感兴趣，会问实习过程中遇到的具体问题，还会问一些具体的财务知识，一笔账如何处理，走那些费用等等。 

 第二轮面试是分组讨论，面试的人员分为两组，根据一个具体的问题双方辩论，最后得出一致的结论。我们组讨论的题目是一个被拐卖到农村的妇女最后当了乡村女教师，问这个事情是否应该被表彰。讨论过程比较激烈，只要心态平和，论点论据说清楚就可以。 

 一些问题: 

 问职工薪酬走什么费用 

 我的回答: 

 答生产类岗位就是生产费用，管理类岗位就是管理费用。 

 
 

 广西移动 

 面试过程或经历: 

 1. 群面形式，六个人一组，五六个面时官，先自我介绍一分钟，接下来就是在校期间，最让你印象深刻的一件事，然后提问三个财务类相关知识。 

 2. 你对三表的认识，固定资产的折旧方式，财务指标的例举及其功能作用。还有其他组的是存货的计提，如何对企业进行审计之类的。 

 3. 然后对一些同学进行简历的相关提问。

中国移动 

 咨询顾问 

 先是接到顾问电话，好客气好温柔的声音说他们项目组缺人，想请你来帮忙，意愿如何。如果可以的话第二天过来面试。 

 第二天穿的很正式就去了，但是发现正式员工穿着没有很正式，都是休闲工作装，亲切感又增加了一层。然后是一对一，是项目高级顾问来面，问了问教育背景，之前在哪实习，做过什么，为什么选择咨询（如果是理工科背景这个问题很重要），为什么选择中国移动。感觉面试有点难度，希望会过。 

 

 上海华彩管理咨询 

 面试分为两个环节，分别是笔试和面试。 11 个人的面试场，先是笔试，性格测试加语言能力加两道问答题，问房地产的价格走势和中国管理咨询业的发展态势。然后是群面，先 1 分钟自我介绍，然后每个人分享一本书，然后是案例， 3 个人一组回答 3 个问题。现场通知进终面的名单，与人力总监单面，结构性面试 。 

 

 中大咨询 

 是校园招聘。在西安，简历没有限制学校，他们说投了简历的都给了一面机会，一面是群面，分成两个小组，辩论。 3 天内给了二面通知，先笔试，然后根据笔试内容做个展示，展示完之后进行讨论。 3 天内给了消息。三面是单面，资深顾问面试的，先是自我介绍，然后问能否适应出差吗？感觉这次面试主要就是看看个人气质之类的了。一周内给了 offer 。
