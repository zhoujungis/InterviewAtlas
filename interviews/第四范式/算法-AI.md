## 29届第四范式agent开发实习面经（已过）

来源：牛客网 ｜ 类型：面经 ｜ 发布：2026-03-13 ｜ [原文链接](https://www.nowcoder.com/feed/main/detail/77a81a03b55143c89d1caf76833676d9)

前情提要

本人29届毕业，这几天也是春招火热期，于是在boss上投了几个公司。发了几份简历之后，第四范式公司hr初步问我了一些vibe coding的经历，之后打算联系我进行面试。

面试内容

问：简历中AI Agents的开发经历是个人开发的还是在实习？

答：前两个项目是个人开发，后一个是团队开发的（项目：工作流、AI框架、Agent多端应用）

问：索要项目上线的网址和在这个Agent多端应用中负责什么方向？

答：这个项目的后端是一个golang、python的微服务架构，其中golang负责后端，python负责ai层。前端则是web端为vue3，移动端为flutter。我负责的是全部的的ai层和golang后端的跨域通信和部分后端功能和web前端功能的改进设计。

问：询问项目的主要功能，和如何实现？

答：使用langchain、langgraph框架，首先把工具通过mcp-adapters进行打包，之后ReActAgent进行调用工具与数据库进行交互，另一方面在进行增删改操作时由于ai输出不一定满足用户的需求，我做了一个独立的确认节点作为拦截中间件，截断了数据的写入，而用户可以来自行编辑或保存删除。

问：Agent的工作模式都有什么？

答：ToolsCallingAgent、ReActAgent、ReflectionAgent、PlanAndSolveAgent（并粗略展开每一种大概机制，此处不多赘述）

问：介绍一下你对RAG的理解？

答：我平时不太喜欢用RAG，主要因为两点，自己开发的时候大多数用不到这个技术，RAG最好在垂直领域来使用，尤其是ToB或者专精某一特定领域，而且前段时间不少人说RAG已死，指的是现在很多东西能替代RAG的功能；其次RAG的召回率并不算太高，想要优化召回率只能花费大量人力财力来进行经验微调。知识库开发的流程一般是，先进行数据清洗，之后进行向量化储存到向量数据库，召回时在进行一个向量匹配的操作

问： 看到你做了一个memory上下文记忆功能的处理，可以说一下处理逻辑吗？

答： 记忆可以分成长期记忆和短期记忆，我在长期记忆这里使用的是RAG技术，将用户强调或者比较有价值的数据存入，这样可以作为一个跨对话窗口的上下文，而短期记忆我也是做了一个上下文压缩，用了一个经验值作为阈值，等上下午到一定程度之后就会进行精炼，而精炼又有两种模式，我分为智能模式和机械模式，智能模式是通过llm进行关键信息等提炼，机械模式是通过正则处理去除冗余的工具调用日志和结构化导致的上下文污染

问：对于模型的选型你是否有考虑呢？

答：之前自己做过coding agent等类似的项目，在多智能体系统中对于不同的任务采用的模型不同，比如plan使用主力模型opus，编写代码使用中等模型sonnet，而探索项目结构可以使用haiku等小模型，这样的话既可以节省token花销也可以不降低代码质量

问：你是否有AI编程的经历和理解？

答：略（先是说了市面上各ai编程工具的差异性优点及缺点和我自己的订阅情况，之后说了开发模式相关如spec driven。ps：可参考该文章 AI 原生工程）

问：对于Agent有没有什么熔断机制？你有接触过么？比如你的基模直接卡死了，你的后端是否有什么保底机制？

答：有的，在项目中我对tool calling做了一个熔断机制如果工具调用失败超过三次就会进行熔断处理，防止反复重试导致系统崩坏。如果基模卡死的话，完全可以弄一个集群来处理，如果一个服务器掉了可以快速转到另一个提供llm的服务器。

最终也算是过了 #牛客AI配图神器#

一、题目描述

 给定一个长度为n的小写字符数组，一次操作是删除一个最小字母，如有多个删除最靠左的。要求输出操作k次后的字符串。

 输入：abcdabcd k = 3
输出：cdbcd 
 二、解题思路 & 代码

 由于都是小写字母，字符类型比较简单，故而可以用简便的方法

 采用哈希表将字符串进行计数 将键值从小到大排序，而后从前往后删除，当删除的数量 == k 时停止 from collections import Counter

 def delMinAlpha ( s , k ) : 
 n = len ( s ) 
 dic = Counter ( s ) 
 print ( "dic:" , dic ) 
 sum_ = 0 
 del_dic = {
 } 
 key_list = sorted ( list ( dic . keys ( ) ) ) 
 print ( "key_list:" , key_list ) 
 for stop_ind , key in enumerate ( key_list ) : 
 sum_ = sum_ + dic [ key ] 
 del_dic [ key ] = dic [ key ] 
 if sum_ >= k : 
 break 
 print ( "ind:" , stop_ind ) 
 print ( "sum_:" , sum_ ) 

 stop_key = key_list [ stop_ind ] 
 print ( "stop_key:" , stop_key ) 

 del_dic [ stop_key ] = dic [ stop_key ] - ( sum_ - k ) 
 print ( "del_dic:" , del_dic ) 
 new_list = '' 
 for j in range ( n ) : 
 if s [ j ] not in del_dic : # 要删除的键值 不存在 
 new_list += s [ j ] 
 elif s [ j ] in del_dic and del_dic [ s [ j ] ] > 0 : # 要删除的键值 存在，且还没删光 
 del_dic [ s [ j ] ] -= 1 
 continue 
 elif s [ j ] in del_dic and del_dic [ s [ j ] ] <= 0 : # 即使要删除的键值 存在，但是已经删光了 
 new_list += s [ j ] 
 return new_list

## 非技术岗 秋招总结+面试回忆

来源：牛客网 ｜ 类型：面经 ｜ 发布：2018-11-01 ｜ [原文链接](https://www.nowcoder.com/discuss/353154734699782144)

从8月初到11月初，整整过去了3个月，秋招总算告一段落，只有这个时候才能稍微心安些回顾一下秋招。。。我是工科背景，不想干老本行就在3月份时找到了一份大厂商业分析的实习，所以下面的分享也以商分为主。在遍地程序猿和PM的牛客，这应该是一个比较边缘的岗位，分享一波面经，里面也有一些有趣的经历，希望能对后续有需要的同学一些帮助。 

 
 

 【 1 】 美团，商业分析岗 

 —流程： 统一笔试-群面-业务面-主管面-hr面 

 —节奏： 三天完成所有面试，群面和业务面都是当晚通知结果、并安排第二天继续面，hr面之后一周收到面试通过的电话 

 —面试回忆： 

 ①群面：两组面试题：盒马鲜生或者拼多多。当时我们组面试的题目是盒马鲜生相关的，给了一大段材料，阅读完后让讨论盒马鲜生未来三年的发展目标、竞争壁垒和三个核心发展策略。当时我们组人很少、只有5个人，加上有2个同学基本不怎么说话，整个面试过程会出现有时全场沉默的尴尬。最后我和一位男生通过了。后面和hr聊过这次群面，hr说群面时不在于话说多少，而在于能不能说出要点，我当时在目标那块提到了要重视商品来源（种植地、养殖地）等，算是很重要的点。 

 ②二面-业务面：两位面试官，全程聊了40min，一部分围绕简历上和商分相关的实习经历，一部分是对美团业务的了解和分析。美团是出了名的深挖简历，简历挖的非常非常细，所以建议面试前一定要好好准备简历。业务这块因为面试通知上有写部门，当时提前准备了一下，聊的还挺顺利。 

 ③三面- 主管 面：面试官是一位很可爱的小姐姐，一点都看不出来已经工作了七八年。当时她对我的专业背景很感兴趣，我是学城市规划的，毕业论文在做一些大数据在城市研究领域的应用。美团目前正在进行一些线下部署，并且本身有很多很多的数据，她希望我能够利用这些数据、借助GIS等进行空间分析，进而指导线下的部署。感谢我的专业，没想到竟然在这里也能用上，可能也正是因为专业背景我才能通过三面，因为其他应聘者的数据分析能力都比我强太多。 

 ④四面-hr面：总监面之后直接被领过去hr面，先聊了下群面，然后她给我介绍了下美团的工作内容、强度和节奏，其他就没什么了。 

 —其他： 美团的商分团队很强大、也很成熟，但估计工作强度和压力也很大 

 
 

 【2】贝壳，商业分析岗 

 

 —流程： 当场笔试-业务面- 主管 面-hr面 

 —节奏： 两周完成所有面试，周六上午笔试完直接去一面，一周后二面+hr面（插一句：贝壳的商分团队很厉害，基本都是美团过来的），一个月后收到通过的邮件 

 —面试回忆： 

 ①笔试题目：一道数据+图表分析大题，基于此为产品、运营等部门提建议；两道选做题：SQL、R
 

 ②一面-业务面：因为贝壳商分都是从美团挖过来的，所以不可避免的深挖简历，当时还被指出了一个逻辑漏洞，对面试官佩服的不行。这个面试官很有趣，问完简历后，聊了会笔试题，说这题不是他出的，这题太硬了，只要愿意学很容易上手（我刚自学一个月SQL，但题还是做错了），说咱来点智力题，智商是硬伤，和智商不过关的人合作真的很心累。 

 第一题：老王是卖衣服的，一件衣服的进价是50元，老王卖了80元，顾客给了一百元给老王，老王没零钱，于是找邻居换了100零钱，事后发现100元是假的，于是老王又赔了邻居100元，请问老王一共亏了多少钱？ 

 第二题：从前有一个商人要雇佣一个工人七天，但是他只有一根金条，而且要求这根金条只能切两次，工人的工资每天都要发，请问，怎么切割这根金条？ 

 第三题：估算北京的租房需求量 

 第一道题刚一开始答错了，但在他的引导下找到了正确答案；第二题很快答对了；第三题给了他两种解法，他对第二种比较满意。面完之后感觉不太好，因为面简历时没怎么准备、一些内容忘了，犯了这种非常低级的错误，但后面的题做的还算可以。 

 ③二面- 主管 面：不得不说，贝壳的商业分析团队很优秀，而且面试的思路很清奇[捂脸]。这位大佬的面试一点也不像面试，全程都像在聊天、在传授经验。问：你了解互联网的商业分析岗吗？我：不是很了解。大佬开始滔滔不绝地和我分享他的见地（篇幅有限、此处省去1万字）.......关键是还都特别犀利和深刻，真的收获非常大。然后又聊到了拼多多、抖音等很火爆的产品，大佬的见地和一般人很不一样，他不看好抖音，看好拼多多、但又指出拼多多动作有些太快，一旦有这么大动作、让阿里爸爸看到商机，很快就会被吃掉，京东和它的后起之秀天猫就是非常好的例子......其他的就不展开了，面完之后真的是好感度+10086 

 ④三面-hr面：三面完之后直接hr面，不得不说这位hrbp知道的也很多[ 捂脸]，对着三面的话题又展开聊了会儿。然后就是介绍了部门的业务方向。
 

 —其他： 贝壳的 商分团队很强大、，很多是从美团挖过来的大佬，关键是都还很有趣

 —面试回忆： 

 ①一面-业务面：一个很nice的小姐姐，看起来很年轻，估计刚工作没几年，主要是就着简历问，聊的很轻松，10min就结束了 

 ②二面- 主管 面：这个也是个大佬，我都被面的怀疑人生了，而且觉得铁定凉。简单几句话聊了聊简历。问：有没有带自己做的一些分析报告之类的。我一惊，之前有准备过京东、天猫、苏宁的竞品分析，但后面一开始秋招就没继续做了，实习的内容也不太方便直接拿给他看。然后我就硬着头皮给他看了没做完的这份竞品分析。被他批的很惨：更像份资料收集和梳理的报告，没有太多自己的观点，你对行业的判断，基本都是基于别人提出了什么。又聊天猫，批：你的这些观点都已经过时了。又问SQL，没怎么答上来，批：自学的SQL看来也不怎么样。然后又问了几道类似观察分析的题：
 

 第一题：啤酒瓶为什么绿色的 

 第二题：超市为什么都被放在商场的地下一层？珠宝之类的为什么都在一层？吃饭的地儿为什么都在顶层？

 ③三面-hr面：（真的特别惊讶二面竟然过了，可能大佬觉得我底子虽差，但还不至于烂泥扶不上墙......）电话聊，为什么想来京东？怎么看京东和天猫？你最崇拜的一个人？有时候需要加班能接受吗？ 

 —其他： 后来发的offer是 数据分析岗，可能京东的商分就是数分？不太清楚......

 ②一面-主管面：范式的商业分析团队很年轻，这位主管是从IBM挖过来的大佬，正在组建商业分析团队，所以一面就是部门主管面。面试基本全程都在围绕我做的那份笔试PPT。面完之后说他这边过了，后面会有一个联合创始人面，问我有什么要问的没。我就问了下联合创始人面要怎么准备。这位大佬特别好，说我目前的话可能对公司的业务和产品不太熟悉，这块需要做下功课。然后互加了微信，联合创始人面之前，大佬叫我提前过来，亲自给我讲他们公司的业务、产品和商分的定位、工作内容，整整讲了一个小时......真的特别感动

先介绍下自己，本硕均985。本科报考志愿填了个夕阳产业----建筑环境与能源应用工程，四年间，不断地在怀疑自己与怀疑专业中度过，也有拿过一些奖学金，最终成绩还是离保研差了些，很有些失落。当时也在找工作与考研之间犹豫，***，本科很好的一朋友给我说了一句话，我现在仍然清楚记得：“当前时代是信息科学技术的时代，你是要被这股浪潮推着往前走，还是想做个弄潮儿”，这番话，坚定了我考研的决心，从7月准备考研本校计算机，到最终录取，这段时光应该是大学以来最充实丰富的，自律而有序，和几个本科朋友一起准备考研，只是他们都是往本科所在专业考，我却选择了另外一条路。说实话，当时如果考本专业，应该是十拿九稳，而计算机这玩意儿，我是一点把握都没有，但是一想，生活中就是因为这么些不确定的事情才值得热爱啊，就像前两天ig打kt,g2打rng，就是那么些不确定使我充满期待。 

 后来考上计算机，咱学校计算机就两年时间，第一年上完课程，马上就得开始秋招，时间很紧迫。期间第一学年的春招实习，是非常重要的，我当时转行刚半年，毛都不会，做了个比赛，拿了些名次，本来约了今日头条的面试，还是怂，给推了，现在想想，很是后悔，就算当时面试了，被***，我也没有什么可失去的，这是后话。 

 提一提我的几个朋友，刚来一段时间，也有了新的朋友圈子，大概十多个人，平常一起出去吃饭玩耍，好些都是跨考的，有从本校食品学院考过来的，有从其他学校船舶学院，通信学院，物理学院转过来的，当然也有本硕都是计算机的科班生。我重点说一下这个食品学院考过来的哥们儿，称呼为A吧，A是个很有危机感和执行力的人，刚开学就想好了后面的路该怎么走，打比赛，找实习，然后秋招，这都得在一年内完成，当时我还没啥想法，在他的带动下也开始准备，当然，如前所述，我实习还是怂，没敢投简历，A则通过了腾讯的面试，直接去微信事业群实习，当时我就惊了，明白其实不是科班生只要好好准备也是能去bat核心事业部的。 

 意识到只剩不到几个月就开始秋招了，也没有实习和啥好项目，只能做做比赛。从5月到7月这段时间断断续续的刷了《剑指offer》的编程题。到了7月底，陆陆续续一些公司开始提前批校招，我在牛客上天天盯着公司招聘信息，找内推，开始投简历，期间做题保持手感，同时准备些理论知识，这一方面主要看《统计学习方法》和《机器学习》也就是西瓜书还有些技术博客。慢慢的，开始有公司约面试，第一家我记得是作业帮，由于比较紧张，代码题没整出来，一面凉凉，这也是我唯一一次倒在一面，记得很清楚。后来就是疯狂安排面试，提前批我投递的公司有40多家，也有不少笔试挂的，例如网易（真的难），一些面试完了放在了offer池里，像vivo和360两家，还有一些，面试时间安排的很晚，到九月份。

 8月底，华为来搞优招，组织了面试，华为的面试是真的水，玄学面试，随便讲讲就过了，当然也有莫名其妙就被挂了的。后来发offer，我朋友一个实验室五个人都签了华为，当然也只是作为保底，毕竟华为优招开始的早，在大概9月中旬会逼签，这时好些公司还没开始校招呢。华为给的待遇还是不错的，有几个部门，比如中软，中研，cloud BU，都是相对值得去的比较好的部门，我身边了解到给的待遇普遍在20k*14-16,认识的拿到sp的有26k，最高27k的，不过今年华为薪资改革，把一部分绩效奖金放在了base里面。另一个优势就是华为的工作城市分布比较多，很多想在二线城市工作又离家近些的如南京，武汉，杭州都是值得考虑的，到后面几个朋友也是考虑这些放弃了大厂（百度大搜、美团等）的offer，所以说，华为每年能招到很大一部分人还是有原因的。 

 提前批其实有很大一部分名额，建议找工作的同学如果没有暑期实习或者转正录用的同学，要在7月底就开始准备，就我了解的以及面试的公司来说，阿里相对来说面试流程最长，多的甚至有六面，头条更注重编程能力考察，腾讯难度没有想象那么高，只是今年算法行情爆炸，竞争者太多了，百度没赶上笔试，没有面，但是身边拿了百度offer的也不少，一方面咱学校在百度的校友比较庞大，whf优秀学长每年也会回来负责招聘，美团我是一天走完流程，四面，每一面都一个多小时，面试体验很好，拼多多今年由于扩招，面试难度不高，京东没有面试，约面试的时候我已经有了很好的工作了，也没啥面试状态了，就放弃了，滴滴同理。 

 下面说说待遇及福利相关，这一块，可以通过微信小程序offershow或者牛客网可以了解，我自己拿到的offer有，美团，搜狗搜索，华为，拼多多，顺丰科技，顺丰同城科技，第四范式，远景智能，均为算法岗，拼多多和第四范式还没谈具体薪资。就我的了解来说，今年研发类的薪资其实已经接近算法岗了，一方面是由于这两年都转算法了，研发类人才稀缺，另一方面，确实是人工智能这一块有泡沫，很多公司给的虚高（个人理解）。已经谈了薪资待遇的公司里面，给的最低的是顺丰科技，30.6w一年，最高的是搜狗sp offer，大概35w左右。聊聊我几个朋友吧，前面说的食品学院的哥们儿A，微信转正，sp offer，31.6w加3w签字费，加5w股票，真大佬，膜拜。同寝室的还有个哥们签了华为诺亚方舟实验室语音算法，对门一个华为sp大佬，一年35w左右，定级15级，另一个签了华为cloud BU研发，32w左右，还有一个去了华为中研院算法，30w左右，当然，这些只是他们签了的，还有像贝壳这种福利待遇都不错的公司的offer，在考虑的，通信学院的那个哥们儿拼多多算法实习转正，ssp，28k×（16+2），第一年包吃住，算满50.4w一年，隔壁宿舍的几个朋友，阿z去了阿里国际事业部研发，阿j签了网易游戏研发，网易游戏给的保底32.8w一年，项目上线另有奖金，这哥们儿拒了旷视科技，我觉得有些惋惜，另有个科班生p哥去了腾讯CDG部门，sp offer，待遇同微信的，实验室的zl哥拒了百度大搜去华为,也一起聊了很久才最终决定，另一哥们l哥滴滴算法岗实习转正。 

 总结下，就我身边的朋友和我自己来看，今年的算法岗虽然竞争激烈，但是好好准备，拿个二线厂如美团，滴滴，拼多多还是不难的，头条要求稍高，我自己也转行一年左右，对于自己的秋招结果还是比较满意的，也深知自己这种算法渣渣还有很多需要学习，写下来这些，也是给大家一个参考，当然，也为自勉。

 更新： 

 说下对于面试来说，面试官关注哪些，首先，你有没有大厂实习经历，实习期间主要做了什么，这一项是很加分的，接着看，有没有项目经历或者算法比赛经历，有的话，会问你对相关知识的掌握情况，项目做得有多么深入，就我和面试官之后的交流来说（仅针对算法岗），其实很多人都没有大厂经历，实验室的项目大多也很水，所以去了公司就如同一张白纸，大公司往往有完善的新人培训体系，他们关注的是你的逻辑思维能力和解决问题的能力以及快速学习的能力，简单来说，就是你够不够聪明，思维是否灵活，这也是算法岗往往有些面试官会问一些逻辑思维题的原因，另一方面就是你编程能力，这个是基本功，不必多说。所以，好好准备，多积累总结面试经验，利用好学校的资源和你手里的资源，肯定有所收获。
