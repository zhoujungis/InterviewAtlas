## 建信融通-后端开发一面面经

来源：牛客网 ｜ 类型：面经 ｜ 发布：2026-06-01 ｜ [原文链接](https://www.nowcoder.com/feed/main/detail/5193c78d62d844b081b7cf38804e0032)

base北京，由中国建设银行联合国铁集团、国家电网、中船集团、三峡集团、五矿集团等央企共同发起设立的供应链金融科技公司，依托核心企业信用搭建互联网供应链金融信息服务平台（核心产品"e信通"），为产业链上下游中小微企业提供应收账款融资、电子债权流转与信用支付等在线金融服务。

【timeline】
网申时间：2026/4/15~2026/5/15

电话约面：2026/5/26 确认是否面试，询问AI工具使用情况
一面通知：2026/5/27 详细面试时间，面试平台

腾讯会议-32min
13:45被运营助理call，叫进会议室开摄像头等候，面试14:00开始。

1. 自我介绍，介绍自己做过的项目，以及项目中主要做些哪些模块
2. 具体讲讲你刚刚提到的订单模块，完整业务流程是怎么样，你主要开发的是什么功能？
3. 处理“订单超时自动取消”这个场景，延迟消息是什么时候发送的？在订单的哪个生命周期创建的？
4. 消息的TTL设置的多长时间？
5. 死信队列的消费者如何避免重复消费（如何保证消息幂等性），比如在死信队列处理消息前，被用户支付了，这种情况你有考虑吗？二次确认机制是怎么样的流程？
6. 项目中同时用到了RabbitMQ和Redis，为什么不考虑用Redis的Stream或者Redisson的延迟队列去实现，而是选择RabbitMQ，这个技术选型你是怎么考虑的？
7. 你刚刚提到，早期采用数据库轮询的方式实现超时取消，后来改为RabbitMQ，你觉得这两种方案在系统资源成本、实现复杂度以及性能表现上的优缺点？
8. 项目中提到用redisson分布式锁去解决高并发抢单，并利用ZSet去缓存待接订单，你能详细讲一下从用户下单到抢单整个的业务流程是怎么样的？
9. Redisson分布式锁，锁的持有时间是如何设计的？依据是什么？
10. 如果某用户成功获取锁后，后续的业务处理耗时较长，或因数据库、网络 IO 等原因出现阻塞，锁是否会一直占用导致其他请求无法执行？还是会自动释放？锁释放的过程你理解吗？（看门狗机制）
11. 项目中提到待接订单是放在ZSet中，那抢单的时候是先从ZSet中取出订单再抢锁还是先抢锁再取出ZSet?
12. Redis是怎么部署的？是单机部署、主从复制，还是集群模式？
13. Spring框架中，事务有几种方式？
14. Java开发过程中，如何去开启一个事务？
15. Java注解的实现原理是什么？
16. 比如一个类有两个方法，方法A加上了事务注解，方法B没有加事务注解，但是调用了方法A，此时有一个Controller去调用方法B，它会触发事务吗？(Spring 事务的传播与自调用陷阱)
17. 你在学习或开发项目过程中，有用到AI工具进行辅助开发吗？讲一讲是怎么使用的，它们带来了哪些效率提升？

## 2022届建设银行金融科技部暑假实习面经（合肥）

来源：牛客网 ｜ 类型：面经 ｜ 发布：2021-07-05 ｜ [原文链接](https://www.nowcoder.com/discuss/353158058526318592)

6.30实习投递截至；

 
 7.3上午电话通知面试（线下面试）；

 
 7.5下午三点面试，用时5分钟左右结束；

 
 

 
 面试流程：到面试地点直接到科技部楼层，无会议室等待十分钟左右就开始单个面试，其他人在门口等待并交一份简历，平均每人面试3-5分钟，结束就走了，流程很快，等通知中。。。

 
 

 
 

 
 面试内容：

 
 1、一分钟 自我介绍 （面试官看简历）

 
 2、根据 简历提问内容 ，我的是关于比赛项目得数据爬取了什么？文档类内容有爬取到吗？我回答比较乱，也没说到关键技术，感觉表现不太好；

 
 3、你应该主要做的python，那你写工作要做java？我回答python是论文需要用的，java是目前开发项目在用和工作想要做的方向，也在边做边学习（把自己能力说成了入门级别，我这嘴和脑子怎么搞的）；

 
 4、那你以后想做java开发的哪个方向？我懵了，不懂他到底要问啥吗，直接说做模块开发，面试官说就是做程序员？我说对，想做技术，不想做简单的测试工作（我为什么多嘴说了这一句。。。）

 
 5、实习时间是7月中旬到8月中旬，可以吗？（每个人都问了）

 
 

 
 总结：问的都是简历内容，要好好熟悉自己项目细节，技术没问什么，其他人问的时间和内容比我还少点，面试官也很温和，环境很好，整体体验良好，就是自己表现不好 😂 

 
 保佑我第一次面试有个好结果，给自己打气吧 ！[面试必过]

## 非计科专业的秋招面经总结（银行软开）

来源：牛客网 ｜ 类型：面经 ｜ 发布：2020-01-07 ｜ [原文链接](https://www.nowcoder.com/discuss/353156003942309888)

我本科的是某211CS专业，保研的时候明明有机会去985的CS专业，但是又很想去设计院当混子（此处省略内心真实想法。。。），于是保了本校的自动化专业（偏铁路）。然而今年铁路行业就业形势一片血崩，连之前保底的卡斯柯都开始高攀不起了，那还能咋办，只能吃老本了，遂在暑假花了2个月时间深度复习 数据结构 、 计网 、 操作系统 、 数据库 等基础知识，然后在 leetcode 上疯狂刷题。当初的想法是，CS方向的知识很久没碰了，研究生期间做的项目感觉有点拿不出手（这个专业对编程要求不高），况且以后也不想太拼命的加班，也想要工作生活平衡，那就只有降低自己的要求，往银行IT发展。成都这边银行还是多，综合对比感觉比较好的有农行、邮政、招银、浦发、工行，除了招银是子公司外，其余都是总行部门。8、9约月份的时候，刚好oppo开始招聘了，虽然不一定去，但是还是决定拿来练个手，就报名了，十所也一样。说了这么多，下面分享下我后面陆续面试的公司和比较详细的过程。插一句，虽然本科做过java方向的东西，但当时都是自学的，学的很不系统也不全面，所以秋招时还是以C/C++作为技术栈，然后MySQL等作为辅助，之前听说银行软开都不怎么对C/C++感冒，但我觉得既然他明确写了要求掌握一种编程语言，并没说只要java的，所以我觉得先凭现有技术进去了再说，后面想转还是有时间和机会学习的。我有个同学也想去银行的软开，但是不会java就一个都没报，所以错过了很多机会，我觉得以C/C++为技术栈的同学还是别怕，就按我说的，进去了再说 😂 

 OPPO C/C++ 开发工程师 base 成都（已拒） 

 笔试： C/C++ 基础，选择 + 编程 

 一面：自我介绍，详细项目介绍，虚函数和纯虚函数，多态的原理及实现，设计模式，线程同步等，手撕单例，手撕一个功能类 

 二面：自我介绍，针对 C/C++ 项目详细介绍并提问，学校学习生活情况等 

 三面： hr 面，对自己的认识，自己的不足（技术、精神），写一个比自己强的人的名字，对加班的看法，个人提问 

 面试总体感觉比较轻松，问题也有偏的，面试官说他是面社招的，还以为他要挂我，两个技术面试官人都很好，交流也很愉快 

 

 中电十所 软件开发工程师 base 成都（已拒） 

 无笔试，有一个线上非技术测评 

 一面：自我介绍，详细项目介绍， C++STL 中的 vector 、 map 的底层实现，设计模式，针对 C/C++ 项目的详细提问，如 MFC 下 OnTimer() 里的情况， OnDraw() 的实现等 

 二面： hr 面，自我介绍，对十所的认识，如何评价自己，自己的优点和缺点，提问 

 在一个宾馆里面的，四对一面试，整体难度适中，面试官中规中矩 

 

 浦发银行总行信息科技部 系统开发 base 成都（已体检等 offer ） 

 笔试：行测 

 上机：三道编程题，分值 30 30 40 ，难度适中 

 面试：仅一面，自我介绍，没怎么问技术，面试官对 Java 项目很感兴趣就针对项目提问，项目的架构，怎么连接数据库，说出使用的具体方法（ getConnection(url,id,psw) ），针对毕设提问，用了什么存储数据，用的什么数据库，方法是什么 

 六对一面试，其中一个面试官是远程的，整体比较轻松，没遇到刁难人的情况 

 

 招商银行 招银网络科技 软件开发工程师 base 成都（已签） 

 笔试：全技术题， C/C++/Java ，数据库、设计模式、软件工程、计网等知识点 

 一面：自我介绍，虚函数和纯虚函数，为什么要将父类的析构函数声明成虚函数，多态的原理和实现，面向对象六大基本原则，什么是事务，数据库的 ACID 准则，什么是索引，手撕一个 String 类 

 二面：自我介绍，项目的详细介绍，针对 C/C++ 项目提问，绘制的界面是如何实现的，怎么确保线程同步，具体的通信是如何实现的，手撕字符串处理的算法题，面试官说他之前面的人都是正向处理的，要求我必须反向处理，我瞄了眼其他人的代码都写了好多，猜测有点难度，我以为是刁难我，没想到反向处理几行就搞定了 

 三面： hr 面，自我介绍，自我认识，有没有待提高的地方，有无其他 offer ，家庭情况，有无女朋友，女朋友情况（查户口来的吧） 

 全程高压，各种偏、难、细知识点，问的非常详细，不管是基础知识点还是项目，手撕的时候刚开始没想出来，但是面试官让我不着急很有耐心，后面还是做出来了，还提醒我反复检查，整个面试感觉很正规也很专业，面试官态度很很好，仅次于 OPPO 的面试体验 

 

 招商银行 成都分行 信息技术部 金融科技岗 base 成都（犹豫过，还是拒） 

 笔试：很奇葩，所有面试搞完了再线下笔试，全行测，面试前几天有个线上笔试技术题全选择， Java 偏多 

 一面： 没自我介绍，也没别的说明， 9 个人一起进去，分成 2 组，按照纸上的要求和材料道具等做东西，设计一个灯塔，最后面试官请人发表意见，我全程没咋讲话，最后被抽到说哪个组做的更好，我说对面的并说明了理由，整个过程很懵逼 

 二面：没想到一面过了，二面三对一，自我介绍，项目介绍，代码量，数据库的设计过程，对在银行做金融科技有什么看法 

 三面：感觉是分行的大领导都来了，在会议室里面， N 对一，自我介绍，项目介绍，刚说完问我为什么不去中车，我说喜欢搞开发，其他同学也有去搞开发的，只问了个 C++ 里传参的方法 

 整个招聘过程持续时间很长，一二面在天府三街，三面又去华西坝，笔试去的成都大学，面试过程感觉很奇葩，每次都是莫名其妙进下一轮 

 

 中国建设银行 远程智能银行中心 base 成都（已拒） 

 笔试：线下笔试，几乎全行测，偶尔有几个技术题 

 一面： hr 以为我面了技术，直接让我去 hr 面，结果搞反了，但还是先面了，自我介绍，学习生活情况，为什么保研不读计算机，同学的影响，喜欢与人交流吗，有其他 offer 吗 

 二面：自我介绍，为什么选建行，对建行的认识，将来喜欢做客服、风险、投诉方向的工作吗 

 去面试了才晓得建行这个是非技术岗，虽然比较感兴趣，而且是总行直属机构，但还是拒了 

 暑假复习的时候感觉就像高三的时候一样，每天实验室、寝室两点一线，暑假实验室没人，就我一个，都懒得下楼吃饭了，直接外卖到实验室楼下哈哈 😅，基本都是早上8点到晚上10点的节奏（毕竟要复习的太多了，自己又很菜。。。）那段时间虽然累，但最后复习到的面试中都有问到很多，最后也有所收获，所以感觉还是值了。 

 
 

 最后说一哈，我这个面筋比较适用于非CS专业，或者想去银行软开的同学，大佬直接绕道，我只想做个咸鱼，每个人都有自己的看法和志向，反正经过努力得到了自己想要的就行，加油！
