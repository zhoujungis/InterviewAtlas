● 业务系统的分布式锁和异步线程池如何做的？作用是什么？

● Agent 产出内容的效果如何评测？有没有自动化评测的机制？
● 更新 Skill 的 Prompt 后如何评测效果？
● Agent 制作的 PPT，如果想修改，如何实现？
● LLM 生成的内容或图片不符合要求的话怎么办？如何保证可控？
● Agent 的上下文管理怎么做的？
● 压缩和摘要的区别是什么？
● 是否了解 LangChain 和 LangGraph？
● 前端能力如何？主要用 AI 实现还是手搓？

● 如何防止 MQ 的消息重复消费？
● JVM 中的常见 GC 算法
● JVM 的分代 GC 机制
● HTTP 和 HTTPS 的区别
● TCP 的拥塞控制机制
● 进程创建和切换的开销有哪些？
● 虚拟内存和物理内存是什么？
