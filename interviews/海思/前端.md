## 前端面经-OD社招（三年只写Vue，自己劝退自己半年，最后定级D3）

来源：牛客网 ｜ 类型：面经 ｜ 发布：2026-10-26 ｜ [原文链接](https://www.nowcoder.com/discuss/944198819858685952)

【他们怎么上岸的 · 第 6 期】

 这期写前端，是因为后台私信里问前端的人不少，但我一直没敢写——前端方向的样本确实比后端少找来找去才找到一个，之前不写是因为怕误导人。所以先说清楚：这是一例，不是普遍结论。他上岸了，定级 D3，base 杭州，终端云服务方向。写他，是因为他踩的那个坑特别常见，而且完全是自己给自己挖的。先说他的情况普通一本，计算机，毕业就做前端，三年。公司是一百来人的 To B SaaS，他一个人对着产品经理和设计，写后台管理系统的页面、表格、表单、权限路由，Vue2 写到 Vue3，Element 用到 Element Plus，后来做过一段 Node 的 BFF，还参与过一个内部低代码配置平台的前端部分。想走的原因不是钱，是他发现自己这三年在重复：新需求来了，拉一个列表页、改个弹窗、调一下样式、联调接口。用他的话说——"我三年其实就做了一套东西，只是这套东西被复制了一百遍。"他拖了半年，理由我听完有点想笑他去年就想投了，简历投出去之前自己先撤了。

 问他为什么，他说了三条：

 "前端在 OD 里应该是配套岗位吧？" —— 他觉得前端是给后端打下手的，岗位少、活边缘

 "机考是算法题，我三年没写过算法，肯定过不了。"

 "我只会 Vue，人家要大厂出来的，我这算啥。"
三条里，真正成立的只有第二条，而且是可以解决的。 第一条是他自己想的，第三条是他在拿"大厂背景"给自己找一个不用投的理由。
我跟他讲了两句实话：前端方向的岗位数量确实不如后端，但不是没有，终端云服务、云计算的管理面和控制台、还有质量与流程 IT，都要前端； 至于只会 Vue——面试官不会因为你只写过一个框架就否掉你，但会因为你讲不清两个框架的差别而扣分。
他半信半疑，还是投了。
关于门槛，我把口径一次说清楚
OD 是社招，硬门槛只有一条：已经毕业，有毕业证、学位证，学信网可查。

 27 届和还在读的同学：投不了，机考都约不了，毕业拿到证再来找我

 学历情况比较特殊的：别在评论区猜，也别听人瞎说，私信把情况发我，我帮你确认能不能走流程
机考（3 道算法题，满分 400、150 过线，他 182）
这是他自己最怕的一关，也是拖了半年的主要原因。捡起来刷了两个月，下班回去刷，周末刷。

 第一题：数组和字符串的模拟，题意绕，但逻辑不复杂，他拿了大部分用例

 第二题：滑动窗口，写过类似的，比较顺

 第三题：图，只写出来一半，后面用例没过
考完他跟我说了一句挺实在的话："前端三年，我以为我这辈子不用再碰算法了。结果第一题读完题干我愣了五分钟。"
182 不高，但三道题都有分，够用。机考看总分，不看单题满分。
技术一面（八股 + 手写 + 挖项目，一个多小时）
前半段问得很密：

 事件循环：宏任务微任务，给一段 setTimeout + Promise 混着的代码，问输出顺序

 闭包：什么场景会造成内存泄漏，怎么排查

 this 指向的几种情况，箭头函数为什么没有自己的 this

 原型链，new 的过程具体做了哪几件事

 Vue2 的 Object.defineProperty 和 Vue3 的 Proxy 差在哪，为什么 Vue3 要换

 v-if 和 v-for 为什么不能写在同一个标签上（Vue2 里的优先级问题）

 key 的作用，为什么用 index 当 key 会出问题

 浏览器渲染流程，重排和重绘，哪些属性会触发重排

 HTTP 缓存：强缓存和协商缓存分别看哪些字段

 跨域怎么解决，CORS 预检请求什么时候会发

 webpack 和 vite 的构建差异，为什么 vite 冷启动快

 TypeScript 泛型用过没有，举一个你项目里的例子
手写题三道：防抖、深拷贝、Promise.all。
真正让他紧张的是后面这段——面试官问他性能优化。
他简历上写了一句"负责首页性能优化，首屏加载时间明显下降"。
面试官就顺着问："明显下降是多少？优化前多少、优化后多少？你用什么测的？"
他当时卡住了，回了一句"大概是快了很多"。面试官没接话，也没为难他，隔了几秒换了个问题。
他后来跟我说，那几秒是他整场面试里最难受的几秒——"我确实做了，我知道我拆了包、加了懒加载，但我从来没记过数字。"
好在后面聊低代码平台的时候他救回来了：那个平台的 schema 怎么设计、组件怎么按需加载、为什么最后放弃了"完全配置化"、改成"配置 + 少量代码"——这块是他自己一路踩过来的，讲得特别细，面试官连着追问了四五个问题。
他自己复盘那句我记下了："简历上那句'明显下降'，是我随手写的。面试官一追，我就知道这句话我不该写。"
技术二面
二十多分钟，八股基本没问，对着面评聊了两件事：一是低代码平台为什么不用现成方案、取舍在哪；二是"进来要写 React，你只写过 Vue，怎么办"。
他答得不虚："语法是壳，我这三年真正在做的是把需求拆成组件、把状态理清楚，这块是通的。React 我这两个月在补，hooks 和 Vue3 的组合式写法思路是接近的。"
面试官没再追。
主管面（不太聊技术）
为什么离开现在这家、能不能接受一部分联调和自测的工作、有没有考研考公的打算、城市意愿、薪资预期。
"能不能接受做联调和自测"这题他答得挺实在："能，我原来一个人对接四个后端，联调本来就是我的活。"
结果：定级 D3，base 杭州，终端云服务方向
三年对口经验 → D3，正常档位。
出结果那天他发消息给我，说了一句："我早知道能投，去年就投了。"
这句话我听得太多了。大部分人的问题不是条件不够，是自己先替对方把自己否了。
他自己总结的三句

 前端不是没岗位，是你得能讲清"你优化了什么、优化到多少" —— 写"明显提升"等于没写

 只会一个框架不致命，讲不清两个框架的差别才致命

 别拿"我是前端"当不刷算法的理由，机考不看方向，只看分数
最后照例把门槛说清楚，免得白激动：OD 是社招，必须已毕业、有毕业证学位证（学信网可查），27 届和还在读的同学暂时投不了，等拿到毕业证再来找我。
我是帮他内推和准备的 HR，坐标科锐国际。方向是全覆盖的：云计算、终端、计算（鲲鹏/昇腾）、海思芯片、数据通信、无线、光产品、云核心网、GTS、数字能源、智能汽车、2012实验室、质量与流程IT；base 有西安、深圳、东莞、杭州、南京、北京、上海、成都、武汉、苏州、长沙、济南十二个城市。定级按 D1-D5 走、对标大厂 13-17 级，看机考和面试表现定，不是一刀切。
前端方向的岗位没有后端多，这个我不糊弄人；但你这个城市、这个年限到底有没有坑位、大概能到哪一档，评论区把情况发我：现在做什么 + 几年 + 想走的方向 + 意向城市 + 是否已毕业，我一条条回。
不方便公开的私信我，报「姓名 + 方向 + 城市」，我帮你看匹配的方向和大概档位。
前端方向的机考高频题型 + 一面八股清单（含手写题）我整理了一份，评论区扣 1，私信发你。
