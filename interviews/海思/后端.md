## Python面经-OD（收到意向后被鸽了，社招上岸复盘，定级D3）

来源：牛客网 ｜ 类型：面经 ｜ 发布：2026-10-20 ｜ [原文链接](https://www.nowcoder.com/discuss/942026114954764288)

【他们怎么上岸的 · 第 4 期】这期这个人比较特殊——他不是没 offer，是 offer 飞了。写出来是因为最近问"被鸽了还能怎么走"的人太多了，他的情况可能跟你现在一模一样。先说背景：普通一本，计算机相关，Python 后端，25 届毕业，在一家做政企项目的公司干了两年，主要写接口和一些数据处理脚本。被鸽这段，我按他原话讲。今年 8 月，他走完了某大厂三轮技术面加主管面，HR 那边薪资、入职时间都聊得差不多了，最后一句话是"等审批，两周内发意向"。然后等到的是另一句："业务调整，这个 HC 冻结了。"从"两周"到最后确认没戏，中间拖了整整一个月。他后来跟我讲的一句话我记到现在："我最难受的不是没面上，是我这一个月什么都没投，全押在这一个上。"这也是我最想让大家记住的一点——口头意向不算数，等 offer 的时候手上必须还有别的事在做。决定投 OD 之前，他抵触了挺久。网上"外包"的说法看多了，他第一反应是不想去。后来是自己把情况摸清楚了才松口：全程华为自己面试、定级定薪和日常管理都是华为负责，跟正编在同一个项目组做同一套需求，跟他理解的外包不是一回事。他的原话是："反正都是写代码，我要的是平台和项目，不是名分。"机考（3 道算法题，满分 400、150 过线，他 205）：

 第一题：字符串处理加边界判断，思路不难，写了大概二十分钟

 第二题：暴力会超时，改成前缀和加哈希表才过

 第三题：图那一类，只写了个大概，跑通了部分用例
两年工作经验让他手感还在，但他自己总结得很实在："工作两年不等于算法不用练，第三题就是没练到位。"
技术一面（前半段 Python，后半段挖项目）：

 GIL 是什么，对多线程的实际影响，什么场景下多线程其实是假的并行

 深拷贝和浅拷贝的区别，项目里有没有踩过坑

 装饰器的原理，带参数的装饰器怎么写

 生成器和迭代器的区别，yield 做了什么

 list 和 dict 的底层实现，dict 查询为什么快、什么时候会扩容

 Python 的内存管理和垃圾回收（引用计数 + 分代回收），循环引用怎么产生的

 多线程、多进程、协程怎么选，asyncio 有没有实际用过

 项目里用的什么框架，遇到过什么性能问题，怎么定位的
后半段挖项目这块，他本来以为政企项目"拿不出手"。结果面试官追问的全是细节——你真做过的东西是能讲到底的，讲不下去的才是编的。他最后讲的是怎么把一批数据处理任务从跑几个小时压到几十分钟，反而聊得最顺。
技术二面：主要对着面评聊项目和技术选型，八股基本没问，细节就不展开了。
主管面（几乎不聊技术）：问了三个问题——为什么离开上一家、被鸽这件事你现在怎么看、未来三年打算怎么过。还有城市意愿和薪资预期。
被鸽那段他答得挺好：如实说失望过，但重点讲这一个月他想明白了什么——不再把所有鸡蛋放一个篮子里。主管在意的不是你被没被鸽，是你有没有因为这事变得不稳定。
结果：定级 D3，base 武汉，已入职。
他自己总结的三句，我觉得比我说一百句都管用：

 别 all in 一个 offer。口头意向、谈完薪、甚至发了邮件，在入职之前都不算数，等的时候继续投，不冲突

 机考 205 不算高，第三题只拿了部分分，是技术面补回来的。一门没考好不等于整场完了，别中途弃考

 Python 别担心方向窄。后端、测试开发、数据相关都有口子，机器考的是算法不是语言，你用 Python 答题完全没问题
最后把门槛说清楚，免得白激动：OD 是社招，必须已毕业、有毕业证学位证（学信网可查），27 届和还在读的同学暂时投不了，等毕业了再来找我。
我是帮他内推和准备的 HR，坐标科锐国际。Python/Java/C++/Go/测试方向都在招，产品线覆盖云计算、终端、计算（鲲鹏/昇腾）、海思芯片、数据通信、无线、光产品、云核心网、GTS、数字能源、智能汽车、2012实验室、质量与流程IT；base 有西安、深圳、东莞、杭州、南京、北京、上海、成都、武汉、苏州、长沙、济南十二个城市。定级按 D1-D5 走、对标华为 13-17 级，看机考和面试表现定，不是一刀切。
被鸽的、秋招没着落的、已毕业想换平台的，都可以来问。把你的情况发评论区：学历 + 方向 + 意向城市 + 是否已毕业，我看到会一条条回。不方便公开的私信我，报「姓名 + 方向 + 城市」，我帮你查在招岗位、看看大概能定到哪档。
