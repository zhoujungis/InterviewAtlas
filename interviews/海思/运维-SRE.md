## Go面经-OD社招（运维干了3年想转开发，上岸复盘，定级D3）

来源：牛客网 ｜ 类型：面经 ｜ 发布：2026-10-21 ｜ [原文链接](https://www.nowcoder.com/discuss/942363753746554880)

【他们怎么上岸的 · 第 5 期】这期的主角是个干了三年运维、想转开发的人。写出来是因为私信里这类人特别多——运维、测试、实施，天天跟代码打交道，但简历上写不出一个"开发岗"，投出去基本没回音。他走过的弯路，可能你现在正在走。先说背景：普通本科，网络工程，毕业后一直在做运维，后来叫 SRE。日常工作大概是这样：看监控、处理告警、写 Shell 和 Python 脚本、维护 k8s 集群、夜里值班。想转的原因很朴素：天花板太明显了。 他原话是——"我写的代码没人当回事，出了问题第一个找的是我，晋升的时候又没我什么事。"最卡他的是一句话：投开发岗，面试官看完简历基本都是同一句："你没有实际的开发经验啊。"运维写的脚本，在别人眼里不算开发。所以他从去年开始自学 Go。 不是裸辞去学，是每天下班后和周末，陆陆续续学了一年多。中间自己写了个小工具——定时巡检集群里的资源，把异常项汇总推到群里，用 goroutine 做并发采集、加了超时和限流。东西不大，代码也就几千行，但他在 GitHub 上是公开着的。后来复盘的时候他说，这个破工具是他转开发唯一的敲门砖，比他背的所有八股都重要。决定投 OD 之前，他也纠结过。网上"外包"的说法看多了，本能地抗拒。后来是自己把情况问清楚了才松口：全程是大厂自己面试，定级定薪和日常管理也是大厂直接负责，跟正编在同一个项目组、做同一套需求。他跟我讲的一句话我觉得挺实在："我先要的是能做开发的岗位，别的先往后放。"机考（3 道算法题，满分 400、150 过线，他 190）：坦白讲这个分数不高。三年运维基本不碰算法，捡起来很痛苦，断断续续刷了两个月才敢约考。

 第一题：字符串处理加边界，比较常规，写得还算顺

 第二题：排序加贪心，改了两版才过

 第三题：动态规划，没写出来，只过了样例就交了
他自己的总结："刷题这事儿别信'我工作过所以不用练'，运维三年我一行算法题没写过，考场上是真的手生。"
技术一面（前半段 Go，后半段挖他那个小工具）：

 goroutine 的调度模型（GMP），什么情况下会阻塞

 channel 的底层结构，有缓冲和无缓冲的区别，close 之后读写分别会怎样

 select 的底层，多个 case 同时就绪怎么选

 slice 和 array 的区别，slice 扩容的规则

 map 为什么并发读写会 panic，怎么解决，sync.Map 适合什么场景

 defer 的执行顺序，defer 和 return 谁先谁后

 context 是干什么的，超时控制怎么写

 GC 的三色标记，什么情况会发生内存逃逸

 他那个巡检工具里，并发采集怎么控制数量、超时怎么做的、失败了有没有重试
第 9 点是整场最关键的地方。面试官没有嫌项目小，追着问的是细节——并发用什么控的、限流是自己写的还是用的库、超时 ctx 怎么传下去。这些他都是自己一行行写出来的，答得上来。
用他的话说："编的项目经不起追问，自己写过的哪怕再破，问到底你都说得出为什么。"
技术二面：主要对着一面的面评聊技术选型和那个工具的改进思路，八股基本没问，就不展开了。
主管面（不太聊技术）：为什么从运维转开发、运维这三年你觉得白干了吗、能不能接受从基础开发做起、有没有考公考研的打算，最后是城市意愿和薪资预期。
"运维三年是不是白干了"这个问题他答得挺好：没白干，我比纯应届生更知道线上是什么样子，写的东西会先想会不会把集群搞挂。 主管后面点头了。
结果：定级 D3，base 南京，云计算方向，已入职。
这里我要说个实话，也是这期最想写的一段。
他一开始是冲着 D4 去的——觉得自己三年工作经验怎么也该到 D4。结果出来是 D3，他当时挺失落的，还来问我能不能再谈。
我的解释是：定级看的是你在这个岗位上的经验年限，运维三年不等于开发三年。 你的优势是工程意识和排障能力，但开发岗的代码量和项目深度，是从现在开始算的。
他后来想通了，跟我说了一句我觉得挺清醒的话："能先进去做开发，比在外面再自学一年强。"
他自己总结的三句：

 想转开发，别等"准备好了"再投。他那个工具写到一半就投了，边投边补，反而比闷头学一年快

 项目不用大，但必须是你自己写的。面试问到底层，编的人一定会卡住

 定级没到预期别急着否定自己，先问清楚定级的依据，入职之后的表现比入职时的级别更重要
最后照例把门槛说清楚，免得白激动：OD 是社招，必须已毕业、有毕业证学位证（学信网可查），27 届和还在读的同学暂时投不了，等拿到毕业证再来找我。
我是帮他内推和准备的 HR，坐标科锐国际。Go/Java/C++/Python/测试方向都在招，产品线覆盖云计算、终端、计算（鲲鹏/昇腾）、海思芯片、数据通信、无线、光产品、云核心网、GTS、数字能源、智能汽车、2012实验室、质量与流程IT；base 有西安、深圳、东莞、杭州、南京、北京、上海、成都、武汉、苏州、长沙、济南十二个城市。定级按 D1-D5 走、对标大厂 13-17 级，看机考和面试表现定，不是一刀切。
运维、测试、实施想转开发的，我经手过不少，这条路径是走得通的，关键是你的项目怎么讲。把你的情况发评论区：学历 + 现在做什么 + 想转的方向 + 意向城市 + 是否已毕业，我看到会一条条回。不方便公开的私信我，报「姓名 + 方向 + 城市」，我帮你查在招岗位、看看大概能定到哪档。
