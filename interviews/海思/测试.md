## 软件测试面经-OD社招（手工测试三年，被自动化逼到墙角，机考185，定级D3）

来源：牛客网 ｜ 类型：面经 ｜ 发布：2026-11-06 ｜ [原文链接](https://www.nowcoder.com/discuss/948231346713849856)

【他们怎么上岸的 · 第 10 期】

 他打过来第一句话声音很低：" 我们组今年开始推自动化，我成了那个只会点页面的人。 "

 二本，东莞，一家做智能硬件的公司，功能测试三年。测试组五个人，他管 App 端和后台，每天点用例、提 bug、跟版本。

 去年公司上了自动化平台，他被派去写脚本——用别人搭好的框架，改定位、加断言、跑回归。他说得很实在：" 我不是不会写代码，我是只会照着别人的框架改。 "

 机考 185。 第一题做满，第二题字符串自己跑样例发现漏了个边界，返工一次；第三题图，只过一半用例。

 我问他为什么不往下写。他说："想十分钟没思路，先交了个能跑的，回头就没时间了。"

 技术面第一句："你怎么判断一个 bug 是前端还是后端？" 

 这题他答得最好，因为天天在干：抓包看请求发出去没有、响应对不对，再换个客户端复现，"请求都没发出去就是前端，发了但响应错就是后端"。

 第二问接口用例怎么设计，也顺：等价类、边界、异常参数、依赖顺序、重复提交。

 第三问把他问住了："你写的自动化脚本，怎么保证它不是在假通过？" 

 他答："看报告，全绿就是过了。"

 面试官没停："全绿就一定没 bug 吗？"

 他停了几秒，说：" 不一定。我们有过元素定位失效，但被 try 包住了，脚本不报错，报告还是绿的。 "

 "那你怎么改的？"

 "后来加了一条规矩：断言数不能为零，元素找不到必须抛。"

 后面还有一问，他说自己答得最差： "你会写代码吗？"

 他说"会一点"。面试官追："会一点是多少？"他卡在那儿，最后老实说："能读能改，从零搭框架我没做过。"

 后面主管面只问了一句"三年都是手工，来了跟得上吗"。他说这一年自己用 pytest 搭过一个小的，接口加报告，"就是太简陋，没好意思写进简历"。

 定级 D3，base 东莞，终端方向做测试。 

 三年手工给 D3，不算高也不算低。他自己说，最难受的不是档位，是那句"会一点"——说完就知道自己把话说小了。

 三句话留给你： 

 简历别写"负责 XX 模块测试"，写你拦下过什么。 哪类问题、什么影响、上线前还是上线后被发现的，这三样比"熟悉测试流程"有用一百倍

 被问会不会写代码，别说"会一点"。 分三档说清楚：能读能改 / 能写用例脚本 / 能搭框架。含糊的人，面试官一律按最低档记

 自动化最容易骗人的地方是"报告全绿"。 敢主动说"我们有过假通过、后来怎么堵的"，比背十条测试理论管用

 门槛说清楚 ：OD 是社招，必须已毕业、有毕业证学位证、学信网可查。 27 届和还在读的暂时投不了 ，机考都约不上；学历情况特殊的私信发我确认。

 （HR 收尾）科锐国际，做 OD 推荐和面试陪跑。方向全覆盖：云计算、终端、计算（鲲鹏/昇腾）、海思芯片、数据通信、无线、光产品、云核心网、GTS、数字能源、智能汽车、2012实验室、质量与流程IT；base 西安、深圳、东莞、杭州、南京、北京、上海、成都、武汉、苏州、长沙、济南十二城都在招。 测试岗主要落在终端、云计算、财经和流程IT 这几条线，深圳、东莞、武汉这边目前还有量。 定级按 D1-D5、对标大厂 13-17 级，年限、机考、面试表现一起看。

 如果你也在做手工测试、公司刚开始推自动化、心里有点慌 ，评论区发我： 做哪端测试 + 几年 + 会不会写脚本（能改/能写/能搭）+ 城市 + 是否已毕业 ，我一条条回，告诉你这段能往测开靠多少。

 不方便公开的 私信报「姓名 + 方向 + 城市」 ，我帮你看方向和大概档位。

 「测试/测开一面高频题 + 手工测试经历怎么讲成测开」 我整理了一份， 评论区扣 1 ，私信发你。

 这个系列还有 C++ / Java / Python / Go / 前端 / 算法 / 硬件单板 / 云计算 / 芯片方向的上岸复盘，见我主页专栏《他们怎么上岸的》。

## 秋招尾声，一点面试体会分享

来源：牛客网 ｜ 类型：面经 ｜ 发布：2019-09-30 ｜ [原文链接](https://www.nowcoder.com/discuss/353155630376624128)

教育背景 武汉地区211 硕士一枚，本科研究生都是双211， 专业-光学 ，意向求职岗位：光学岗或者硬件岗 

 2. 秋招结果 

 因为本人有点偏结果导向型，所以就先把目前秋招的结果放出来。目前还在等海思的开奖，也收到了TP LINK 的两方协议，所以极大可能是在这两家公司之间做出选择了。 

 TP-LINK 系统测试工程师（深圳岗） 已签两方 华为海思 硬件工程师-光技术岗 泡池子等开奖 舜宇光学 光学设计岗 （余姚）已拒 山东歌尔股份 光学设计岗 （潍坊） 大概率拒绝 大华股份 光学工程师 笔试未通过 海康威视 光学岗 一直简历复筛中 光迅科技 光学岗 一面未通过（委婉表示拒绝调到销售岗） OPPO VIVO 小米 （已凉， 研究生的方向是光纤，并非光学镜头相关，岗位不太匹配 ） 3. 秋招准备 

 （1） 岗位需求能力确定——实习 

 这里的意思并非要求大家一定要去做实习生，只是想说明一个了解目标岗位需求最便捷的途径，这也是今年自己4月份的惨痛经历换来的。、 
 

 我在4月份的时候投递了华为的实习生，有幸通过了笔试接到了面试通知，在面试之前也有了解过这个岗位的职责描述和能力需求，但面试的时候才发现自己所准备的方向和面试官所考察可岗位需求的能力并不是匹配的，以海思的光技术而言，实习（包括后面的优招）面试官都有考察我通信方面的基础，而我再实习准备期间，完全跑偏了方向。但正是这次实习面试的失利，让我了解到这个岗位所需求的是哪一方面的能力，所以在实习到优招的空档期，根据面试官考察的方向，狂补知识基础，最终临时通知优招的面试，但也顺利通过了三轮面试，成功进入资源池 😂 

 所以 实习生的面试对一部分不了解岗位需求的人来说，确实是一个很好很直接的途径，可以为接下来的秋招做准备 

 前提一定要了解清楚这个公司的实习和秋招的规定，如果实习不通过也不能投递秋招，那还是万万不要用实习来试水了。 

 （2）简历和面试 

 不要一份简历，秋招从头走到尾， 每个岗位所需求的能力都有不同，所以每次投递之前，一定要根据岗位的需求去适当的修改自己的简历，突出自己和这个岗位所匹配的能力。在面试海思时，因为我的项目中实验部分是和岗位不匹配的，但是理论仿真有一定的联系，所以在介绍项目时 有意识的去突出这个理论仿真的匹配度，或许会为面试加一点点分。 

 （3）专业复习 

 大家肯定都有各自的复习方法，所以这个就没必要展开说了，只是分享一下自己的想法。因为我读研方向和本科的方向相比太窄了，而求职又比较依靠本科的知识基础，所以我复习时，是先去了解各这个岗位需求哪几门基础，然后再复习时注重课程之间的关联和逻辑性，最后通过自己的理解，形成一个知识体系，虽然在面试时遇到自己不完全有把握的问题，但是因为有个知识体系在，所以可以从不同的方面去想问题，从某一个方面去得到启发。。总的来说还是一个知识的融汇贯通吧。。 

 
 

 以上是我目前秋招的一些心得体会，整体来说秋招最考验人的还是心态，尤其是身边的人offer一大堆，而自己颗粒无收的情况下。但自己一定要学会调整自己的心态，认真抓住每一次面试的机会。。 

 最后希望大家都能收到满意的offer，，当然也祝我自己能够等到海思开奖。
