## 击壤科技/文思海辉/盈灿科技/长亮科技Java社招面经分享

来源：牛客网 ｜ 类型：面经 ｜ 发布：2020-06-12 ｜ [原文链接](https://www.nowcoder.com/discuss/353156512342286336)

击壤科技

 
 

 
 面试过程： 

 
 1、简单地自我介绍； 

 
 2、问自己的优势是什么？ 

 
 3、询问项目经历有关内容； 

 
 4、问一些 redis 、 spring 的基础问题，还会问 hadoop 相关的东西是否知道，有没有使用过； 

 
 5、问 websocket 发送信息； 

 
 6、Linux如何查看 tomacat 是否启动？ 

 
 7、Spring的事务隔离级别和传播属性 Linux 的基本命令大数据框架。 

 
 

 
 

 
 文思海辉

 
 

 
 面试过程： 

 
 1、自我介绍后问了自己的工作经历，具体说出工作经历内容，最好细节到代码； 

 
 2、是否看过看过 spring 的源码？ 

 
 3、是否用过 docker 和 springCloud 这样的搭建微服务？ 

 
 4、spring的事务特性，什么业务场景用到事务控制； 

 
 5、Java垃圾回收机制，什么时候进行，如何进行检测内存泄漏； 

 
 6、tom的配置，性能参数设置还有一些 dubol redis 的东西。 

 
 

 
 盈灿科技

 
 

 
 面试过程： 

 
 1、自我介绍； 

 
 2、问一些 java 基础问题，是否用过 wicket ？ 

 
 3、有没有线程互联网金融开发经验？ 

 
 4、问到架构的相关内容以及思想以及对分布式的看法，说说分布式缓存和分布式服务集群的区别； 

 
 5、在之前工作是如何解决加工和分布式改进等； 

 
 6、还问到了 ArrayList 内部是如何实现的； 

 
 7、面向 aop 编程，谈谈你的理解 

 
 

 
 

 
 长亮科技

 
 

 
 面试过程： 

 
 1、自我介绍后问你是否可以接受出差； 

 
 2、问你一些常用的 java 知识， oracle 数据库， linux 或者 unix 系统常用的命令， oracle 数据中怎么建立函数； 

 
 3、说说 REDIS 怎么做延时队列，再问一致性哈希，问 JVM 优化和 JMM ，然后再自己实现一个红黑树； 

 
 4、问 jdk 的 currency 包源代码的内容； 

 
 5、Zookeeper是如何选举的，算法是怎么实现的； 

 
 6、Kaflka的 comsumer 是怎么设计的，如果让你来你该怎么设计； 

 
 7、你对工资的期望是多少。

## 校招火星时代科技/文思海辉php工程师面经

来源：牛客网 ｜ 类型：面经 ｜ 发布：2020-05-29 ｜ [原文链接](https://www.nowcoder.com/discuss/353156478926266368)

牛客上学到不少面经经验，搞一波反馈。 

 火星时代科技有限公司 

 一轮面试：只经历了一轮技术面； 

 面试官：技术主管； 

 l 做一个自我介绍； 

 l 简单讲述自己的技术优势； 

 l 说几种 sql 语句的优化方法（例如子查询换成 join 这种）； 

 l php 去重和交集的原生函数（ array_unique 和 array_intersect ）； 

 l mysql 两种引擎都是什么，有什么区别？ 

 l 简单介绍下 get 和 post ； 

 l 大量数据应该通过 get 还是 post ，为什么（ url 的长度限制）； 

 l redis 缓存相关问题； 

 l php 数据类型、强制转换什么的问题； 

 l 参与项目的经验，情景问题：假如项目遇到某个问题，要如何解决； 

 与主管闲聊了一段 … 

 

 文思海辉 

 两轮面试： 

 一面：面试官是技术部的负责人，主要是技术面； 

 l 简单的自我介绍； 

 l 简要谈自己项目方面经验； 

 l 简单说说自己的毕业情况以及是否在校获得过技术奖项； 

 l 手写代码的问题：涉及的类目有语言基础、设计模式、算法基础、数据库； 

 l javascript,mysql 语句， cookie, 等之类的问题。 

 二面： 

 面试：技术部负责人 +hr ，群面为主； 

 l 根据简历没人分别介绍自己； 

 l 每人五分钟讲述自己的项目经验细节； 

 l 项目方面：你认为你曾经做的某个小功能对你有什么影响，你为什么要做，你做了之后得到了什么？ 

 l 情景问答：一个项目问题，自己分小组讨论解决；（整个面试过程中附近都有人在讨论问题和方案）； 

 l 最后每人填一份关于薪资方面表格。
