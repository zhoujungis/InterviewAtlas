## 我是如何准备大模型算法岗面试的？

来源：牛客网 ｜ 类型：面经 ｜ 发布：2026-03-02 ｜ [原文链接](https://www.nowcoder.com/feed/main/detail/63aededb536044d783161a109f70c2fd)

很多人问我如何准备大模型的面试，分享下我的经验，针对两种情况：
1. 有大模型实习
2. 无大模型实习
针对无大模型实习的情况，我建议先找一段中厂实习为主，比如 zhipu、Minimax （当然有大厂进大厂）这些，相对容易进，尽量积累大模型实习经历。
针对有大模型实习的情况，复习内容为：
1. 常规八股（transformer、bert 等）
2. 最新八股（GQA 等）
3. 技术报告（一定要自己看原PDF，目前推荐 DeepSeekV3, R1, kimi1.5, Minimax-01, Qwen2.5, Qwen2.5-VL）
4. 手撕 Leetcode：Hot100
5. 手撕模型，比如 MHA 这些
首先是常规八股和最新八股，这一部分可以自己找找网上资料，整理好的，背。
然后是技术报告，目前推荐的内容有：
1. DeepSeekV3：必读
2. DeepSeekR1：必读
3. Kimi1.5：选读
4. Minimax-01：选读，据我所知最长上下文模型（外推到 4M，不过好像被 LLama4 的 10M 超过了）
5. Qwen2.5：必读
6. LLama3.1：必读
7. Qwen2.5-VL（如果简历有多模态内容）：选读
重点关注：
1. 阶段训练（预训练几段、Post-training 几段？上下文用了多少？数据配比是什么？）
2. 模型创新点（MHA 创新是什么？作用是什么？）
3. 上下文优化创新点（一般是优化显存和阶段训练）
4. 多模态优化创新点（简历有多模态内容）
5. 几个模型不同之处（比如 Qwen2 和 Qwen2.5 的不同之处）
最后是手撕，Leetcode 只刷 Hot100 够了，模型手撕建议关注（我目前会的）：
1. MHA
2. LayerNorm
3. Transformer Encoder (MHA+LayerNorm+FFN)
4. PE（绝对位置编码）
5. ROPE
6. SwiGLU
7. RmsNorm
每次面试前快速过一遍就 ok 了。 #AI面试问题分享#

4. 面试更重要的是讲好自己的项目。coding方面只要刷完hot100基本够用，八股大概了解原理够用，我没咋面过人才计划，但普通岗八股问不了太深，基本不会上升到具体的公式/通信量/显存计算上。自己的项目一是熟悉，二是要尽量用数字指标衡量自己每一个小工作的产出。

## 北京智源人工智能研究院2022校园招聘

来源：牛客网 ｜ 类型：面经 ｜ 发布：2021-09-10 ｜ [原文链接](https://www.nowcoder.com/discuss/353158475771486208)

公司招聘动态、名企内推、笔面试题库及面经攻略

 
 请认准2021名企校招日程汇总： https://www.nowcoder.com/school/schedule 

 
 

 
 公司简介

 
 
 智源（BAAI）是由北京市政府支持，由张宏江博士和多个业界大牛共同打造的世界级人工智能科学研究和产业孵化研究院。这里有黄铁军、唐杰、文继荣、陈云霁、孙茂松等100多名智源学者和青年科学家，有打造出全球最大、上万亿参数中文预训练模型的顶级团队，也孵化出了智谱华章、瑞莱智慧、灵犀云、上奇数科等一批新锐AI公司。这里还有每秒4万帧的脉冲视觉芯片、神经元仿真大模型等更硬核、更好玩的东西。
 

 
 招聘职位
 

 
 算法工程师
 

 
 岗位职责：
 

 
 1. 负责大规模预训练模型的优化；
 

 
 2. 负责大规模预训练模型的展示应用开发；
 

 
 3. 组织进行大规模预训练模型应用方案的实施、测试、验收。
 

 
 任职条件：
 

 
 1. 相关专业硕士及以上学历；
 

 
 2. 熟练掌握pytorch、tensorflow等深度学习框架；
 

 
 3. 对BERT、XLNET等预训练模型有深入研究，有大型预训练模型训练经验者优先；
 

 
 4. 具有较强的学习、分析和解决问题能力，可以迅速掌握业务逻辑并转化为技术方案，能够独立承担任务；
 

 
 5. 具有良好的团队协作精神和沟通能力；
 

 
 6. 在ACL、EMNLP、NAACL、AAAI等顶会发表过论文者优先。
 

 
 系统软件开发工程师
 

 
 岗位职责：
 

 
 1. 参与对现有类脑神经网络模拟系统的分析调研；
 

 
 2. 参与类脑神经网络模拟系统的架构设计；
 

 
 3. 负责类脑神经网络模拟系统的编程实；
 

 
 4. 4、查找及解决软件开发中存在的缺陷。
 

 
 5. 撰写相关技术文档
 

 
 任职条件：
 

 
 1. 熟悉Linux操作系统其及组件，对Linux内核有基本的了解和认识；
 

 
 2. 熟悉C/C++和Python，熟悉用CMake管理项目编译过程；
 

 
 3. 熟悉常用的数据结构和算法、熟悉多线程编程及多线程程序性能优化；
 

 
 4. 能够团队合作完成中大型分布式系统软件的设计实现，代码健壮性好；
 

 
 5. 至少熟悉网络、存储、内存管理、进程调度、异构计算的其中一项；
 

 
 6. 掌握git等代码管理工具；
 

 
 7. 谦虚好学，积极主动，责任心强。
 

 
 AI技术趋势行业研究员
 

 
 岗位职责：
 

 
 1. 跟踪研究预训练模型、深度学习、强化学习、AI算力系统等AI相关技术发展情况及趋势。
 

 
 2. 跟踪研究OpenAI、DeepMind、Mila等国际顶尖AI研究机构的研发布局及重大成果产出情况。
 

 
 3. 撰写专题研究报告，围绕AI技术发展热点问题或关键问题进行深度分析及解读，提出AI技术研发布局的相关建议。
 

 
 任职条件：
 

 
 1. 硕士及以上学历，本科为人工智能、智能科学与技术、机器人、电子、计算机、软件、通信、自动化等相关专业者优先；
 

 
 2. 对于AI技术的发展历程及主要技术领域有基本的了解，具有AI科研工作经验或者AI技术媒体报道工作经验者优先；
 

 
 3. 具有较强的研究分析能力、报告撰写能力和语言沟通能力；
 

 
 4. 具有良好的职业操守，工作积极主动，富有创新精神及较强的工作责任感。
 

 
 图形工程师
 

 
 岗位职责：
 

 
 1. 自研可视化引擎的设计与核心功能实现；
 

 
 2. 分布式可视仿真系统的性能优化；
 

 
 3. 面向生物数据的绘制引擎实现与优化。
 

 
 任职条件：
 

 
 1. 本科以上学历，图像处理.计算机视觉、机器智能、模式识别等相关专业；
 

 
 2. 良好的C++ 编程功底；
 

 
 3. 熟悉OpenGL / Vulkan / DirectX / D3D 等；
 

 
 4. 积极乐观，责任心强，工作认真细致，具有良好的团队沟通与协作能力。
