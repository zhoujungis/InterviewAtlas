## 大华 C++ 面经 总结

来源：牛客网 ｜ 类型：面经 ｜ 发布：2026-07-09 ｜ [原文链接](https://www.nowcoder.com/discuss/904740708769165312)

1. C++ 中引用和指针的本质区别是什么？工程里如何选型？ 

 答： 

 
 引用本质上是对象的别名，定义后必须初始化，且不能重新绑定到其他对象。

 指针是一个变量，保存地址，可以为空，也可以改变指向。

 引用在使用上更接近原对象，语法更简洁，不需要显式解引用。

 指针更适合表达“可能不存在”“需要重新指向”“需要指针运算”的场景。

 函数参数传递中，若只是访问对象而不改变指向，优先使用 const T& 。

 需要表示可选对象、动态创建对象、C 接口兼容时，优先使用指针。

 大华 IPC 项目里，配置对象、帧对象传参常用引用；驱动回调、第三方 SDK 接口常用指针。

 
 2. 什么是 RAII？为什么 C++ 项目里特别重要？ 

 答： 

 
 RAII 的核心思想是：资源的生命周期绑定到对象的生命周期。

 对象构造时申请资源，析构时自动释放资源。

 它能显著减少内存泄漏、文件句柄泄漏、锁未释放等问题。

 相比手动 new/delete 、手动加锁解锁，RAII 更安全、更稳定。

 智能指针、锁守卫、文件流类，都是 RAII 的典型应用。

 在长时间运行的 IPC 设备中，资源释放必须可靠，否则运行数天后容易出问题。

 工程上应优先让资源管理交给对象，而不是交给程序员记忆。

 
 3. 左值、右值、移动语义分别是什么？解决了什么问题？ 

 答： 

 
 左值通常表示有名字、可取地址的对象。

 右值通常表示临时对象或即将销毁的对象。

 右值引用用于绑定右值，配合移动构造和移动赋值实现资源转移。

 移动语义的核心不是“复制数据”，而是“转移所有权”。

 它能避免大块内存重复拷贝，例如字符串、vector、视频帧缓存。

 对于频繁传递缓冲区的 IPC 业务，移动语义能明显降低 CPU 和内存开销。

 工程上要区分“需要保留原对象”的拷贝和“原对象不再使用”的移动。

 
 4. 虚函数为什么能实现多态？构造函数为什么不能声明为 virtual？ 

 答： 

 
 含有虚函数的类会通过虚函数表实现运行时多态。

 基类指针或引用调用虚函数时，会根据对象实际类型决定调用哪个函数。

 这适合 IPC 项目中“统一接口、不同实现”的场景，例如不同码流源、不同编码器。

 构造函数不能声明为 virtual，因为对象构造过程中虚表尚未完全建立。

 如果构造函数 virtual，运行时无法正确决定该调用哪个构造函数。

 析构函数常常需要声明为 virtual，防止通过基类指针删除派生类对象时只调用基类析构。

 多态的价值在于解耦接口和实现，提高模块扩展性。

 
 5. override 和 final 的作用是什么？ 

 答： 

 
 override 用于显式声明某个函数是重写基类虚函数。

 如果函数签名写错，编译器会直接报错，而不是静默形成隐藏函数。

 final 修饰虚函数时，表示禁止子类继续重写该函数。

 final 修饰类时，表示该类禁止被继承。

 这两个关键字主要是增强代码可读性和编译期检查能力。

 在大型 C++ 工程里，它们能减少“以为重写成功、实际没有重写”的隐蔽 bug。

 对于平台层基类和业务层派生类，建议显式使用 override 提高维护性。

 
 6. 栈、堆、全局区、常量区分别存放什么？嵌入式 Linux 为什么要特别关注内存？ 

 答： 

 
 栈主要存放局部变量、函数参数和返回地址，空间较小，函数结束自动释放。

 堆主要存放动态分配对象，生命周期由程序员或智能指针管理。

 全局区和静态区存放全局变量、静态变量，生命周期贯穿程序运行过程。

 常量区存放字符串字面量和只读常量数据。

 大华 IPC 设备内存通常有限，还要同时跑采集、编码、网络、存储、Web 等模块。

 如果频繁在堆上申请释放大块帧缓存，容易造成内存碎片和 OOM。

 因此工程上更强调内存池、预分配、对象复用和可控的缓冲区上限。

来源：牛客网 ｜ 类型：面经 ｜ 发布：2020-05-10 ｜ [原文链接](https://www.nowcoder.com/discuss/353156422546432000)

浙江大华股份 

 一面 

 1. 首先是了解一下工作经历 

 2. 然后就是会让你说一下你的工作内容,以及用到的知识,会问几个问题 

 3. 然后会看你的笔试题,让你自己讲讲你为什么这样做,原因是啥,最后会拿出准备好的面试题来问你,然后就结束了 

 二面 

 问一些堆栈啊,linux GCC啊等等的 

 

 
 

 青岛麒龙文化有限公司 

 一面： 

 1. 面试官首先让我做个简单的自我介绍 

 2. 然后按照简历问了一下我之前做的项目，遇到的问题等等 

 二面 ： 

 主管面，主管问的问题就相对来说会随意一些，但是更考验你是否对产品有过自己的思考和认识。 

 1、 询问家庭情况和住址等。 

 2、 当面提问关于本专业问题，并要求现场给予相关解答。 

 3、 对薪资的要求。 

 4、 未来的职业规划，入职后的规划。 

 5、从原单位离职原因和能到岗的时间。青岛麒龙文化有限公司环境不错。面试官也很nice，提问的问题我感觉并不太难，但很有针对性。 

 

 

 泰科电子公司（TYCO） 

 1. 先做题，基本都是c++为主，有理论，有编程 

 2. 面试官进来后，先看一下做的题，一道道讲一下，错在哪里，还比较客气的，又问了一些c++方面的问题 

 

 

 深圳震有科技 

 1. 笔试就是考一些c的基础题，比较简单 

 2. 再一道上机题 

 3. 最后两个技术面，谈一谈自己的工作经历 

 第二个技术面就直接简单得跟我谈了一下待遇问题，然后就没有人事面了。
