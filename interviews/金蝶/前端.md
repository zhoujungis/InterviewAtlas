## 中级前端开发工程师面试与简历准备指南

来源：掘金 ｜ 类型：面经 ｜ 发布：2026-06-24 ｜ [原文链接](https://juejin.cn/post/7654602408578318362)

中级前端开发工程师面试与简历准备指南

 作为中级前端开发工程师，您的核心竞争力应从“能写出功能”转变为“写得更好、懂得原理、能解决复杂问题、有工程化思维”。

 一、 简历准备方向

 
 突出项目影响力（STAR法则）： 
 
 Situation（情境） & Task（任务） ：业务背景是什么，面临什么问题？

 Action（行动） ：你具体做了什么？（不要只写“使用 Vue 开发页面”）

 Result（结果） ：带来了什么价值？（性能提升了 XX%，首屏时间缩短了 XX 秒，封装的组件库被 N 个项目复用，降低了开发成本等， 必须量化 ）。

 

 技术栈匹配且明确： 
 
 精通（深入理解底层原理）：1-2 项（如 Vue3/React, JavaScript/TypeScript）。

 熟练（能独立完成复杂开发）：常用的生态库（Pinia/Redux, Webpack/Vite, Node.js）。

 了解（有实际项目经验）：Electron, 小程序, 跨端框架等。

 

 展现“中级”特质： 
 
 强调你在 性能优化 、 工程化建设（CI/CD, 脚手架, 组件库） 、 复杂状态管理 、 重构遗留代码 方面的经验。

 如果带过新人或主导过 Code Review，一定要写上。

 

 
 二、 面试准备方向

 1. JavaScript 核心底座

 
 执行机制： Event Loop（宏任务、微任务）、执行上下文、作用域链、闭包。

 原理与手写： 防抖/节流、深拷贝、Promise（A+规范）、发布订阅模式、Ajax/Fetch 封装、数组扁平化等。

 ES6+： Promise 核心机制、Async/Await 原理、Generator、Proxy/Reflect、Map/Set 区别。

 
 2. 框架深度（Vue 或 React 选其一深入）

 
 Vue： 
 
 响应式原理（Vue2 Object.defineProperty vs Vue3 Proxy ）。

 Diff 算法及 Key 的作用。

 生命周期原理、组件通信方式及适用场景。

 Composition API 与 Options API 的本质区别及优势。

 

 React： 
 
 Fiber 架构、时间切片、Lane 优先级模型。

 Hooks 原理及闭包陷阱。

 Diff 算法、Reconciliation 过程。

 状态管理方案的横向对比。

 

 
 3. 前端工程化

 
 构建工具： Webpack 核心概念、Vite 为什么快（ESM 机制）、Babel 编译原理。

 优化能力： Webpack 构建提速、产物体积优化、Tree-Shaking 原理。

 规范与部署： Git Flow、ESLint/Prettier 配置、CI/CD 流程、Docker 基本概念。

 
 4. 计算机网络与浏览器原理

 
 网络： HTTP 1.1 vs 2.0 vs 3.0，HTTPS 加密原理（对称+非对称），TCP 三次握手四次挥手，常见状态码，缓存策略（强缓存、协商缓存）。

 浏览器： 从输入 URL 到页面渲染完成发生了什么？重绘与回流的区别及优化。浏览器的垃圾回收机制（V8引擎）。

 
 5. 架构与设计模式

 
 常见设计模式在前端的应用（单例、观察者、发布订阅、策略、代理）。

 前端架构演进（MVC -> MVP -> MVVM）。

 微前端方案及适用场景。

 
 三、 综合建议

 
 刷透面试题： 找一份高质量的面试题库（如《前端面试宝典》或大厂面经），不要死记硬背，要理解其背后的设计思想。

 回顾项目： 面试官一定会针对你的简历项目深挖。把简历上的项目拆解，准备好“遇到的难点”和“解决方案”。

 保持技术敏感度： 了解行业最新动态（如 Web Components, WebAssembly, AI 辅助编程），能在面试中作为加分项提出。

 前端面试 = “原理+手写+场景+项目”

 四维考核：基础深度、框架理解、工程能力、项目亮点

 备考四步走：①基础扎实→②框架吃透→③工程化实战→④项目复盘，环节漏一个，offer 远一寸

 ——— 🔥 前端基础三大核心 ———

 JavaScript 核心：事件循环、闭包、原型链被称为“金三角”，必考。闭包要会解释作用域与内存泄漏，Event Loop 要能手写宏任务/微任务执行顺序，原型链继承需能对比 Class 与原型写法的差异。

 CSS 布局与渲染：盒模型、BFC、Flex、Grid 必须烂熟于心，响应式设计需掌握 rem/vw 适配方案，动画性能要能说出 Composite 与 Layer 优化。

 浏览器与网络：从输入 URL 到页面渲染的完整流程必背，HTTP/1.1 与 HTTP/2 的区别、缓存策略要能画图说明，跨域方案不少于三种（CORS、Proxy、JSONP 原理与局限）。

 ——— 🛠 框架三板斧 ———

 
 
 React 核心：虚拟 DOM 与 diff 算法、Hooks 原理（闭包与链表存储）、Fiber 架构与并发模式。面试常问 useEffect 依赖管理、useMemo/useCallback 性能优化，以及 Redux/Mobx 状态管理选型理由。

 
 Vue 核心：响应式原理（2.x 的 defineProperty 与 3.x 的 Proxy）、依赖收集与派发更新、编译过程（模板 → AST → render）。Vue 3 组合式 API 与 React Hooks 的异同常被拿来对比。

 
 框架通用考点：组件通信方案大全、SSR 实现与优劣、前端路由原理（Hash 与 History 模式），以及如何设计一个可复用的高阶组件/指令。

 
 ——— 📦 工程化与性能 ———

 
 
 性能优化指标：LCP、FID、CLS 等 Web Vitals 要懂含义与优化手段。实践中需列举图片懒加载、代码分割、接口缓存、CDN 优化等案例，最好带上项目数据（如首屏加载从 3s 降至 1.2s）。

 
 前端安全：XSS 与 CSRF 的攻击原理与防御方案必考，CSP 内容安全策略、HTTPS 双向认证等进阶点也常出现在大厂面试。

 
 ——— 💡 面试回答策略 ———

 
 
 原理题：先讲核心思想，再展开流程，最后联系业务场景。例如：“Vue 响应式是通过依赖收集实现数据驱动视图，在组件初始化时递归遍历 data，用 Observer 转为响应式对象，同时创建 Dep 收集 Watcher，数据变动时触发视图更新。”

 
 场景题：遵循“分析 → 方案 → 优缺点”三步。如“如何实现一个无限滚动列表？”，可答监听滚动 + 分页加载、虚拟列表优化、以及各自的内存与体验权衡。
