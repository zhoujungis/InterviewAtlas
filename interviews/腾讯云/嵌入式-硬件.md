 static 关键字的作用？ 
答：修饰局部变量：延长生命周期，只初始化一次；修饰全局变量：限定作用域为本文件；修饰函数：函数仅本文件可调用；类内 static 成员 / 方法属于类，不属于实例。

 程序代码内存分哪些区？ 
答：栈、堆、全局 / 静态存储区、常量区、代码段。栈由系统自动分配释放；堆手动 malloc/free；全局区存放全局、static 变量；常量区存放字符串常量；代码段存放程序二进制指令。

 acid 是啥？ 
答：ACID 是数据库事务四大特性：原子性、一致性、隔离性、持久性。原子性事务不可分割，要么全成功要么失败；一致性保证事务前后数据合法；隔离性多个事务互不干扰；持久性事务提交后数据永久保存。

 内存泄漏是什么，怎么排查处理？ 
答：内存泄漏是堆内存申请后没有释放，程序持续占用内存。排查工具 Linux 可用 valgrind，Windows 使用相关内存检测工具；编码层面成对使用申请释放接口，智能指针管理堆内存，避免中途 return 跳过释放逻辑。

 对 C++ 容器有哪些了解吗？ 
答：分为序列式容器 vector、list、deque；关联式容器 map、unordered_map、set、unordered_set；容器适配器 stack、queue、priority_queue。底层实现各有差异，根据场景选用。

 先进先出的队列有哪些？ 
答：普通 queue 适配器底层可以用 deque/list；还有环形队列，多线程下可以使用阻塞队列。

 讲讲数据库相关知识？ 
答：包含事务 ACID、索引、SQL 语句、锁机制。索引用来加速查询，B + 树是 InnoDB 索引底层；分表分库优化大数据场景，同时存在乐观锁悲观锁控制并发。

 说说常见的数据结构有哪些？ 
答：数组、链表、栈、队列、哈希表、树（二叉树、B + 树）、堆、图等。不同结构适配查找、插入删除等不同场景。

 网络编程相关知识，DNS 是什么？TCP 和 UDP 区别？ 
答：DNS 域名解析，把域名转换成 IP 地址。TCP 面向连接、可靠传输，有握手、确认、重传机制；UDP 无连接，不可靠，开销小，适合直播、DNS 这类场景。

 vector 相关知识？ 
答：底层是连续数组，支持随机访问；有 capacity 容量和 size 大小，capacity>=size；扩容会重新开辟内存、拷贝元素、释放旧空间，会迭代器失效。

 vector 为什么访问速度比较快？ 
答：底层内存连续，支持随机访问，CPU 缓存命中率高，寻址简单，O (1) 访问。

 vector 和链表 list 对比？ 
答：vector 连续内存，随机访问快，中间插入删除开销大；list 双向链表，内存不连续，随机访问慢，任意位置插入删除只需要修改指针，不需要移动大量元素。

 讲讲哈希相关内容？ 
答：哈希函数将 key 映射到数组下标；存在哈希冲突，解决方法有链地址法、开放寻址法。unordered_map 底层就是哈希表，查找平均 O (1)。
