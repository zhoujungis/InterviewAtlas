## 绿盟AI研发工程师一二面-面经

来源：牛客网 ｜ 类型：面经 ｜ 发布：2026-11-17 ｜ [原文链接](https://www.nowcoder.com/feed/main/detail/02005c06ed934bd293e40eda31517b4b)

一面
1.自我介绍
2.挑一段自己觉得印象最深刻的实习经历，说一下在这段时期里碰到的问题是什么，主要做了哪些工作，通过什么样的方式去解决这些问题
3.介绍一下传统 RAG 的流程是什么样的？
4.传统 RAG 存在哪些问题？要解决这些问题，目前有哪些主要的技术方向？
5.除了 Neo4j 这种知识图谱的结构之外，还有哪些其他的方式也可以去解决这个问题？
6.HTTP 这个协议。你可以介绍一下它是什么样的协议吗？比如它工作在哪个协议栈上，协议内容有什么，版本有什么区别，这些都可以说。
7.在 HTTP 协议上，如果要实现一个长连接的业务，有哪些方式可以实现？比如刚才 AI 的产品，它肯定也使用到了，它底层的技术是什么样的？
8.那你觉得为什么在 AI 场景下，它用的是 SSE 而不是 WebSocket 呢？
9.数据库事务有哪些基本特性？详细说一下这些特性分别是什么含义
10.介绍一下你了解到的数据库索引有哪些类型，以及数据库索引底层的实现方式是什么样的？
11.对于 InnoDB 这个存储引擎，为什么它会采用 B+ 树的方式来实现索引，而不是像红黑树、B 树或者跳表这些结构？这些结构在这个场景下会存在什么问题？
12.那跳表这个结构呢？为什么没有用跳表这个结构来存储呢？
13.比如现在有一个 MySQL 查询特别慢，我应该怎么去分析是什么原因导致这个查询比较慢？
14.那假设我现在 EXPLAIN 发现它走的就是我们设计好的索引，但实际上它的查询还是很慢，这种情况下一般可能是什么原因导致的？
15.目前你使用到的 AI coding 工具是什么？然后目前生成的代码，在你所有项目或者工作代码里面大概占比会到多少？
16.你刚才提到了 SDD 的方式来规避 AI 的一些问题。第二个问题是在 AI 编码过程中，你还碰到了哪些其他的问题，然后你是通过什么样的方式来解决这些问题的？
17.像 subagent 这种方式你有用过吗？

二面
1.自我介绍
2.你主要用哪些语言？现在用 AI，前端也能写吧？现在还在实习吗？
3.问实习经历（直接开门见山问第一段devops平台开发的实习，和面试官做的业务比较相关）
4.你觉得一个 Agent 主要需要具备哪些能力？
5.对话压缩和断线恢复你了解是怎么实现的吗？
6.用滑动窗口做上下文压缩，不会丢失前面轮次的内容吗？
7.滑动窗口是每一轮都压缩，还是每花 10 个轮次再重新压缩？
8.你知道这个 checkpoint 里面分了哪些内容吗？
9.这个 state 本身运行时存在哪里？
10.运行时有一份 state，为了恢复，你在 Redis 里也有一份。你这个同步时机机制是怎么设计的？这两个 state 没有关系吧？
11.你了解 Redis 怎么做持久化吗？比如 Redis 挂了，你们的东西怎么办？
12.你们线上是怎么部署的？Redis 了解吗？
13.这两个 Agent，你开发的代码最后怎么发布到正式环境的？可以介绍一下。
14.怎么解决发布冲突？
15.你们的分支是怎么管理的？
16.那有可能几个人都在开发功能，我这个 dev 上有几个人的功能，测试了其中一个，这怎么办？
17.你提交合并、上线了，那现在的 dev 分支和其他人的开发分支，你们需要怎么处理？
18.你比较喜欢用什么？现在用什么 AI 工具和模型？
19.那你们是每个人限额，还是怎么限额？
20.了解python的携程吗？
21.你们大概了解 Python 的协程切换是怎么做的吗？
22.FastAPI 里面，比如做一些外部调用需要注意什么，了解吗？
23.你们现在用 AI coding，AI 会输出技术方案、代码，你们看了之后怎么评估它是否 OK、合理，怎么修改？
24.怎么保障服务发布之后能快速响应用户的反馈需求？从稍微大一点的点考虑。
