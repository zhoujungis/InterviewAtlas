## 米哈游 平台研发-游戏运维 面经

来源：牛客网 ｜ 类型：面经 ｜ 发布：2026-09-08 ｜ [原文链接](https://www.nowcoder.com/feed/main/detail/be1ee2369e5b4536b4bc5e47c8463c9e)

#牛客AI配图神器# 码一下JD，注意，米米的游戏运维，业务运维，运开都是非常不同的，注意区分

工作职责
1. 负责游戏服务器及相关基础设施的部署、发布、监控、巡检和日常运维，保障游戏稳定、高可用运行。
2. 参与游戏上线、版本发布、扩缩容、故障处理等运维工作，持续提升发布效率和服务稳定性。
3. 参与云原生平台建设，学习并实践 Kubernetes、Docker 等容器技术，协助完成游戏业务容器化部署及平台运维。
4. 参与 CI/CD、自动化运维平台建设，通过脚本开发和工具建设减少重复劳动，提高运维效率。
5. 参与监控告警体系建设，使用 Prometheus、Grafana、ELK/Loki 等工具，持续优化监控、日志分析和故障定位能力。
6. 协助分析线上故障及性能瓶颈，参与应急响应、问题复盘及稳定性优化，推动系统持续改进。
7. 学习并参与网络、存储、数据库、中间件等基础设施的维护与优化，为游戏业务提供稳定可靠的运行环境。
任职要求
1. 应届本科及以上学历，计算机、软件工程、网络工程、信息安全、通信等相关专业。
2. 扎实的计算机基础知识，了解操作系统、计算机网络、数据结构等基础课程。
3. 熟悉 Linux 操作系统、shell脚本，能够熟练使用常见 Linux 命令完成日常排查。
4. 熟悉 TCP/IP、HTTP、DNS 等网络协议，具备基本网络问题分析能力。
5. 至少掌握一门编程语言，包括但不限于 Go、Python、C/C++。
6. 具备良好的逻辑思维能力、学习能力和沟通协作能力，对技术有持续学习热情。
加分项
1. 熟悉阿里云、腾讯云、AWS 等公有云产品。
2. 有 Linux、Go、Python、Kubernetes、云计算等相关项目经验。

面经在下面：

基本信息

1. 请简单自我介绍，并说明主要技术栈。

编程八股与 Linux 基础

1. 线上系统的内存持续上涨且不下降，排查思路是什么？

2. 常见的内存泄漏类型或开发场景有哪些？

3. 如何理解 Go 的 GMP 调度模型？Python 的多进程和多线程是否使用过？

4. Linux 中进程和线程有什么区别？为什么需要线程？

5. 进程从创建到退出通常有哪些生命周期状态？

网络基础

1. DNS 常见的解析记录类型有哪些？

2. A 记录和 CNAME 记录有什么区别？为什么不直接使用 A 记录？

3. DNS 使用什么传输层协议？53 端口对应什么协议？UDP 和 TCP 分别用于哪些场景？

4. ICMP 和 ARP 分别位于哪一层，解决什么问题？

5. VLAN 是什么概念，主要工作在哪一层？

6. 静态 CDN 和动态 CDN 有什么区别？

7. Anycast 是什么？Anycast 如何选择流量入口？

8. BGP 和 OSPF 有什么区别？

容器与 Kubernetes

1. Docker 底层的 cgroups 和 namespaces 在容器中分别解决什么问题？

2. 容器中的 PID 1 是什么？有什么特点？

3. Kubernetes 的 Pod 中多个容器默认共享哪些 namespace？哪些 namespace 默认不共享？

4. 一个 Kubernetes 集群的主要工作组件有哪些？

5. kube-proxy 的工作机制是什么？有哪些常见工作模式？

6. Linux 如何查看主机路由表？

7. iptables、IPVS 和 Linux 路由表分别解决什么问题？

8. 集群中的一个 Pod 访问另一个 Service 时，数据包大致经过什么路径？

9. 如果目标 Pod 位于其他节点，数据包路径会有什么变化？VXLAN 封装中的内层包和外层包分别是什么？

故障排查与基础设施工具

1. 介绍一次实习中排查过的比较深刻的问题或故障。

2. 使用过 Terraform、Argo CD 等基础设施工具吗？
