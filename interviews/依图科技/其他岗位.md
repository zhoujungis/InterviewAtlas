 T2

 
 从前有一扇秘密大门，打开大门的口令记录在一个数组中，为了破解其中的奥秘，需要找出数组内重复次数第二多的小写字母及其出现的次数。

 
 输入描述

 
 输入一个任意长度的字符串数组

 
 输出描述

 
 输出数组内重复次数第二多的小写字母及其频次，输出形式为:字符-频次

 
 示例

 
 输入：
['abaabbbabbddddfew1','abbbAAwe123','45dipopg#$@']

输出：
a-5
 
 输入：
['qwe','qwe','qwe']

输出：
ERROR
 
 题解

 
 import java.util.HashMap;
import java.util.Map;
import java.util.Scanner;

// P2
public class Main {
 public static void main(String[] args) {
 Scanner in = new Scanner(System.in);
 Map cntMap = new HashMap<>();
 while (in.hasNext()) {
 String next = in.next();
 for (char c : next.toCharArray()) {
 cntMap.put(c, cntMap.getOrDefault(c, 0) + 1);
 }
 }

 char c = '_';
 // max1 次数最多， max2 次数第二多
 int max1 = 0, max2 = 0;
 for (Map.Entry entry : cntMap.entrySet()) {
 int cnt = entry.getValue();
 if (cnt >= max1) {
 max2 = max1;
 max1 = cnt;
 c = entry.getKey();
 } else if (cnt > max2) {
 max2 = cnt;
 }
 }

 if (max1 != max2) {
 System.out.println(String.format("%c-%d", c, max1));
 } else {
 System.out.println("ERROR");
 }
 }
}

 先介绍自己，美国留学，找工开始的时间是9月份，其实已经是非常晚了，然后连续两个月的寻找，十分的不顺利，于是在10月底发了上面的帖子。那时候的我，已经有点开始放弃秋招，准备春招了。 

 
 

 于是沉沦了一个月，吃吃喝喝玩玩，放松下身体的同时，也收拾心情再度出发了，12月，开始继续投简历，接面试，先后接了腾讯，华为，字节，依图，vivo等公司的面试，下面是结果： 

 12月vivo面试纯聊天，没过； 

 12月依图两面技术面，拿到offer； 

 12月底腾讯过了一面后没消息； 

 12月底华为过了所有流程，至今仍然等offer； 

 1月初字节三面，拿到offer，打算去。 

 
 

 我觉得我的基础知识和算法水平在这期间其实并没有一个大幅度的提升，但我的心态确实变了，依旧对于找到一份好的工作有压力，但焦虑感下降了，每天刷题，补充基础知识，对于面试也随着面试场次的增加也更加得心应手，所以接下来是总结，不一定对，但如果有可取之处，能帮到找工作的各位，那真是不胜荣幸。 

 
 

 1、保持一个良好的心态。对于找工作这件事，一定要明白的是， 岗位一定是会有的，只要自己努力的去争取，一定能找到一份理想的工作 。在电脑前看这篇帖子的各位，我希望大家对于各种论坛有一个良好的认识，知乎，脉脉，牛客网，一亩三分地，上面的言论能反应一部分的现实，但有些时候是不全面的，切忌不要因为某些言论而过度失落，要保持一个良好的心态。总的来说， 少看分享，多看面经。 

 2、打铁还需自身硬，不仅要打好基础，还要刷好题，毕竟好的薪水还是需要实力相匹配的。 

 3、不要放弃，你不尝试就永远没有机会，失败了好歹还能收获经验呢。 

 4、有时候没理由的被刷，就单纯的当做运气不好吧，多试试，总有运气好的时刻 😁

## 依图科技-项目管培生

来源：牛客网 ｜ 类型：面经 ｜ 发布：2018-09-11 ｜ [原文链接](https://www.nowcoder.com/discuss/353154534631481344)

依图科技-项目管培生
 前一天晚上十一点打电话通知我第二天早上九点多去面试，就在学校里面的一个奶茶店，位置比较小。形式是一对一。 

 我面试的岗位是项目管培生，之前完全没有相关的经历，也没有什么写代码的经历，看了一下人工智能的行业发展、公司的简介就去了。 

 直接面了两轮。 

 第一轮是一个年轻一点的项目经理面试的，主要是针对简历问的。 

 所以是自我介绍，问了问我本科学法学双学位的事情（有什么体会，能不能举出具体的事例），问了问我在华为实习期间（实习是技术岗）的工作，有什么技术指标，画图讲解； 

 问了问之间参加创业比赛的经历，主要是碰到的问题、和别的获奖作品的差别在哪里，为什么没有克服这些问题、主要扮演的角色是什么； 

 问了工作时间996能不能接受（我估计不止996）； 

 情景假设: 如果我现在已经是项目经理了，要我去推广我们的产品，会先做哪些准备； 

 问如果进了公司以后，发现面对的情况、工作的内容和想象中很不一样，可能低于我的预期，会怎么做 

 怎么知道依图这个公司的，对依图有什么了解； 

 对项目经理这个岗位有什么了解嘛，知道是做什么的吗； 

 问了问我在华为实习的部门结构，分别什么工作，上下游接触的人分别是哪些，有没有碰到那种很难缠很难沟通的，是怎么处理的； 
 

 然后我提了几个问题就结束了，接下来就是让我等二面。 

 
 

 第二轮是一个经验更加丰富的项目经理，基本跟简历无关了。 

 先问我为什么选择这个岗位，我说觉得自己沟通能力好；hr就很开心问我怎么说，还让我说说具体事例； 

 问我有没有过项目管理的经历，我说没有，然后hr就问我那我对项目经理的理解是什么样的，我就说其实我们搞科研也是管理项目blabla，然后hr就说“对所以生活中处处是项目，不要说自己没做过项目”（这个大家要注意）
 

 然后问项目需求的确立（大概这个意思），比如有十个客户都有需求，而公司的经费只够满足六个客户的需求，怎么抉择，考虑哪些因素； 

 问了问校园工作的经历，主要工作内容；
 

 说碰到比如说开发人员不合作的时候，要怎么去沟通，怎么确定你的项目能保质保量地完成； 

 问应届生们（或者就是问我）找工作会考虑哪些因素（注意！这里处处是坑，你说一个点，他就说针对这个点继续问下去） 

 薪资要求、工作地点等等问题啦 

 最后还问了我这一年我有没有时间去实习。 

 
 

 大概就这些吧，然后现在等结果ing

## 依图科技面经分享

今天我在一天内去面了两家公司，出乎意料的都当场拿到了offer，因为之前一个offer都还没有，今天应该算是十分具有意义的一天,所以回来打算新开一贴。之前的一系列面经转 
 https://www.nowcoder.com/discuss/24900 

 
 约的上午9点半面百姓网，下午2点面依图科技，虽然百姓网现在没落了，但有机会去涨涨面试经验还是可以的，面试官也没让我失望，出了一些有意思的题，下面分享一下。 

 因为早班车堵车严重，我9点50才到，首先进行感觉这公司好多女员工。 

 一面面试官拿着我的笔试试卷和简历进来，依个问我做错的题。首先是最短路径算法你理解哪些？答：floyd, dijkstra,
 bellman-ford,spfa
 ，分别适用什么场景？答：除了floyd是计算两两最短路，其它都计算单源最短路径。复杂度各是多少？答：一堆分析。然后让我把笔试中写的复杂度过高的一题再重新优化了一下。 

 两道概率题： 

 1. 一个人在沙漠中车抛锚了，已知每天有车经过的概率是60%，问他在前8个小时获救的概率是多少？ 

 2. 扫雷游戏： 在一个局部的情形中，点开了1和2，X表示未知，问A,B,C,D中哪一点是雷的概率最大？

 X X X X X 

 A 1 B 2 C

 X X D X X

 两题我都没答对，承认我的概率论学的真心不好。后来面试官给我讲了解法，豁然开朗。 

 
 一道codeForces原题(我没做过)：从N个数中可放回的抽取B次，问B次取出的数的和被X模余K的方法总数是多少，N<50000,B<10E9,K<X<100 

 这题我在5分钟内写出了递推式并给出了快速幂优化后的时间复杂度，面试官很满意。 

 
 二面面试官主要跟我聊简历上的几个项目，他好像不能理解词向量的形式，反复解释了很多遍，问的问题都比较简单，有TF-IDF,余弦相似度，分词工具等等。 

 
 

 
 面完已经12点多了，在全家随便买了个饭吃后直奔依图。到了感觉技术氛围很浓厚，工位是像网吧一样连成一排的，桌面上各种纸笔凌乱。被安排在咖啡厅面试，但因为面试官有事，直到下午2点半才开始，我都困得不行了，这里要感谢HR给我点了一杯冰拿铁提了提神。 

 一面面试官是个看起来就觉得很聪明的人，或者说长的很聪明的人，先问了问3个项目。因为我直说机器学习这块我正在恶补，他就说那就不问机器
 学习，直接出算法。

 第二题第一问也很简单：
 一个矩阵上每一点都有分值，从左上角走到右下角，只能往下或者往右，问走一遍能够取到的最大分值，简单DP一下。第二问比较有难度，问走两遍能够取到的最大分值，大概花费了15分钟才解出来，面试官很满意。 

 二面面试官看起来也蛮聪明，上来啥都不说直接出算法题

 我说了两个解法，但都是错的，因为还是用了随机函数。最后面试官说了解法，感觉trick痕迹太明显了，正常根本想不出来啊。
