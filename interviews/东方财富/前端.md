 经历

 秋招结束后，虽然零零星星有几场面试，但其实都不太满意，感觉要翻盘春招必然要有一段更好的实习。当时未与深信服签约，最终选择了汇川。虽然汇川 HRBP 要求我提前去苏州实习，但我觉着往返学校太麻烦了，还不如就近在广东找一份过渡的实习。 随后求职了一个月，一通过面试就去实习了。

 

 早上实习通勤看到的🌈

 入职后才发现，做的是偏大数据的项目。当时正忙于应对多个面试，实在分身乏术，也没想着找下家。领导曾问我要不要转平台开发，可惜我未接受——如今想来，转的话能学到更多的。所幸 MT 极为尽责，不仅详细讲解系统架构，还主动帮我修改简历，非常感谢他。期间感觉欣喜的是宁波通商给了次免费旅游的机会，所以爽爽玩了几天。

 

 

 随后就是拼多多的客户端面试，当时可是拼了全力去准备，跟朋友说出这是“双非的最后一舞”，但没想到惨败于三面手撕。再之后就是广州汇丰的补录，当时可是高兴了很久很久，甚至脑袋一热跟 MT 说了这件事。他也为我着想，觉得实习的这家公司不适合我，走下坡路了，确实不该留在这儿的。但当我冷静下来搜索了相关资讯后，发现汇丰不适合我，想躺又不能完全躺平想卷又卷不动，只能马上重整旗鼓，整理了项目和简历，在二月底辞职了实习准备春招。

 离职后 MT 跟我说，他都想去汇丰躺平了[笑cry][笑cry][笑cry]

 随后就是春招一系列的面试，这时候因为有了第二段实习和八股场景背 得 更加娴熟，基本面试都能走到最后，手撕好几场都是 DP，也是轻松拿下。感觉这个时候面试比秋招的水平提升了不少。期间要去东方财富线下三面，因为报销就去了。

 

 很明显感受到，春招比以往开的更早，2月就开了，4月基本就结束了，我的春招在4月底也画上了句号。

 感想

 这篇总结其实老早就想写了，与上次的秋招过去就半年。发生了各种各样的事情，这个时候都心态其实和当初已经不太一样了。

 2月底，我来到学校办公室，负责就业的老师就跟我聊天吹水，说整个计院的就业情况非常不明朗；还给我看了校招三方管理系统的数据，凑近一看，我也认同了。如今春招已接近尾声，应该有所好转。

 整个学院的数据这里不能列出来，但单以“身边统计学”来说，这届 ACM 校队就业的同学的年薪也是从 20 w 到 40+ w 浮动，不谦虚地说，这是我们学校比较厉害和自律的同学了，但这小部分人完全说明不了什么。我所在班级中，有人找不到工作；有人转行从事技术销售、运营、技术支持等岗位；有人入职外包公司；也有人进入常规的软开公司，薪资在 9 k 上下浮动。

 宏观的视角，我个人是讲不出啥的，转回个人感受吧。在近些时候，比较——或者说攀比——这个事情变少了，只是觉得身上担子重了不少，虽然我还没毕业独立，但快了。有两件事情感触很大：

 一是就业，我跟我实习的第一家小厂的同事经常联系，公司因为项目收益不好，逼走了很多人。同事早早做好准备，找了大半年，以五年经验都难以找到广东的 13 k 的前端开发，各种各样的原因：行情、起薪、学历、工作经历，连约面都少之又少。

 二是家庭，家里并不富裕，父母都是打工挣的辛苦钱，把我和姐拉扯大。那天父亲跟我说，“到时候你出到社会，开支就得自己担着了，我跟你妈都退休了要”。近来家里发生的一些变故，让满头白发的父亲的背弯了又弯，他把我送到车站前，跟我说了家里很多的事情，他和母亲都很爱我，问我毕业了还回来吗，让我不要顾虑他们，让我自己在大城市要争气、照顾好自己、一定要吃好吃饱，怎么尽是些唠叨的话……写到这里，眼泪止不住地又掉了下来……

 家长里短的事儿就不说了，只是当个人记录吧。各位牛友如果在秋招没有满意的 Offer，可以尝试再去一个比较好的实习作为铺垫，11、12月其实基本没什么面试，有也请假就好了，回来再战春招其实还是有机会的。

 以我的经历就可以参考，再比如我的好友@已经不能更加糟糕了(34324661)秋招一直没什么面试，故去初创公司转正实习做保底（转正还被压价），实习到2月后也开始春招，近些天他也取得满意的 Offer——招银科技、深信服、小米汽车——由衷地为他高兴。

 ﻿﻿ 

 感谢各位能看完这一篇总结，其实都不能算总结，只是一篇流水账而已。牛客和各位牛友真的帮助了我很多，无论是面经还是提问回答，非常感谢各位，认识了不少的朋友在这里，好些熟悉的面孔都没再活跃了，这是好事。

 那么在最后，祝愿大家都有满意的 Offer 和顺遂的未来！

 面试通用

 自我介绍

 强烈建议在面试之前准备一份自我介绍，其中要包含工作经历、简要的项目描述、职责描述、个人技术栈以及个人优势等内容（重要性就不多介绍了）。

 
 tips：自我介绍要根据具体面试情况而不断调整、优化

 
 项目难点

 因人而异，建议面试之前提前构思清楚项目难点，并做适当衍生。

 举个例子：

 面试官：看到你简历上写了有做过性能优化，可以讲讲你知道的其他方式吗？如果现在去看还有哪些方式可以完成目标？

 类似这种问题，如果提前做了准备，那基本上可以说是手拿把掐了。

 最近在学习什么

 实话实话，同时做好面试官衍生问题的准备，这一部分重点在于告诉面试官你的学习方向和个人对于学习新技术的动力。

 如：Wasm、Turoback等等..

 
 温馨提示：没时间学习的话，建议不要去强答，否则撞上对口的面试官会死的很难看

## 渣渣硕的秋招——前端开发入门及面试分享

来源：牛客网 ｜ 类型：面经 ｜ 发布：2021-11-19 ｜ [原文链接](https://www.nowcoder.com/discuss/353158953557237760)

整个秋招，还是参加了十几场面试，在牛客上看了不少面经，所以自己也记录了一些秋招面试题，希望能帮到别人。 

 前端开发入门： 

 我开始看前端相关的东西其实挺晚的，建议大家还是早一点。开始是看的黑马的一个 教程 ，主要是学习html和css的基础知识，讲的挺细的，但大家知道的，很多东西看完之后就忘得差不多了，动手敲才是真理，所以我觉得赶时间的话，可以看 晓舟报告 的视频，很棒的一个up主，他有介绍如何开始前端学习，从基础知识体系到框架，我几乎把他那一个系列视频都看完了。另外，js数据结构与算法（主要是应对笔试），推荐coderwhy的 视频 ，看他的 简书 也可以。建议大家边看前端相关的教学视频边练习力扣HOT 100，可以先把简单和中等的题刷了。 

 

 

 

 除了常见的八股文，其实在面试过程中最容易被问到的还是自己的项目，大家要对自己的项目有一个深入的理解，不能只是跟着教学视频敲一遍代码（我就是这样，接收到的知识都是浮于表面，所以结果不怎么好 😑 ），要多去思考。 

 面试题合集共享： 

 （1） 前端工程师自检清单及答案整理 

 （2） 一名【合格】前端工程师的自检清单 

 （3） 前端开发面试题 

 
 

 一些面试分享： 

 有些当时就记下来了，有些就不太记得了，大家见谅哈。 

 兴业数金： 

 1. 生命周期函数： 

 创建实例前后（ create ），模板渲染到页面前后（ mount ），更新数据前后（ update ），销毁实例前后（ destory ） 

 2. 插槽及种类： 

 

 slot 标签，将值插入到相应位置 

 种类：具名插槽、作用域插槽 

 l 具名插槽：一个组件中定义多个插槽，用属性 name 来区分 

 l 作用域插槽：子组件向父组件传值， slot-scope 

 

 

 字节一面： 

 1. 数据库的范式： 

 范式是符合某一种设计要求的总结； 

 要设计一个结构合理的关系型数据库，要满足一定的范式 

 第一范式（ 1NF ）、第二范式（ 2NF ）、第三范式（ 3NF ） 

 
 

 

 

 2. 浏览器请求的过程 

 （1） 首先对 url 进行解析，拿到域名字段 

 （2） 在浏览器缓存 / 本地 host 文件中查找对应域名的 ip ，若没有，则发起 dns 请求中查找 

 （3） 获取到域名对应的 ip 地址后，发起 tcp 连接， tcp 三次握手后 

 （4） 浏览器发起 http 请求，服务器回应 

 （5） 浏览器解析响应报文，渲染页面 

 （6） Tcp 四次挥手，断开连接 

 

 3. 进程间的通讯方式 

 管道pipe、消息队列MessageQueue、信号量Semaphore： 

 线程发生阻塞，忙等待的原因： 

 线程阻塞：被挂起，不占用 cpu （睡眠指令，执行了一个对象的 wait() 方法，等待相关的资源）；线程忙等：消耗 CPU ，一直在轮询某个变量直到符合条件 

 4. 发生死锁的必要条件：
