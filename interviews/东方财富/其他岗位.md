## 东方财富一面

来源：牛客网 ｜ 类型：面经 ｜ 发布：2026-04-27 ｜ [原文链接](https://www.nowcoder.com/discuss/878421437839699968)

东方财富一面

 是否做过后端，用过哪些后端语言 （我：做过一些，主用 Node.js（Express/Koa），也用过 Python 的 Flask，Java 的 Spring Boot 接触过但不深。数据库方面 MySQL 和 MongoDB 都用过，不过我的主方向还是前端，后端主要是配合项目开发。）

 nodejs、TypeScript、React 是否了解 （我：都比较熟。React 一直在用，函数组件和 Hooks 是日常，Next.js 也用过。TypeScript 最近的项目都有引入，泛型、工具类型这些都常用。Node.js 除了写接口，还在项目里做过 SSR 和中间件封装。）

 前后端区别 （我：运行环境不同，前端跑在浏览器，后端在服务器。关注点不同，前端侧重交互、渲染、响应式、性能；后端侧重业务逻辑、数据安全、高并发。技术上，前端主攻 HTML/CSS/JavaScript，后端语言选择更多。另外，前端需要适配多端，后端更看重服务稳定和扩展性。协议上，前后端通过 HTTP 这种无状态协议通信，状态一般交给前端或中间件维护。）

 常见的图片格式及区别 （我：JPEG 有损压缩，适合照片，不支持透明；PNG 无损压缩，支持透明通道，适合 UI 切图；GIF 支持简单动画但只有 256 色；SVG 是矢量图，放大不失真，能直接操作 DOM；WebP 同时支持有损、无损和透明，体积小，兼容性需注意；AVIF 压缩率更高，但解码性能在一些设备上还有问题。）

 svg 和 canvas 区别 （我：SVG 是保留模式，基于 XML 描述图形，每个图形都是 DOM 节点，方便绑定事件和 CSS 控制，适合交互不多但需保真缩放的场景。Canvas 是即时模式，通过 JS 在画布上绘制像素，依赖分辨率，图形是位图，无法直接给图形元素绑事件，但性能高，适合大量图形、动画和游戏场景。）

 echarts 是用什么实现的 （我：ECharts 4.0 之后支持 Canvas 和 SVG 两种渲染方式。默认用 Canvas，因为大数据量下性能更好；移动端或需要精细交互时可以用 SVG 模式，能够直接用 CSS 控制样式，核心是渲染引擎可以按需切换。）

 我看你用过 tailwindcss，有什么差别吗和一般的 css，有什么缺点 （我：Tailwind 是原子化 CSS，用预定义的类组合样式，不用自己起 class 名，设计系统的约束性强，配合构建工具还能摇树优化。缺点是 HTML 模板会变长，类名冗长，需要记很多缩写，样式和结构耦合在标签里，后期修改可能比传统 CSS 文件更琐碎。另外从原子化方案迁移出去的成本也较高。）

 jpg 和 png 和 gif 区别是什么 （我：JPEG 有损压缩，不支持透明，适合颜色丰富的照片；PNG 无损压缩，支持完全透明和半透明，适合 Logo 和需要保留细节的图形；GIF 最大特点是无损但只支持 256 色和简单帧动画，透明只有全透明没有半透明，所以动图容易失真且文件大。）

 jpg 有什么优点 （我：压缩率高，在可接受的画质下能把图片体积压得很小，非常适合网页和照片分享。兼容性非常好，所有浏览器都支持，解码速度快。对无需透明且色彩复杂的图片，JPEG 是默认选择。）

 介绍网络缓存 （我：主要分强缓存和协商缓存。强缓存通过 Cache-Control 或 Expires 头，未过期时浏览器直接用自己的缓存，不发请求；协商缓存需要发请求到服务器，用 Last-Modified/If-Modified-Since 或 ETag/If-None-Match 让服务器判断资源是否变化，304 就沿用本地缓存，200 则返回新内容。实际项目里常给静态资源设长时间强缓存，文件名加 hash 来实现更新。）

 图片懒加载 （我：现代方案用 IntersectionObserver 监听 img 元素进入视口，再将 data-src 赋值到 src 触发加载。传统方案是监听 scroll 事件，用 getBoundingClientRect 计算位置。现在也可以直接用原生 loading="lazy" 属性，注意兼容性。另外要注意占位图、防抖和提前量设置，避免白屏。）

 this 指向 （我：this 的指向由函数调用方式决定。普通函数谁调用指向谁，全局调用非严格模式是 window，严格模式是 undefined；对象方法指向该对象；构造函数指向新实例；箭头函数没有自己的 this，从外层作用域继承；call、apply、bind 可以显式绑定。实际项目里常用箭头函数来固定回调的上下文。）

 https 如何保证安全性 （我：核心是 SSL/TLS。握手阶段用非对称加密交换会话密钥，同时完成证书验证确保服务器身份；之后通信全用对称加密，效率高且防窃听；传输数据还带消息认证码防篡改。简单说就是身份验证、数据加密、完整性校验三层保护。）

 PC 端和移动端区别（ 我：屏幕尺寸和布局：PC 端多固定或弹性布局，移动端需要响应式、viewport 适配，常用 rem、vw/vh。交互上，PC 依赖鼠标键盘，有 hover 和精准点击；移动端依赖触摸、手势，需处理 300ms 延迟或使用 touch 事件，还要处理软键盘弹出等问题。）

 访问量大时的性能优化 （我：从几个维度。网络：使用 CDN、压缩资源、开启 gzip/brotli、合并请求、使用 HTTP/2。资源加载：图片使用 WebP 格式、懒加载，代码按需加载、三方库做 tree shaking。渲染：避免重排重绘、使用虚拟列表、骨架屏、防抖节流。缓存：合理设置强缓存和协商缓存，利用 Service Worker 做离线缓存。服务端可以进行 SSR 或 SSG，减少白屏时间。）

 手撕驼峰命名 （我：就是写一个转换函数，把 background-color 这样的短横线命名转成 backgroundColor。用正则匹配 - 后的字母转大写就行。）

 数组去重的几种方法 （我：传统的方法有利用 Set 去重最简单；也可用双层循环、indexOf 或 includes 去重；或者配合 filter 加 indexOf 判等；还可以利用 Map 键唯一或对象键值对去重。Set 是最常用的，一行 [...new Set(arr)] 就能搞定。）

 刚刚提到了验证码登录，那么如果在一个分布式系统中，http 请求是无状态的，在某个服务器上是登陆过的，那么如果下次请求在另一台服务器中执行了或者之前登陆过的服务器内存清空了宕机了，怎么避免重复登录呢 （我：如果用的是传统 session 机制，可以把 session 集中存储到 Redis 或数据库中，这样所有服务器共享状态，不会因为机器切换或宕机导致登录丢失。如果用的是 JWT，token 本身就是分布式的，服务端无需存状态，只要验证签名和有效期就行，天然支持多实例。实际场景中为了安全，可能还会配合 Redis 维护一个 token 黑名单或者实现双 token 机制来兼顾安全和体验。）

 XML, JSON 的区别？ （我：JSON 更轻量，数据体积小，解析快，键值对结构与 JavaScript 原生兼容，字段是双引号包裹的字符串；XML 标记语言，格式冗长，门槛高，但支持命名空间和更复杂的文档结构。数据交换场景 JSON 几乎已经取代 XML，但有些老系统或配置文件还在用 XML。）

 AJAX 是同步还是异步的？ （我：名字里的“A”就是异步的意思。虽然可以通过设置 xhr.open 的第三个参数为 false 改成同步请求，但会阻塞 UI 线程，几乎不推荐用。实际项目里 AJAX 都是异步行为，配合回调、Promise 或 async/await 来处理结果。）

 AJAX 的实现（ 我：基础实现是用 XMLHttpRequest，创建对象、调用 open、设置请求头、监听 onreadystatechange 然后 send。现在更常用的是 fetch，基于 Promise，调用更简洁，需要手动处理错误和超时。打包环境里一般直接用 axios 这类库，做了更完善的封装。）

 个人经历

 本人是普通双非本，从25年三月份开始实习，算是比较晚了，当时第一次准备面试，没有太多的面试经验，总想着把所有的八股都掌握了才开始面大厂，所以三月份暑期实习的投递根本不敢投大厂，害怕脏面评，回过头来才知道，勇敢的人先享受世界，越是大的公司约面，就越能激发你学习的动力，反倒是大公司约面的时候，我八股复习的效率更高，因为太想进步了，之前面作业帮的时候就把HTTP+TCP用两个小时就复习的七七八八了，而且大厂约面的时候你可以往后拖一拖，为你自己留足时间来复习，所以不要总想着一切都准备好再去面试，因为面试的时候总会问到你不会的东西，而且实习不比秋招，不会问太深奥的东西，说不定运气好都是你会的，那就赚翻了。

 后面五月份觉得在第一家公司干的活没啥意义，就选择了离职，那会大厂基本都没HC了，也没有出色的实习经历和学历优势，自然也很难约到大厂面试，也是找了一个月才找到了一个中小厂，在这边干的也很累，是做Saas服务的，有时候正职加班带电脑回去，甚至是通宵，项目紧急时周六日也要加班，当时问正职转正还叫我赶紧跑路，大家还是太辛苦了。

 之后离职准备秋招了，也是边整理简历和背八股，一直到九月底才开始投秋招大厂，但都是发测评和笔试，那些测评做起来又臭又长，那段时间做这些测评又没面试，天天都在思考人生的意义是什么，人都麻了。。。也是从十月中旬开始真正感受到秋招的寒气，我这种后端小趴菜基本没有大厂约面，于是乎转战老板直聘，每天海投到上限，到后面感觉 boss 打开来全都投过的感觉，但是约面也是寥寥无几，于是乎投日常实习，结果实习也约不到面试，可能也是投晚了，很少要26届的了，并且简历也不出彩，大厂基本约不到面试，只有字节给了面试，但是后面东财oc后就拒掉了。

## 【求职技巧3】如何回答常见的面试问题

来源：牛客网 ｜ 类型：面经 ｜ 发布：2023-05-31 ｜ [原文链接](https://www.nowcoder.com/discuss/493452930708701184)

面试，是求职过程中非常重要的一步，一场成功的面试可以充分展现你的专业能力和魅力，更能帮你获得理想的职位。优秀的背景和过往经历，也需要你有条理清晰、简洁明了、符合面试官标准的回答方式，接下来内推牛将和大家一起探讨如何优秀地回答面试中的常见问题。

 1、 "你为什么想要应聘这个职位？" 

 面试官希望通过这个问题了解你对公司的了解程度和你是否真心热爱这份工作。在回答这个问题时，你需要表现出你对这个公司的研究和对这个职位的理解。你可以提到公司的产品、服务、企业文化或者价值观对你的吸引，并明确表示你有能力并热衷于这份工作。

 2、 "你在压力下工作的情况是怎样的？" 

 面试官希望通过这个问题评估你的压力管理能力。你可以提供一些具体的例子，描述你如何有效地化解所面临的困难，顶住压力，成功完成任务。这个问题的关键是要展示你的问题解决能力和抗压能力，千万注意，不要抱怨你所经历的压力和面临的困难，展现你过多的负面情绪。往往，面试官也可能会采用压力面的方式，故意质疑你的能力，这时候条理清晰且心态平和地回答面试官的问题，是证明自己具有较好抗压能力再好不过的方法了。

 3、 "你的长期职业规划是什么？" 

 这个问题用于了解你对自己未来的设想以及你的职业发展规划。你的回答需要反映出你对职业发展的认真思考，以及对于在该公司工作的热情和计划。同时，回答需要具有实际性和可行性，与应聘的职位和公司的发展方向保持一致。

 4、"你的优点和缺点是什么？" 

 这个问题旨在评估你的自我认识能力。在回答优点时，你应该提供具体的例子来证明你的优点，并强调这些优点如何使你适应应聘的职位。在谈论缺点时，你需要诚实，但也要注意避免提到与应聘职位直接相关的关键能力的缺陷。你可以谈论你正在努力改进的地方，并展示出你的成长和自我提升的愿望。

 5.、"你能描述一下遇到的最难的挑战和你是如何克服的吗？" 

 面试官通过这个问题来评估你的问题解决能力和应对压力的方式。在回答这个问题时，你可以采用STAR法则（Situation-Task-Action-Result，即情境-任务-行动-结果）。首先，描述你面临的挑战，然后谈论你的职责，接着解释你采取的行动，最后阐述结果以及你从中学到的经验和教训。

 6、有什么想问我的吗？" 

 这通常是面试结束时的问题，也是你向面试官展示你对职位和公司认真研究并且积极投入的一个好机会。尽量不要说你没什么想要问的，趁这个时候可以了解下关于公司文化、工作团队、职位责任或者职业发展等方面的问题，展示你对公司的了解，获取更多的知识会方便你更好地应付接下来的面试。这个时候薪资并不是最重要的事情，往往在面试结束后，hr会帮你解决这个问题。

 总的来说，面试是你展示自己能力和求职动机的重要机会，准备充分才能更好地回答面试官的问题。以上的策略只是一种常见的指导，你可以根据自己的实际情况做适当调整。希望这些对你在面试中取得成功有所帮助！

## 秋招上岸，总结我心中的红黑榜

来源：牛客网 ｜ 类型：面经 ｜ 发布：2022-11-02 ｜ [原文链接](https://www.nowcoder.com/feed/main/detail/e077aac2bc4c4a7dab352e6621c97363)

声明：红黑仅个人观点，不客观也不全面，给 24 届和以后的做个参考。如果没拿到 offer 的我会说明，拿到 offer 的薪资也不便透露，请自行 os 查看

红榜：
东方财富，HR对接非常负责，薪资也非常有诚意，不想卷互联网的可以去尝试下

阿里云，面试流程很快，不拖沓。面试官水平挺高的，问项目都能问到痛点上，基本没问八股。小缺点是薪资拖的比较久

荣耀，两轮技术，和二面技术官聊了一会天，感觉挺有想法和魄力的。泡池子有点久，不过最后开的价格挺有诚意的

Ebay，进笔试了，参加笔试的每个人都收到了小礼品。拒信也比较爽快

搜狐，过筛之后HR先来联系了下意向，对面觉得不合适之后就直接拒掉了。不浪费双方时间，好评

京东TET，流程推进挺快的，面试的内容挺有意思。群面是讲业务思路，技术面面试官水平挺高的，能看得出是很有经验的一线开发，进了终面不过当时手里有满意offer了就懒得去了

Hulu，出题水平挺高的，挂的我心甘情愿

字节，面提前批的时候八股完全没准备，面试官可能看不下去我这个水平还给了点指导意见和后续规划。在后面涉及到八股的面试里确实挺受用的，看我答不上来也没摆架子给脸色，非常感谢那位面试官

Insta360，流程推的快，面试友好，HR非常负责。薪资比不上互联网但按它的体量来说给的很有诚意。感觉蛮有意思的一家公司，前景也很不错

黑榜：
华为，我最讨厌的公司没有之一，很后悔之前投递过简历，电话号码一旦暴露出去之后就是无数骚扰电话。笔试难度一轮比一轮难，标准还是一样，HR说的半个字都不能信

TP，笔试系统是我见过最烂的，负责高校群的HR屁用没有，消息不回，问题不回。一面八股，东问西问感觉面试官挺随便的，二面问逻辑题不知道到底想招什么人，面完没兴趣继续了就直接拒了

米哈游，过筛了之后笔试全A直接挂，简历不匹配可以拒，没必要恶心人。后续还发骚扰短信让去线下宣讲

网易，笔试题目又臭又长，很多边界条件都是没讲清楚。雷火三个半小时真的是精神折磨，当然也可能是我菜

亚马逊，招聘系统稀烂，几个入口数据都不统一。笔试难度意义不明，完全不具备区分度。能不能被捞完全是玄学，没有状态更新的反馈，在外企里是做的最差的

其他：
美团，快手，蚂蚁，小红书，拼多多，不评价。有的是我自己面的不好，有的是薪资不理想，行情不好可以理解

 class Solution {
 public int singleNonDuplicate(int[] nums) {
 int n = nums.length;
 int low = 0;
 int high = n - 1;
 while (low < high) {
 int mid = low + (high - low) / 2;
 if ((high - low + 1) / 2 % 2 == 1) {
 if (nums[mid] == nums[mid - 1]) {
 low = mid + 1;
 } else if (nums[mid] == nums[mid + 1]) {
 high = mid - 1;
 }
 } else {
 if (nums[mid] == nums[mid + 1]) {
 low = mid + 2;
 } else if (nums[mid] == nums[mid - 1]) {
 high = mid - 2;
 } else {
 return nums[mid];
 }
 }
 }
 return nums[low];
 }

来源：牛客网 ｜ 类型：面经 ｜ 发布：2021-09-02 ｜ [原文链接](https://www.nowcoder.com/discuss/353158406280257536)

【东方财富】09.02 一面凉经

 面试背景

 8月份开始投秋招，结果一个笔试都没过，投了东方财富免笔试，但是实际上还是会有手写代码的环节。 上午手写代码，下午5点的面试，用QQ在线视频面试。 面试官人很好，看起来挺年轻的，交流起来也平易近人，好评。 面试提问

 面向对象的三大特征？
 答：封装、继承、多态。 多态的表现形式？
 答：只说出 List list = new ArrayList<>(); 这种使用场景。 C语言面向过程与Java面向对象的区别？
 答：面向过程是解决某种具体场景下的问题，面向对象会将场景中的元素抽取出来，封装成对象，可以解决类似场景中的一系列问题。（然后被反问了，C语言的结构体也可以做到类似功能，有什么不一样吗？没回答上） 两台服务器已经完成TCP三次握手连接，那如果此时拔掉网线，会发生什么？
 答：不清楚 HTTP的请求方式。
 答：常用的有GET、POST、PUT、DELETE。 GET和POST的区别
 答：GET安全，POST不安全（追问：GET为什么不安全？-在地址栏输入会被看见或被拦截-那POST不会被拦截吗？-会，然后被问住了）。 Spring Boot用过哪些注解？
 答：@Repository、@Service、@RestController、@PostMapping、提示下想起来@Autowired。 提到@Autowired，那么了解IoC吗？讲讲IoC有什么作用。
 答：忘了 最后一问，有十亿的整型数据，范围1-10000，用什么排序算法？
 答：想不起来排序算法了。 面试反问

 用的技术栈？
 答：C++、Golang、Java都有，所在部门主要是Java微服务开发。 前后端分离，人分离吗？
 答：会分离，但作为后端工程师，了解前端是你的优势。 其他想不起来了。

 总结

 面试官在我反问的时候，问我是不是每准备面试(T - T),无话可说，因为确实没怎么准备，8月份基本在刷算法（不然大部分笔试都过不了），结果之前实习背的八股都忘了。

 面试官问的都比较基础，然而还是大部分都没答到点上，说明基础薄弱，需要再针对性看一下Java、TCP、HTTP相关的基础，还需要复习一下排序算法。

 没有好好准备面试。 需要针对Java基础、TCP、HTTP基础再复习一下。 需要学好设计模式和框架原理。 估计一面已经凉了，秋招上半场一片惨淡，可能要准备春招了。

## 东方财富技术岗位校招流程官方答疑帖，HR小姐姐终于坐不住啦！

来源：牛客网 ｜ 类型：面经 ｜ 发布：2018-09-21 ｜ [原文链接](https://www.nowcoder.com/discuss/353154588607979520)

致各位牛客网的同学们： 

 
 

 当我们如你一样，在牛客网搜索东方财富时，看到了大家对于 2019 校招面试流程的一些建议和疑问，在此，对于大家集中关注的问题，统一作如下解答： 

 
 

 1. 关于技术类岗位的招聘方向？ 

 回答： .net/C# 、 java 、 python 、 andorid 、 iOS 、 web 前端、测试等方向均有需求，不同用人部门的语言需求侧重不同，为了增加大家面试成功率，我们会要求大家在求职申请表上注明语言方向，面试时尽可能按语言分配至面试官。 

 
 

 2. 技术类岗位流程？ 

 回答：简历筛选（参加宣讲会免筛选） -- 笔试 — 技术面试 —HR 面试 — 测评 —offer ，无论什么岗位，流程都是一样的。 

 
 

 3. 关于技术类岗位面试地点？ 

 回答：校招网申覆盖全国，同时会在上海、苏州、无锡、成都、武汉、西安、南京、南昌、长春、沈阳、南昌 11 个城市 31 学校举办宣讲会，并在每个非上海城市停留约 1 周时间，大家可以就近选择面试站点完成笔试和面试。其中算法岗位仅开放上海、南京 2 个区域安排笔面试。 

 
 

 4. 如我想去其他城市参加笔面试，路费报销吗？ 

 回答：因校招期简历量大，首轮笔面试恕不能为每一位同学报销路费。如部分岗位终面需要安排至上海总部，则会为大家报销路费并提供住宿。 

 
 

 5. 为什么面试官觉得我不错，却把我淘汰了？ 

 回答：如果在面试时就得到面试官的肯定，那恭喜你一定是个优秀的同学，但你的优势未必符合这位面试官所在部门的岗位需求，这部分同学会进入到校招人才库，后续由 HR 统筹调剂，分配至其他更适合的部门，当然也会征询同学本人的意愿。 

 
 

 6. 为什么面试结束后，有的 3 天得到反馈，有的 1 周得到反馈的？ 

 回答：由于面试环节是各条线路分头推进（请参考问题 3 ），凡进入面试环节的同学，也都会由不同部门的面试官面试，所以后续流程也会略有不同，但我们都会尽快安排，一般 1 周左右都是合理的时间。 

 
 

 7. 没有项目经验就一定会被 pass 吗？ 

 回答：每一个笔、面试的环节都是对大家不同角度的考察，项目经验是其中一项，并且在我们的评价表上是一个附加项哦，并不会因为没有项目经验就被 diss 或是直接 pass ，真的是大大的误解。但同等条件下，如果你有项目经验，那也一定是很大的优势！ 

 
 

 8. 为什么我在网申页面看不到投递状态了？ 

 回答：我们有发现大家看到的状态和招聘系统实际状态偶有不一致的情况，反而造成同学们的困惑，因此暂时统一关闭。 

 
 

 9. 关于笔试报告上有照片的疑问？ 

 回答：本次笔试系统感谢牛客网的在线支持，对于线上答题的同学，系统会进行随机拍照，便于 HR 监考，在答题提示中也有预先的提示。对于部分同学担心发型乱了、衣服不好看等情况，大可放心，我们不是选美哦，只要衣冠整洁，确保至始至终是本人答题即可。 

 
 

 10. 一定要实习吗？不能实习就会挂吗？ 

 回答：又是一个 big 误解！首先，是否通过面试不取决于是否能实习。第二，在不影响课业的情况下，我们欢迎大家提前实习。第三，不同部门对实习需求不同，具体实习时间也会在 offer 后再和大家协商。 

 
 

 最后，毕业季找工作有运气成分，但多的还是靠努力，机会始终是留给有准备的同学，希望大家都能找到满意的工作，期待在东方财富遇见你！
