前言

 我面试的岗位是 个人安全-Android手机软件开发工程师 。本科。

 不知道能不能过一面呢……
2018年08月22日11:10:36刚写完这句话，二面电话来了……

 一面

 一个小时

 介绍项目 inner class与outer class（主要是访问权限的问题） this指针为什么可以访问所有成员方法和成员变量 编译器中如何处理这些权限限制的。 海量去重算法 有一瓶酒精和和一瓶水，各舀一勺给对方，问谁的浓度比较高？ 你觉得你最熟悉的东西（比如框架、源码）——我讲了性能优化方面的。 git reset git rebase git 三个工作区的区别。 view的绘制原理 事件分发 简单介绍RxJava。 问是否熟悉Linux编程，熟悉C++或者C 么？ 我回答熟悉Linux，但是没做过Linux开发，会C++，没写过C。 二面

 半个小时

 说简历，最主要是实习经历和项目经历 海量去重算法 实习内容 性能优化 git rebase的原理 用过的git操作 git add git commit git rebase git reset git push git merge git rebase的底层原理 三面

 我等了一个小时了…… 人生规划 为什么你会选择安全方向？ 你在实习的单位是否有转正流程？ 你对于你实习岗位与你方向不一致有什么看法？ 为什么春招不找和你实习岗位一直的公司？ 你考研吗？对于考研有什么看法？为什么不考研？ 腾讯和360你会选择哪一个？ 你是否有实习的时间？ 你对于早上面试的两位同事有什么看法？ 你有什么问题问我的？ 玄学等Offer

 跪求offer！╮(╯▽╰)╭
