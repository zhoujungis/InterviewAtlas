题目：abc+cba=1331，求解a+b+c=？
我的解法是：
100a+10b+c+100c+10b+a=1331
101a+20b+101c=1331
101(a+c)=1331-20b
令a+c=x∈0-18,b=y∈0-9
101x=1331-20y
右边y的系数是20，所以不管怎么减右边个位数都是1，那么左边101只能乘个位数为1的数
也就是x要么是1要么是11，但是1和11的时候y都不满足条件0-9
然后我人麻木了陷入了怀疑，就拿编译器用穷举（三重for循环实现）
package main

import "fmt"

func main() {
for a := 0; a < 10; a++ {
for b := 0; b < 10; b++ {
for c := 0; c < 10; c++ {
if 101*(a+c)+20*b == 1331 {
fmt.Println(a + b + c)
fmt.Printf("a: %d, b: %d, c: %d\n", a, b, c)
}
}
}
}
}

## 面试真的不要作弊，大家都尴尬

来源：牛客网 ｜ 类型：面经 ｜ 发布：2023-10-19 ｜ [原文链接](https://www.nowcoder.com/discuss/544460195062140928)

最近在疯狂面试，真诚告诫大家面试真的不要作弊，搞的大家都尴尬。 

 

 面试官问了一个问题，面试界面就显示对方就跳出页面了，然后看到他变了视角，眼球开始往斜上方看，光还一闪一闪的，大概过了半分钟，开始流畅的说答案，说完之后页面显示回来了，眼球也变回了正视我的方向。 

 

 {nowcoder-vote}{89920} 

 求职不要耍小聪明，其实很多时候，我们面试官都能看出来的。 

 

 刚好最近感悟比较多，同时也是最近面试跟很多同学聊，发现大多数同学都很焦虑，虽然在面试过程中已经给与他们一些辅导和安慰了，但还是决定来牛客给大家分享一波，希望能够帮助到更多应届生面试拿到offer，也算是帮到更多人吧。 

 
一、 保姆级面试经验分享 

 我是16届进入360的，现在是算法工程师，牛客上大多数是拿到offer的同学分享的经验，我从面试官的角度给大家分享一下面试经验。 

 
1. 心态上放松，别紧张别害怕 

 这个是首要的！！！ 

 

 可能看起来比较鸡汤，但是确实是我面试过程中很多同学都会存在的现象，因为包括我自己当年校招面试的时候也非常紧张，导致回答问题的时候我大脑一片空白，也是那个面试官通过一些引导，我觉得引导出了我真正的技术能力，而且刚好我当时的项目遇到了一些问题，在面试环节中问了这个面试官，他还帮我解决了这个问题。 

 

 所以我在面试别人的时候我都会告诉他们放松，这不是压力面，就是正常的面试沟通了解的过程，也会引导和尽量帮助到应届生们。 

 

 害怕和紧张真的会影响你的发挥，而且有的公司真的有压力面，没啥的，我们也不是多个眼睛鼻子的，面试官的职责就是帮助公司筛选到更匹配的人，必须要通过问问题和你的回答来判断你的情况和公司是不是匹配，不存在哪位同学比哪位同学高一等，也不存在面试官比学生高一等，我们是打工人，你们以后也是，说不定还成为同事呢。 

 

 所以建议有这个恐惧心理的一定要克服一下，不然你就已经输了，建立自信很重要，大家都是双向选择的。 

 

 

 
2. 不要耍小聪明，作弊等手段不可取 

 这点开头就提到了，无论是简历、笔试还是面试环节，都不要耍小聪明。 

 

 成功有方法，但是没有捷径。 

 

 不过这点我倒是没怎么遇到，除了文章开头提到的那个，当然，那个同学我也没有在面试过程中提出来，还是正常面试下去了，只是在追问环节他就不太能回答上来了。 

 

 其实最关键的是现在的防作弊系统做的都非常好，我们的面试后台都能非常清晰的看到你们的情况，跟笔试一样，提交的代码也能看相似度等等。 

 

 
3. 专业匹配度的准备 

 这点是最重要的！ 

 

 根据我这里脱颖而出的同学，我总结下来主要有这4点，你们也可以朝着这个方向努力，分别是技术深度、技术广度、项目经验、技术想法，接下来我分别分享一下。 

 

 ①技术深度 

 大多数同学准备面试的方法就是背八股文的方式，这个倒是没有什么问题，但是只能说这个是基础，因为你能背，他也能背，真正拉开差距的就是追问环节，看你的技术深度，是了解层面，还是理解层面还是融会贯通出神入化了。 

 

 那我一般会追问的比如”是否看过源码“、“你有没有用过”、“用的过程中有没有遇到过什么问题”等等。 

 

 ②技术广度 

 对应的深度的就是广度了，大家都背，那就我比你多背点，我了解更多的技术栈，我就牛。 

 

 但是如果说同样的精力应该准备深度还是广度呢，我个人会更推荐深度，这个其实更关系到个人潜力的问题。 

 

 当然，精力多的，可以多学习一些，没有坏处的。 

 

 但是不要为了准备而准备，基础一定要掌握好，在掌握基础的前提下，能更好的动手实现一些东西，也有一些实现价值。 

 

 很多同学可能会附上github链接，展示自己写的代码，这些代码看了就知道就是为了展示而展示，可能有还不如没有。 

 ③项目经验 

 无论什么技术都要落地到业务，像我们算法也一样，也要落地到业务的，所以如果你能有一些项目经验，对业务模式和落地等有一定了解，那肯定是非常加分的，如果你的项目经验还有一些价值，比如上线了多少人使用或者申请了某个专利等等，这些就更加分了，至少在我这真的非常加分。 

 

 而且这个和上面提到的深度也是相辅相成的，因为只有在实际项目和业务中使用过，才能理解的更深。 

 

 我在面试中也会深挖之前做的项目或者实习，不光看你的经验，还可以通过这个看到你的思考模式和遇到问题的解决方法。 

 

 同时我也会多问一些具体场景下的问题，比如“冷启动怎么处理”、“深度学习的调参技巧”、“有没有采取过其他trick或者解决方法”。 

 ④技术想法 

 我觉得技术想法是能侧面体现出你的学习能力、技术热情、了解和关注程度的，而且这个一般也背不了，所以能阐述出自己技术想法的同学在我这也比较加分的。 

 

 这点和项目经验也是相辅相成的，有想法才更可能去实践，我是非常推荐大家去做项目的，像学校上课做实验的项目就很好，如果还有额外的机会，生活中场景也是非常多的，如果有想法，自己做出来岂不是更好，对提升也会很有帮助，同时还能丰富简历和面试。 

 

 当然，面试环节我会结合不同同学的简历针对性的提问，不会有刻意刁难，因为技术栈不匹配都没关系，重要的是学习能力、技术热情、技术基础，以及加入360的意愿。 

 

 所以我每次面试中都会在结束了跟一些同学聊聊后续学习和提升建议，同时也介绍一下360，让不了解360的好的同学了解一下，毕竟我了解了你，你也可以了解一下我们公司嘛，同时也可以对我进行提问，我认为这才叫真正的双向选择。 

 

 刚好这里也给大家分享一下360这个应届生友好的平台吧，还是非常值得加入的。 

 二、对应届生来说，互联网大厂360是非常好的平台 

 360作为互联网大厂，平台确实还是非常可以的。

 1、有给应届生具体的培养目标 

 去年的时候，360提出了“2557”培养目标，希望同学们通过360的培养和岗位学习，能够实现工作2年具备岗位骨干，5年成长，而且这一切都落实的非常具体： 
 

 能在1-2年完全胜任岗位职责，有优秀的产出 

 2-3年成为岗位熟手，自身优秀的同时能带教新人 

 3-5年成为业务骨干或一线经理，能带领小团队协作完成任务
