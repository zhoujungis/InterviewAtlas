## 【经验贴】模拟面试看看你还缺什么

来源：牛客网 ｜ 类型：面经 ｜ 发布：2026-03-12 ｜ [原文链接](https://www.nowcoder.com/discuss/861530377939062784)

技术面一般分为一下几个环节：自我介绍、技术八股文、项目、反问

 自我介绍 

 技术面的自我介绍需要准备两份，一份在2~3分钟左右，另外准备一份比较精简的在1分钟左右的。因为有些面试官会要求你做一个1分钟的自我介绍，那么你没有准备，还是讲这么长的话，讲到一半就会被面试官打断了，也会给面试官留下时间意识差的印象。

 把两份自我介绍的稿子写出来不断地念，反复修改直到自己觉得满意为止，念的时候还要给自己计时，注意时间的把握。

 下面就给大家一个我自己的模板，并以这个模板为基础详细讲讲要怎么做自我介绍。

 面试官好，我叫xxx。就读于xxxxxx大学xxxxx专业。大学期间我参加了xxx比赛，获得了xxx奖项。还获得了xxx奖项，并且获得xxx奖学金。

 我比较熟悉使用STM32系列芯片，就拿xxx项目来说，里面有用到xxx芯片，xxx功能，xxx功能，xxx功能等

 之前所做的项目都是在单片机上开发的裸机程序，没有跑操作系统，最近才开始学习一些FreeRTOS方面的内容，现在只是了解一些基础知识，还没有在实际项目中实践过。

 Linux的话只是会一些基础的指令，对这方面接触比较少。

 我提前了解到贵公司的xxx岗位，在看了该岗位的岗位描述后，对该岗位比较感兴趣，也觉得该岗位和我的匹配度比较高，所以投递了贵公司的xxx岗位。

 首先第一段就介绍了自己的个人信息以及所参加的比赛获得的奖项和奖学金等，开门见山直接告诉面试官你的能力水平大概是怎么样的。

 第二段介绍了自己主要使用的芯片及其功能，这部分的话主要是展示你会哪些东西，有哪些东西是公司需要的。

 第三段和第四段提到了自己的薄弱环节，其实适当提到自己的薄弱环节并没有太大的关系，一方面是我面的是单片机的岗位，那么我提到我实时操作系统和Linux不熟悉也不起到致命的影响，另一方面是，如果你确实有某一块知识有欠缺的，而这个知识恰好又是该岗位所需要的，那么最好也直接在自我介绍的时候提出来，并表示自己正在学习当中，不然等到面试官问的时候而你答不会的话，会给面试官一种落差的感觉，反而更不利。

 最后一段表明自己为什么要投递该公司，表现出自己对该公司的了解，以及渴望加入该公司的态度。

 技术八股文 

 所谓的技术八股文就是一些常考的考点的意思，面试官往往会直接考察你对某个知识点的掌握情况，这个时候就需要对C语言、单片机、数据结构与算法、操作系统等知识比较熟悉才能从容应对。

 面经一共3 2篇文章，12w+字数 ，包含全部最新的面试必问考点， 4.7w+同学学习，3300+订阅 ，非常适合在找工作面经薄弱的同学，销量即是口碑，提前订阅提前享受，持续更新中。

 原帖链接： https://www.nowcoder.com/creation/manager/columnDetail/MJNwoM 

 项目 

 项目这部分，首先是会让你介绍一下你的一个项目，然后面试官会根据你项目里用到的技术去进行提问，如果遇到面试官比较熟悉或者感兴趣的内容，可能就会问得比较深入，一般来说还是以面试者的讲述为主。对于自己写在简历里的项目一定要非常熟悉，针对项目里的每个技术细节都要掌握。

 这里就汇总一下面试官会针对项目问出哪些比较通用的问题（由于每个人的项目不同，针对项目中具体的点的问题就不列出来了）

 请你介绍一个你做的最好的一个项目 

 如何介绍自己的一个项目呢？其实和写在简历里的差不多，首先是介绍一下这是一个什么项目，由多少个人完成的。其次，介绍一下这个项目的主要功能以及你负责了哪部分的内容。然后是介绍这个项目里面用到的技术点。最后总结一下这个项目的成果。

 这个项目是几个人做的，你在这里面是负责什么内容？ 

 你和你的队友的分工大概是什么样的比例？ 

 这个项目的难点在哪里？ 

 在做这个项目的过程中有遇到什么困难吗？最后是怎么解决的？ 

 这个项目有什么不足之处吗？ 

 你在这个项目中学到了什么？ 

 如果让你现在优化项目中的一点，你会怎么做？ 

 这些问题被问到的可能性还是很高的，所以大家还是要提前准备好答案，逻辑要清晰，不要在回答的时候吞吞吐吐。

 反问 

 反问环节基本上是每个面试都会有的，当面试官问完了他的问题之后，一般会问你有什么问题问他的，这个时候你千万不能说没有问题，因为这样往往代表你没有好好准备这个公司的面试，在面试官那里肯定是扣分的。

 在面试前准备好几个问题，等到这个反问环节的时候挑几个提问就可以了。在反问的这个环节，最好能体现出你的态度以及你对公司的向往。而有一些问题是很踩雷的，就不要问了。下面汇总了几个建议问的问题，和几个不建议问的问题。

 建议问：

 可以介绍一下贵公司在xx城市、xx城市和xx城市业务上的区别是什么吗？ 

 可以介绍一下贵公司在xx城市的规模是怎么样的吗？ 

 可以介绍一下xx岗位主要是在做哪部分业务吗？ 

 可以介绍一下xx岗位开发的产品主要是基于什么平台来开发的吗？ 

 请问贵公司对于应届毕业的新人会有哪些培养呢？ 

 提出这些问题，之后还可以根据面试官的回答来进行再次提问，面试是一个双向交流的过程，不要担心问这么多问题会怎么样，面试官反而会觉得你问这么多问题，是对公司比较感兴趣。

 不建议问的问题：

 薪资待遇 

 薪资待遇在终面通过之后会有一个环节专门谈的，不建议问，而且面试官也不会给你一个具体的数字的，感兴趣的可以去offershow小程序上面查。

 上下班时间及是否双休 

 上下班时间和是否双休也是会在终面通过后和谈薪一起沟通的，想要提早知道的可以去知乎、牛客网上面搜索，或者询问师兄师姐，或者去一些交流群询问。

 还有一些假大空的问题，比如问公司的战略规划这样的问题，这种问题没有任何意义。

## 面试官：怎么禁止用户复制？

来源：掘金 ｜ 类型：面经 ｜ 发布：2025-06-09 ｜ [原文链接](https://juejin.cn/post/7513557849243762724)

前言

 今天在刷知乎，看到一篇非常棒的文章，想复制其中一段给妹子，结果提示“禁止转载内容不支持复制”，开玩笑，这点小伎俩能拦得住我？于是起身打开笔记本电脑尝试起来，不看不知道，一看有门道。顺手写篇文章记录下。

 

 面试官：怎么禁止用户复制我们网页中的内容

 青铜段位：阻止默认事件法

 包括但不限于阻止copy事件，mouse事件（阻止选区产生），阻止key事件（阻止键盘操作）等等。

 document . addEventListener ( 'copy' , e => {
 e. preventDefault ()
})
 
 
 例子： blog.csdn.net/secketl/art… 未登录的csdn

 
 面试官挑眉 ："用户按F12禁用JavaScript，阁下又当如何应对？"

 
 黄金段位：CSS 幻术

 本质上就是用css让用户无法区选到对应的内容，从而不能产生复制。

 .anti-copy {
 user-select: none;
 -webkit-user-select: none; 
 position : relative;
}
 .anti-copy ::after {
 content : "已启动防复制结界" ;
 position : absolute;
 right : - 120px ;
}
 
 面试官微笑 ："我在控制台删掉::after伪元素，阁下幻术不攻自破，并且无法区选用内容的户体验实在太差了"

 
 钻石段位：字符映射

 这就是我今天遇到的知乎的方案。通过字体文件对字体做映射，实现展示出来的内容和实际dom的内容不一致。

 
真实的DOM内容就是一串乱序的中文，所以即便你通过了复制的方式拿到的内容也是无意义的内容。

 
似乎知乎会对特定文章生成一个字体映射的包，通过这种方式可以有效的阻止用户复制粘贴该内容。

 
 例子：知乎禁止转载文章。

 
 面试官思索许久 ："我只要拿到映射的字体包，把乱序的内容复制出来，再进行映射处理，阁下如何应对"

 
 王者段位：自定义渲染

 内容选区等都进行自定义渲染，接管所有操作。
 

 
该例子通过svg绘制内容，区选的实际上是svg绘制出来的，并且接管了选区等绘制。

 
 例子：WPS 在线文档

 
 面试官面露难色 ："那我只能截图AI识图了"

 我 ：我***的，这工作我不要了。

 后续

## Redis 攻略面经（七）-- Redis 事务的使用和特点

来源：掘金 ｜ 类型：面经 ｜ 发布：2022-12-11 ｜ [原文链接](https://juejin.cn/post/7175896794851704892)

开启掘金成长之旅！这是我参与「掘金日新计划 · 12 月更文挑战」的第十九天， 点击查看活动详情 

 
 📣 大家好，我是Zhan，一名个人练习时长一年半的大二后台练习生🏀

 📣 这篇文章是复习 Redis 缓存实践中的问题 的学习笔记📙

 📣 如果有不对的地方，欢迎各位指正🙏🏼

 📣 与君同舟渡，达岸各自归 🌊

 
 
 👉引言

 
 我们知道MySQL的事务，知道Java中的事务，但是似乎很少提到Redis中的事务，但是在Redis中我们也要保证命令 按照顺序串行化执行 队列中的命令，那么Redis是如何在命令层次和底层实现事务的呢？

 
 Redis 事务的本质是 一次性、顺序型、排他性的执行一个队列中的一系列命令 。事务支持一次执行多个命令，一个事务中所有命令都会被序列化。在事务执行过程，会按照顺序 串行化 执行队列中的命令，其他客户端提交的命令请求不会插入到事务执行命令序列中。

 那么本文就从 应用层面 来探讨一下Redis 事务的使用：

 
 🛢 Redis 基本命令

 
 mysql中的事务开始是 begin ，结束时 commit ，那么Redis怎么开启事务和结束事务，又有哪些不同于MySQL的地方呢？

 
 
 MULTI ：开启事务，也就是从这个位置开始，所有的命令都会逐个放进队列中，也就是相当于MySQL的 begin 

 EXEC ：执行事务中的所有操作命令，也就是提交事务，相当于MySQL中的 commit 

 DISCARD ：取消事务，也就是回滚事务，相当于MySQL中的 rollback 

 WATCH ：监视一个或多个key，如果事务在执行前，这个key被其他命令修改，就会中断事务，这就是区别于 MySQL的地方 

 UNWATCH ：取消所有的 watch 监视

 
 
 🕶 WATCH & CAS

 
 既然有区别于 MySQL 的命令，那么它有什么使用场景呢？其实它和 CAS 有关，我们来看看具体怎么使用：

 
 先给一个场景，因为我们的对策都来源于问题，那么有了问题，我们才会去设计对应的命令去解决，那么场景如下：

 对于一个商品，它的存货只有一件了，但是现在两个线程都进来了，两个线程都判断存货大于0，都通过了校验，进行了下单操作，导致最后 出现了两个订单，且订单的余量变为了-1 ：

 

 但是有了 WATCH 我们就很好解决这个问题了，我们先回顾一下watch的作用： 监视一个或多个key，如果事务在执行前，这个key被其他命令修改，就会中断事务 ，根据这个作用我们可以写出下面这段代码：

 WATCH capacity
capacity = GET capacity
capacity = capacity - 1
MULTI 
SET capacity &capacity
EXEC
 
 有了上面的代码，如果在WATCH执行之后，EXEC执行之前，有其他的客户端修改了容量的值， 当前客户端的事务就会失效 ，程序要做的就是 不断的重试 ，直到没有发生碰撞为止

 
 那WATCH实现的底层逻辑是什么呢？

 
 其实就是我们所说的 CAS：compare and swap ：

 
 在开始事务前监听一个键值对，记录下来这个值

 在提交事务后，拿到键值对的当前值

 进行两个值的比较（ Compare ）：
 
 如果值没有发生变化，就 执行 事务

 如果值发生了变化就 回滚 事务

 🎈 事务的回滚

 
 大家如果有使用关系型数据库的经验，可能知道 Redis在事务失败的时候不进行回滚，而是继续执行余下的命令 后觉得有点奇怪

 
 那可能大家有疑问： DISCARD 不是回滚吗？但其实这里所谓的回滚是指：在 EXEC 执行过程中，出现了命令的错误，会继续往下执行，不会因此中断，所以其实我们可以发现这些问题属于是开发者出现的 编程错误 ，而 不是生产环境的问题 ，因此不需要对回滚进行支持， 因为回滚不能解决编程错误带来的问题 ，例如对错误的类型执行了INCR，很明显这不是回滚能处理的

 🎯 事务的四大特性

 🔴 原子性

 首先通过上文知道，运行期的编程错误是不会回滚的，所以其实很多文章由此说Redis事务违背原子性的

 但是 Redis官方文档给出的解释是：所有的命令，要么全部执行，要么全部不执行，而不是全部执行成功 

 🟢 一致性

 redis事务可以保证 命令失败的情况下得以回滚 ，数据能恢复到没有执行之前的样子，是保证一致性的，除非redis进程意外终结。

 🟡 隔离性

 redis事务是严格遵守隔离性的，原因是redis是单进程单线程模式，可以保证命令执行过程中不会被其他客户端命令打断。但是，Redis不像其它结构化数据库有隔离级别这种设计。

 🟠 持久性

 redis事务是不保证持久性的 ，这是因为redis持久化策略中不管是RDB还是AOF都是异步执行的，不保证持久性是出于对性能的考虑。

 
 📕 事务的其他实现方式

 
 Redis 事务除了命令，有其他的实现方式嘛？

 
 其实对于一个Java后台程序员，与我接触最多的Redis事务其实是 Lua脚本 ，很少使用到 MULTI,DISCARD,EXEC 这种命令。

 基于Lua脚本，Redis可以保证脚本内的命令 一次性、按顺序的执行 ，当然，它也不提供事务运行错误的回滚，与上述的情况一致

 
 💬 总结

 本文讲了Redis事务的命令行使用以及一些介绍：

 
 对于 Redis命令 ：我们提到了基本的事务 开启、提交、弃用 三种命令

 对于 事务的回滚 ：Redis的事务回滚机制相对于其他的很特殊，我们也做了讲解

 对于 事务的四大特性 ：我们分别讲述了四个特性的实现，并且提到并没有实现 持久性 

 对于 事务的其他实现方法 ：这就是我们后台程序员可能接触比较多的 Lua脚本

## 高校行政岗面试经验分享

来源：牛客网 ｜ 类型：面经 ｜ 发布：2022-09-22 ｜ [原文链接](https://www.nowcoder.com/discuss/402456576693481472)

林奕汝老师，现入职温州大学行政岗，她本科毕业于温州大学教育学院学前教育专业，研究生毕业于英国曼彻斯特大学教育领导专业。曾获温大三好学生、曼大研究生一等学位、浙江省第六届中华经典诵读竞赛二等奖、第七届互联网+大赛国际赛道铜奖等荣誉。她分享如何准备高校行政岗面试及真题分享，教师编提前批、医院行政岗等备考经验分享。 
 

 温大这场招聘分为第一轮面谈和第二轮结构化面试。 

 面谈部分 

 第一轮面谈分为自我介绍和考官提问。 

 关于自我介绍，它的目的是要体现个人特点，以及你是如何匹配这一岗位的。由于不知道考核时长，因此最好准备四份自我介绍，分别是一分钟以内、一分半左右，三分钟以内、五分钟以内，将这四份自我介绍都背熟。其中的内容包括自我认知和岗位认知，也可以加上未来规划这一部分。自我认知包括学习经历、性格特征、能力、参与的社会活动、学生干部经历等，选取几个叙述。岗位认知则是你对该岗位的理解，以及为什么要选这个岗位。未来规划则是入职以后的规划。 

 不管是企业招聘还是事业单位招聘，考官都希望听到一份有逻辑的答案，因此自我介绍最好也分为几个模块。她介绍自己的三个模块，前两块是自我认知，第一部分简单地介绍了自己在学校中获得的部分成绩和荣誉，第二部分则重点讲自己的能力，这些能力都应是适配于行政岗的。有不少同学在写自我介绍时喜欢把所有的获奖经历都搬上去，想以此体现自己的优秀，这其实是一个误区，只要挑选几个重要的奖项（最好和报考岗位相关），或是一些经历/项目/比赛，并写出自己从中获得的与报考岗位适配的经验/能力就足够了。另外，有的同学会很空泛地说“我有一定的文字功底、沟通能力、组织能力”，但没有举实例，语言会显得苍白。在描述自己的能力时，一定要用例子来佐证。这就好比写论文，我们需要抛出一个论点，后面紧跟着一系列的论据来支撑这个论点，使它具有说服力。自我介绍也是一样的，我们通过具体的例子来证明自身能力，这些例子可以是参加举办过的活动、日常学生工作等，从中学到了哪些经验、锻炼了哪些能力。哪怕自我介绍时间只有1分钟，也要举一个简短的例子来证明你拥有的能力或经验。第三部分，把岗位认知和未来规划揉合在一起写。岗位认知是指对该岗位的理解，以及报考动机。建议把报考动机和热爱联系在一起，例如报考教师岗位是因为“喜欢孩子”、“热爱教学”。未来规划可以视具体岗位定，因为这场招聘没有细分具体岗位，因此可以写得笼统简短。 

 一般来说，人才引进面谈中的自我介绍是可以透露个人信息的（不绝对），如果本科或研究生院校是比较好的学校可能会让考官多加留意。很多高校比较喜欢招自己的学生，如果报考的学校恰好是自己的本科或研究生院校，那也会相对更有优势。 

 考官提问方面的准备，第一，搜罗关于学校的信息，例如办学理念、办学特色。有的考官喜欢问“你为什么想来我们学校”、“你知道我们学校的xx理念吗”这类问题，如果这时能把学校某些特色融进答案，那将是一个加分点。第二，准备岗位相关的问题，这是非常重要的准备问题的方向，这类问题无论应聘哪个公司哪个单位，都是很有可能会被问到的。第三，通过查阅文献了解我国高等教育行政体系当中存在的问题，并根据文献准备一些建议。第四，阅读教育部颁布的和高等教育有关的文件。第五，通过知乎、小红书等app查看他人分享的经验。第六，购买资料，但不要花冤枉钱，网上很多高校行政岗真题集都是假的，要挑靠谱的买。 

 准备完自我介绍和问题后需要不断地练习，特别是要将几篇自我介绍背熟，还可以找朋友或家人当考官进行模拟面谈。真正面谈时，由于紧张，自我介绍时的说话速度会越来越快，这时候要把速度慢下来，不能看起来太像背诵。在回答问题时，尽量往“自己是如何适配该岗位的”这一方向上引，并且最好分点将结论前置，例如，问题是你认为自己为什么适合幼儿教师岗位，那么可以说，“第一，我有着较强的专业性，我的本科专业为……；第二，我的教学能力较强，实习期间……；第三，我有不错的科研能力，发表了……”将结论前置，后续再用例子说明或展开说明，会使答案更有逻辑和说服力。 

 结构化面试部分 

 她介绍自己之前没有真正接触过结构化面试，而且短期内通过自学去掌握每一种题型是比较困难的，因此可以考虑报录播网课，能力较强的同学可以不上网课。如果比较懒散且不差钱，可以报个线下班，线下班的好处是老师会盯着你，逼你开口练习，同学之间也有练习的氛围。 

 她当时跟着网课老师每天练题，前期每一道题都认真听认真练，后期也是每一道都听，但会筛选出一些需要的题去开口练，每天练习的时间至少要三小时（不包括听课时间），四五个小时也是有可能的，在这一过程中会感到非常口干舌燥，但它是提升流利度最有用的办法，也是她认为的唯一办法。 

 想要练好结构化面试，核心就是多开口去说话、多去练习，把流利度提升上去，并且要进行录音，每道题至少练个十遍，她一般练10-15遍。这里所说的网课题目有选择性地练，是因为机构很少会专门针对某个单位设置面试班（教师、医院除外），比如说专门为水利局的考生设一个班。这些面试班上课练习的题目有一部分是具有普遍性的，例如“老同志懒散把工作推给你怎么办”，也会穿插针对不同岗位的题目，例如“寒潮将至，你作为xx局工作人员，领导安排你进行船舶安全检查，你会怎么检查”。这种专业性很强的其他岗位的题目可以选择不练。 

 除了练题，她还去找了近几年的感动中国的十大人物，从中挑选了一些人物事例去扩充自己的素材库。感动中国的人物事例是非常好的素材，又是正能量的，颁奖词也写得绝妙，因此有时可以把它们用到结构化面试中的态度观点题或社会现象题。她还列出了她认为的成功需要的十大品质，比如说勤劳、诚实、不惧艰险、艰苦奋斗。 

 这里写了不怕困难，顽强拼搏的精神，然后再写了一个理论，这个理论可以是网上找的，也可以是自己编的。下面的例子最好选取一些古今中国名人事迹，普通点的也可以，像是励志演讲家彭博这类。但要注意的是近几年愈发强调文化自信，所以国外名人的例子尽可能少举一些。 

 感动中国和成功十大品质这两个部分也是网课老师要求做的，除了跟着网课学习，偶尔会去b站上看一个叫面试学长的博主，学习不同的答题思路，不看也没关系。网课结束以后我会到小红书上找结构化面试题去练，其实找免费分享的题目就行，不要去购买真题集，有存在乱编现象。而且也没有必须要找高校行政岗真题，这种真题很少，像是博主们分享的其他岗位的真题，或是他们自己想的模拟题也是可以拿来练习的，结构化面试的题目都是差不多的，而且基本上考不到原题。 

 找了这些题目之后也要自己去画逻辑框架图，这时候先不要去写逐字稿，即图中的黑笔部分。要做的是先把逻辑框架图给写下来，然后看着逻辑框架图张口说答案并进行录音，每道题练10到15遍。等练了大量题目之后（五六十道）就可以写逐字稿了，然后背诵自己写的答案。她当时准备了一个活页本记录自己练过的题目，后面还会找一些新题写上去，每道题一定要自己去画逻辑框架图，包括前面跟着老师学的时候，逻辑框架图也尽量自己去画一遍。每道题口头练好后去听自己的录音，根据录音把答案完善一下，因为答题时有的点可能没想到，有的表达可能很别扭，那么就需要去完善这份答案，用自己说着舒适的词句去表达出来， 等背的量比较大了（五六十道）就可以进行模拟计时练习。同时一定要善用身边资源，可以问导师、班主任、学长学姐去了解学习一些经验，就算被拒绝了也没有关系，机会是自己的，不要害怕被拒绝，一定要多问。但是也要做好全面的准备，不能只听别人的经验，她当时向学姐打听过来她的考试流程、时间、题目，但是等我自己考试的时候，情况又有些不一样，因此去借鉴别人经验的时候也不能全听，还是要做好万全的准备。 

 重要的是，要保证答题的流利度，如果回答流利，答的内容中规中矩也会有不错的分数，在考场上大家多少都会紧张，能保持流利就已经非常不容易了。并且，我们答结构化面试题的时候，最基本的是分点回答，第一第二第三/首先其次再次等都是可以的，答题要给考官一种“这是一个有逻辑的人”的感觉，就算你只能想出来一点，也要想方设法把它分成第一、第二、第三去作答，让人乍一听感觉还是有逻辑的。另外，结构化面试有时候并不是一道题一种题型，它有可能是两种题型的杂糅，比如人际关系+应急应变，所以各个题型都要掌握好，平时在自己练习的时候也要注意去练杂糅的题目。 

 其他考试经历和真题 

 第一场是温州市教师教育院的数字化师训岗位。它没有笔试，第一轮是面谈，考试要求是硕士研究生及以上，教育类、教技或计算机类的专业能参加。面谈分为自我介绍和考官提问，很多非统考的事业单位考试，它们往往都是自我介绍加考官提问，所以三四份自我介绍一定要准备起来。她回忆自己当时好像是一分钟不到的自我介绍，考官提问是，“用专业术语回答混合教育下网络教育平台应该是怎样的？背后的技术支持又要考虑哪些？”完全答不上来，也就被淘汰了。当时的考生应该大部分都是教育类专业的，这个岗位最后一个人都没有招，并且在第二次发布的时候取消了教育类专业这一报考条件，只要教技或计算机专业的。现在很多事业单位以及企业都很缺计算机方面的人才，如果有计算机特长并且符合报考条件都尽可能去尝试一下。 

 第二场是某个幼儿园提前批，报考要求相对低一点，专科及以上，但是需要有一定的成绩或者荣誉，比如说成绩排名前百分之多少，并要求是学前教育专业的。这个幼儿园的提前批面谈包括自我介绍、才艺展示和考官提问，才艺展示包括美术、弹唱、舞蹈。我参加的时候，先进行了美术考核，一半考生在一个办公室里画画，主题是“热闹的”，在这之后要进行自我介绍和其他两项才艺展示，温州这边的幼儿园都很想要研究生，如果是研究生，本科或硕士专业是学前教育，那去参加幼儿园的面谈面试是很有优势的。 

 第三场是鹿城区市直属中小学的小学英语教师提前批。这个岗位要求本科及以上，加上一定的成绩或荣誉，专业要求英语或翻译，或是教育学专业，这里的教育学专业后面有标着专业代码，按理来说是特指教育学这一个专业的而不是教育类的专业。面试没有自我介绍，考官提问三道，第一道是“你认为小学英语老师需要具备什么？”这道题要用英语回答。第二道题是“你觉得小学英语课堂知识性更重要，还是趣味性更重要？”第三道题是“考编压力零到十分，给自己的压力打个分，并说明原因”。这场22届的考核形式跟21届的不太一样，21届面谈内容是自我介绍+一个简单的问题，所以大家要做多方面准备，毕竟考核形式可能时时变化。

 一面是ai面试，一分钟的自我介绍，有三次机会，所以不出意外这个很简单。但是需要注意的是一定要记得穿着正式（西装最好），这样容易过。 我的自我介绍大概就是分为四点：来在哪儿+学习方面+学生工作+竞赛项目+总结陈词自己的岗位适配度。 

 三、二面 

 我个人觉得二面是最难的一面，当时还出错了哈哈哈（网不好，所以自我介绍面试官没听太清）。 二面的主要内容包括：一分钟自我介绍+销售类型选择+模拟销售，用时15分钟，双人一起面试。 

 （自我介绍用一面的就可以） 二面前有一个问卷，这个问卷一定要好好填，最好截图保存下来，每个选择都要知道自己为什么选他，能说出相关经历最好，不能也要说得出选择的理由一二三…… 然后就是 销售类型 ，是问卷里面的一个题（abcd四种类型），这个没有正确答案，回答有理即可，一般会问：1、为什么选它为第一个。2、为什么选它为第二个。但是我朋友遇到一个意外：3、想一个新的销售模式。 

 最后是 模拟销售 ， 个人认为最难的环节 ，但是只要找到核、心就没太大问题，无非就是 了解需求、深入挖掘需求，然后提出方案 。比如当时我的题目是：我喜欢城市旅游，请说服我去郊外旅游。首先你需要做的是询问面试官原因（了解需求），然后根据原因列点分析、对比两个选择的优缺点，最后提出一个方案来解决问题满足需求。这里分享一个我在知乎看到比较好的帖子： 基恩士二面模拟销售练习 作者是俺是蜻蜓队长 

 这条帖子一定去看看哈哈哈，我个人觉得很有用，在这里也感谢一下贴主。 

 四、三面 

 看了很多帖子，都说三面是压力面。但是我没感觉到压力（此处没有凡尔赛的意思），可能是面试官比较温柔哈哈哈也比较帅，所以就没紧张。三面面试官一般是日本总部的技术高层，但是中文很好，所以一般都听得懂，而且配了翻译，然后加一个中国公司的高层。一般是日本的面试官提问。 整个三面是一分钟自我介绍+面试官提问，30分钟 。面试官的问题会从自我介绍、简历、二面前问卷入手，层层递进，一个问题接一个问题，造成压力，所以千万不要撒谎，要不然很容易露出破绽。当时问题大概就是：1、你的问卷二选一（我记不得了，老实说的记不得，然后面试官给我说了我的选项，我给出了解释）。2、根据上面的问题，问你在大学的相关经历（比如选择成为有用的人、有趣的人的实例）。3、你大学期间做过最艰难的选择。4、选择基恩士的原因。5、你考研吗。暂时只能想起这么多，但是 每一个问题都有迹可循，都是从你的回答一环扣一环的说的 ，所以再说一遍 不要撒谎！！！！ 如果你面完觉得很顺，整体也没有卡壳，面试官也问了你类似于工作地点、offer多少类似的问题，你多数就稳了。 

 五、行测 

 三面结束以后，就是行测环节。一般当晚就可以收到，我是三面当晚收到的，然后第二天做的。主要是两封：行测+性格测试（有传言说只收到一封就是待定，收到两封就是过了三面），然后把 两封好好做了一般就比较稳了 ，不过我有和我同一批的朋友是收到两封行测，但是也待定了，所以很玄学，行测也要好好做，但是我朋友在我的下一批也过了哈哈哈哈哈。然后就是最多一个周的等待，就知道结果了。 

 
 

 
 

 六、个人总结 

 在面基恩士的过程中，其实我没有很认真准备，就前一天看看面经，大家别学我。因为我其实在三年的大学生活中有很多交流、开会、面试、发言经历（学生工作），所以算是有一定基础。没有相关基础的朋友（类似有发言紧张、措辞有问题等）可以多练习一下，然后多借鉴，熟悉了就自然不会出问题了。另外就是，关于基恩士的评价两极分化严重，大家在面试过程中查看面经或许会被劝退，但是我想说的是有些东西只有自己经历了才知道，如果没更好的选择，基恩士真的值得，也不要过多听外界的声音，有付出才有回报，相信自己的判断，同时，想太多也没用是不，大不了先拿了offer再决定。 

 然后是真的想夸一下基恩士的面试流程，真的很良心，流程真的很快，所以不怎么耽误时间。我投了十几个公司真的对这一点深有体会，有些公司就是养鱼，大批简历才安排面试，所以来基恩士投一下，你不会后悔。

## 审计面试经验分享

来源：牛客网 ｜ 类型：面经 ｜ 发布：2021-06-08 ｜ [原文链接](https://www.nowcoder.com/discuss/353158002922430464)

本人毕业于 2020 届南昌大学。初入社会，一切未知，和立信会计师事务所结缘也是意外之举。去年 4 月实习，怀着一股孤勇只身来到深圳， boss 直聘也因此填入的择业地是深圳。 2021 年 3 月，研究生初试成绩出来，如预料搬未能上岸，收拾心情准备投简历应聘，彼时的我还在武汉的朋友家，父母电话想要我留在江西，其实本意也会呆在江西，毕竟亲朋好友都在江西，但是，，一切都因一通电话改变，投简历第二天，接到立信电话，告知通过简历筛选阶段，通知来面试，问是否在深圳，当时整个人都是懵的，一方面疑惑怎么会有深圳的面试邀约，另一方面是因为自己很想去四大或者八大，有种梦想成真的感觉。在接到电话到来深圳的这一段犹豫和抉择这里不予细说，当我背上行囊，便知道是另一种开始。而在这里，主要是给学弟学妹详述立信会计师事务所面试流程。 

 
 整个面试时间是需要大概 4 个小时，（每个事务所不一样，具体时间看合伙人是否健谈）面试流程分为三个 part, 第一 part: 主要是简短面试以及笔试，面试官是人事主管。第二 part 是主要的面试，自我介绍、面试官及应聘者双方了解，面试官是部门经理。第三 part 是和合伙人面谈方面，其实是这一部分取决定作用，不要紧张、不要紧张、不要紧张，重要的事情说三遍，展现日常的自己就好。 

 
 首先要准备好两版自我介绍，一版是一轮面试用的简短版自我介绍，另一版是第二轮面试环节和合伙人面谈时候用的自我介绍。两版侧重不同，第一版着重于介绍自己以及对企业认识，对自身未来展望三个方面详谈，对于应届生而言，可以从自己大学开始，讲一下自己的学生会或社团经历，或者是参加的与审计相关的竞赛方面。在准备这段介绍之前要先定一个基调 : 我把我的这段大学生活或者某些实习经历展示给面试老师看是想展示我的什么特点 ? 一般侧重团队合作力或者职业技能之类的。在简短自我介绍结束后，事务所面试官会给一份试卷，然后把你领进一个会议室，你有一个小时的时间答题，一个小时后面试助理会来收你的试卷，立信具体的面试题我不记得了，只记得有很多交易性金融资产的题目。如果笔试环节成绩不合格，可能会被取消接下来的面试，因此专业知识需要好好准备。 

 
 第二部分是在笔试结束后，面试官会让应聘者在会议室呆着，面试官现场批改，等待批改的时间看这一轮面试的人数，一般不会很久，然后面试官会按照成绩排名顺序依次点名进去面试。这第二轮面试，面试官可能会让你描述你对企业的认识（我有被问到这个问题），这一 part ，无论对应聘企业熟悉与否，建议都需要提前做好调查，包括企业文化，企业发展前景，管理层结构以及同事相处氛围等。一方面是以便自己对企业有个更深刻的认识，另一方面也给到企业信号 : 作为应聘者的我对你们公司很关注甚至是认可该公司的企业文化，调查来源建议：微博、知乎、百度等，企查查、豆瓣、还有一些应聘网站。第三 part 就是展望未来发展。其实在应聘者输出对企业认识的同事，面试官也会向应聘者补充企业的相关部分，在这一部分结束后，面试官会询问是否还有什么需要了解部分，这时应聘者可以像面试官询问薪资待遇以及职业发展等情况（有些面试官会在第二轮面试直接说，这里就不需要询问，或者可以自己补充需要了解信息），具体了解了解情况如下 : 薪资待遇方面 : 第一底薪多少，（如果是业绩类企业还需询问是提成绩效方面是如何考核计算），何时以何种方式发放工资，五险一金是否缴纳（一般大企业实习期间便会缴纳），年终奖多少（部分大企业是十三薪或者十四薪），如何发放以及何时发放，节假日有什么职工福利，第二 : 职业发展方面需要询问员工入职实习期多久转正，转正后升级需要什么条件以及需要多久时间，怎样操作流程，一般是一年一次，集中在六月或 7 月（这个各个事务所规则不同，立信是七月）立信一般是上班工时达到一定额度，再加上负责人审批，便可升级，具体职称评判标准每个事务所都不一样。知乎贴上可能会有详细信息，或者也可询问学长学姐。如果对同事相处氛围或者办公环境有要求的也可询问。 

 
 

 
 

 
 最后一部分是与合伙人交谈，我当时是从 1 点面试到了 4 点，四个小时的面试时间其中合伙人面谈占了一半，可能是我面试时应聘者不多，也可能是我的项目合伙人比较健谈，具体谈了什么已经忘记了，大概就是先自我介绍，然后他也介绍了一下自己，问我一些大学参加的相关比赛以及实习经历，问我对未来有什么计划，得知我想考 cpa, 告知我最好这两年考完 CPA ，工作之余多学习多看书，现在想想一点也不觉得是严肃的面试，反而像是自一个长辈的殷切教导。后面在所里有次电梯里遇到合伙人，合伙人和我说我笔试的成绩其实并不是很好，但是和他面试那轮，他对我映像很深刻的一点是我整个人很放松，和我交谈像是正常谈话一样，很舒服，所以我想，不要紧张，轻松自然是面试很重要的一点吧！ 

 
 这是我在立信面试的整个流程，仅以自己的一点经验展示给学弟学妹，希望能给到一点帮助，不畏将来，不惧现在，未知的未来另一面也代表有无限可能。

## kkk的国企银行面试经验

来源：牛客网 ｜ 类型：面经 ｜ 发布：2020-06-21 ｜ [原文链接](https://www.nowcoder.com/discuss/353156535935246336)

回馈牛客，给漫长春招画下一个句号。

 
 首先温馨提示，本文不会透露各厂待遇，是为求职意愿偏向国企，银行的后来者提供一个综合的面试技巧和面试经验。

 
 本人情况概述，渣211CS本，大学可以说混了一大半光阴（千万千万别学我）。考研失利开始春招。

 
 春招最开始用的某直聘海投简历。

 
 然后一无所获。

 
 焦虑迷茫怀疑自我时同学推荐了牛客，从此入坑。本文将按照面试常见问题分类如何作答来叙写。

 
 -------------------------------以下正文------------------------------------------------------------------------------

 
 1. 自我介绍。 

 
 这个建议自己总结一套扬长避短的模板出来。每个人情况不同，我简单说一下我的自我介绍然后分析一下吧。

 
 三位面试官好，我是xx大学xx专业本科应届毕业生xx（名字）。今天应聘xx职位我认为我的优势在于英语能力方面，大学本科期间一次性通过了英语四六级；另外我大二大三期间作为负责人或者重要的参与人参与了一些省级和国家级的项目和比赛，积累沉淀了一些专业方面的学习经验和方法，收获了很多东西；最后我比较喜欢踢足球，平时也会通过足球来排解学习压力并同时锻炼身体。以上基本就是我的自我介绍，谢谢各位面试官。

 
 首先，说清楚自己是本科生还是研究生。其次表达清楚自己的项目含金量高（其实面向csdn面向github罢了）并且自己是主要参与者，这句话说出来很重要，基本上后面提问环节会让你选一个自己擅长的来说，也就是说主动权还在你手上。然后就是自己的兴趣爱好，其实主要突出这是自己排解压力的手段，告诉面试官自己有有效排解工作压力的方式。遇到有相同爱好的面试官你就赚大了！我面宇宙行的时候跟面试官交流了至少五分钟足球。但是我后来细想，这也可能是在考察临场反应能力和演讲能力，如果真的如此，我只能说相比于浦发银行抽题目演讲来说工行还是爸爸。

 
 自我介绍基本就是这些吧，少数结构化面试要求说出自己优缺点，那就一定得找个缺点说出来。因为我分析我群面能pk过那些985，简历漂亮的让人嫉妒的大佬拿到某运营商省公司offer可能就是他们审题不严谨，没说出自己的缺点。我说的缺点就是没有实习经历，可能就跟其他人相比竞争力较弱。但立马就补一句：但我认为我学习能力比较强，自己平时也在用一些比较新的框架实现一些demo，相信我能笨鸟先飞。注意kkk的小心机----一定要说一些不疼不痒的小瑕疵然后立马说出自己的弥补办法，同时要在保持低姿态的同时展现自己的优点，这些是在知乎上学到的，感谢知乎。

 
 2. 项目面 

 
 我是自己实实在在做过项目的所以这方面基本能对答如流。总的来说就是简单介绍一边时。尽量用通俗的语言，项目是什么，做什么的。现实生活中有什么用，因为很多项目面会有hr在一旁听着。我寻思相同情况下你能吸引人家并且他能听懂同时带来一些启发：哦，原来这些死肥宅敲键盘做的东西对我生活带来了这些便利啊。打分总比这部分全程发呆打分会高些吧。然后算法类尽量复习一下老师发给你的论文的重点细节，系统类就复习一下当时现学的接口这些应该问题就不大了。遇到那些一两年前的项目还扣核心公式来恶心人的。我只能说这家公司不配。

 
 3. 技术面 

 
 这篇如果要细说哪家公司问了哪些问题那可就太长了而且牛客上确实有很多。这篇主要说一些kkk的小心机。面试前刷面经前遇到不会的就百度，然后一定一定记住所有百度来的文章要看完，包括但不限于 提出问题的角度，如何分析问题，得出的结论。举个例子：面试官问:你刚刚提到你比较擅长java平时也会做一些项目，那你可以说一下实现接口和继承类的区别吗？

 
 这个回答也很基础:java继承类只能继承一个但是可以实现多个接口。

 
 这就完了吗？我相信很多竞争者都能回答出来那你怎么能在简历没他漂亮的情况下脱颖而出，在短则不到十分钟的时间里展示自己呢？

 
 我是这样回答的：我记得最开始学习java的时候我很巧也发现了这个问题，为什么java和c++不一样。只能单继承，但又弄个接口出来，然后我就查了很多资料，发现原来......(说区别和联系)。后来用的时候也逐渐分清了什么情况用什么。最近我还知道jdk1.8之后接口的一些新的特性......。

 
 首先很遗憾这似乎不能速成，确实需要积累。但是这样回答首先可以暗示自己没有刷面经，其次“查了很多资料”，“后来用的时候”，“最近知道xx新特性”这些字眼不经意间能展示出自己爱好技术，平时喜欢钻研的优点。我之后总结来看确实能发挥比较大的威力，因为从与一些面试官交流来看似乎这些能力是考察的重点。

 
 4. 压力面 

 
 很多时候面试官会为难甚至恶心你，我觉得在已经有保底offer情况下这些没必要压抑自己做自己就好，因为能在一定程度上这告诉了你这家公司会有多大工作压力吧（猜测）。

 
 总体来看我遇到的压力面相对较少，都简单说说吧。

 
 京东方面试我java后台开发方向扣我两年前推荐算法类项目用到的公式。

 
 中信银行问到java中int的大小我回答4字节面试官遗憾的摇头告诉我8字节并叫我多看书。当时没什么经验认为面试官都是对的，所以接下来的面试过程我完全心不在焉并且底气不足言语没有任何自信。不知道为什么之后表现得那么糟糕居然还过了初面不过这家银行线下考察的邮件太不友好了，那个时候我似乎已经offer拿到手软直接拒了他。

 
 最最恶心人的就是开水团面试在我回答对了的情况下问我：“确定吗？”并且诱导我说出错误答案。我完全不知道他为什么要恶心我，不过这也导致我作为美团外卖多年年卡会员直接卸载了美团并且朝思暮想盼望着他的倒闭。

 
 说这些就是告诉大家，面试一旦开始，你所掌握的知识都是正确的，不要怀疑自己。面试那十多分钟时刻保持自信！

 
 我想说的基本说完了，现在是2020年初夏，窗外下着小雨告诉我说今天睡觉不能开窗并且会有很多蚊子，而我想对目前暂时失去方向的你说一些绝对不会落伍的话：没有人能真正一夜看尽长安花，也没有人会永远困在深不见底的腐臭淤泥中。对于大多数的我们来说，我们更像永远推着巨石的薛西弗斯，有颠峰也有低谷。关于这一切我们要知道应该就像《长安十二时辰》里元载所说的：

 
 站在高山望深渊，坠入深渊识攀爬，人活得不是一个点，人活起伏。

## 专治秋招抑郁综合症/非技术岗的秋招面经及各类不着调的分享

来源：牛客网 ｜ 类型：面经 ｜ 发布：2018-11-30 ｜ [原文链接](https://www.nowcoder.com/discuss/353154777334882304)

十一月只剩最后一天，即将到来的十二月让人有些心惊。 

 知乎和牛客上新鲜出炉的面经大多是技术同学们的分享，动辄七八个顶级sp的offer让人瞠目结舌之余也心生艳羡. 

 非技术岗的秋招实在是难，行业的严冬，无竞争力的专业，技术驱动的风向，都是壁垒与高墙 

 我的秋招从八月底开始，给自己设立的目标是：互联网行业首选，其次是地产行业，最后是K12在线教育 

 
 

 个人背景： 

 二本本科，某老牌211新闻与传播研究生 学习成绩尚可，六级/奖学金/C刊/科研等均满足，无大厂实习经历，有学生组织经验，无突出计算机功底。 

 个人优势： 表达能力尚可，心态乐观开朗 

 应聘的方向： 

 1、互联网行业：运营、市场为主 

 2、地产行业：企划 策划 

 3、在线教育：社群运营方向 

 秋招简历投递的情况： 

 1、分行业投递，并未海投，预测总量在30左右。 

 2、收到笔试的有七成，收到面试的大概仅在3成左右 

 面试集中时间在十一之后，高峰期在十一之后的两周，后续是零星的面试，总体上秋招获得的机会较少。 

 面试过的企业： 

 知乎（社区运营）共四轮---现在仍无音信 

 网易有道（市场营销管培生）--群面挂 

 滴滴出行--（终面）---拒绝了终面 

 猿辅导---（两轮）---后致电告知我没有HC 

 阿里大文娱（四轮）---offer-已签约 

 央企华侨城（两轮）---offer 

 地产世茂集团（三轮面试+体验之旅）--offer 

 跟谁学（用户运营）--offer 

 好未来管培--第二轮挂掉 

 玛氏（综合管理培训生）--拒绝了面试 

 美的（电商运营）--不愿调剂-挂 

 个人期待但没有收到面试的公司： 

 今日头条（被捞起来面实习生岗位）/腾讯内容运营（据说没HC，去霸面被秘书岗位捞起来很神奇）/爱奇艺（始终处在新投递的状态）/美团（笔试之后没消息，听人说北京根本不捞人）/vipkid（很想去社群，但一直在新投递状态）京东（一直处于初始筛选） 

 拒绝了面试的岗位： 

 龙湖/华夏幸福/泰禾集团/保利等 

 综上可以看出，我在互联网行业得到的机会其实真的十分匮乏，朋友们面大厂面的如火如荼，但是我却根本毫无音讯。 

 总结起来大概是以下原因： 

 1、没有看得过去的大厂经历，在实习经历上实在是匹配度不够高。 

 2、纯文科专业，在一些技术驱动的公司面前劣势明显。 

 3、跨区域参加秋招（学校不在北京）机会很少。 

 4、一次宣讲会都没参加。（参加宣讲会确实会有意想不到的好处，但是很多宣讲会都太偏远，有时候实在太累）5、投递的企业都是北京企业，地域问题。 

 
 

 面经： 

 其实我的面试机会很少，庆幸的是还是把握住了自己心仪的岗位，因此妄谈面经自觉十分不够资格，只做分享不做建议。 

 关于群面： 

 群面向来是淘汰率比较高的轮次，从招聘者的时间和精力成本上来说，无疑是十分省时省事的，因此即使我们对群面有再多的不满也无法逃避。 

 我在群面上的发挥一般都还不错，会有8进1或者是9进1，9进2的战绩，能够在群面中提出框架，贡献想法，提供大方向和突破口，在加上表达能力尚可也总是承担reporter的角色。 

 在我的感知中互联网群面的难度是大于地产的难度，地产的群面更传统，而互联网则更创新，不管面试什么岗位，永远都是产品题，就像我霸面腾讯被秘书岗位捞起来，群面的题目亦是产品相关。 

 在秋招中最让我印象深刻的就是网易有道的群面，我第一次在群面中感觉到自己无从发挥，论表现大概只在3/4名的位置，时间长人数多的群面对个人精力的消耗十分恐怖。 

 其他互联网公司的群面都不简单，但按照名气和行业的差别，难易程度亦有所区分。 

 tips:好的团队气氛很重要，认清个人优势，不要被角色给框死，表达时尽量言简意赅，有创新则发言不要赘述 ，别给队友挖坑，勇敢制止队友挖坑，Q&A环节勇于发问。 

 个人性格原因会有同学觉得我有些强势，这在群面中是一把双刃剑，会显得攻击性很强，我自己也在不断调试希望能够有效的找到平衡。 

 
 

 其他轮次的面试每个企业都有自己的风格，对自己的简历要充分自信与熟悉，不管是结构化的面试还是非结构化面试都要有自信，自信，自信，自信很重要。 

 其他啰嗦的面经： 

 1、关于着装和化妆等：我曾经面世茂的时候穿了个红裙子去面试，坐在一群黑衣白衬衫的同学中间十分突兀，虽然情有可原但实在不是上佳。面地产类的行业稍微正式点总不会出错，至少能够避免 

 在面试人群中的格格不入，其他包容性较强的行业舒适得体即可，之前看好歌曲我一个喜欢的创作者说“人不可以不自在”，我深以为然。 

 我一般对自己意愿十分强烈的公司都会化点妆，有些则十分惫懒基本上就那样去了。如果小姐姐们觉得自己化妆后更有自信那么一定美美的化完去面试，其他的个人感觉自然 

 得体不喧宾夺主就好。 

 2、碰到素质低下无脑怼人的面试官：我没遇到过这种情况，但是在知乎看话题的时候看到过一些情境。有的企业会以压力面的方式无下限的拷问应聘者，如果真的觉得自己被冒犯或感觉不舒服，可以 

 直言不必忍耐，尊重是相互的，大家都是个宝宝，不要因为找工作就觉得自己低人一等，谦虚谨慎是必要的，但不必处处迎合。 

 3、关于被拒绝和长时间等待：拒绝本身对任何一个有自尊心的宝宝来说都是痛苦和难以接受的，意味着否定和没底气。同时等待也让人长时间处于焦虑和反复的自我肯定与自我否定的死循环之中。 

 但偏偏这两种情绪都是秋招必备。 

 面对拒绝就是接受，很难特别难，你可以用任何方式宣泄，吃睡买，发朋友圈，骂人，唱歌，蹦迪都行。 

 面对等待就是不要坐以待毙，如果没有佛系等待的耐心，你可以选择一切你能获取的方式去询问结果，问面试官，问熟人，问学长，脉脉、牛客、知乎甚至是新浪微博，找一切你能够找的人脉与资源。 

 4、关于宣讲会：宣讲会还是很重要的。虽然现在很流行网申，但是很多企业在网申这一块的处理并不高效甚至不够重视。除了自己拥有网申系统的大厂，其他以招聘网站为媒介的企业大部分还是依赖 

 宣讲会的流程。我在面试过程中，经常碰到一些拿了offer的小伙伴都是走的宣讲会的流程，而我对应的网申还是毫无进展。比如说贝克找房，58集团，凤凰网等（人家offer都拿了，我还以为没开始）。 

 另外一些地产宣讲会后就面试，所以大家要积极收集信息，对于心仪的企业积极主动参加。 

 
 

 最后： 

 希望胖友们都有好的收获

 有心理问题的可以咨询我 费用是一包辣条

 本人目前就读于华南理工软件工程专业大四，2017年春季招聘拿了腾讯、CVTE、华为、YY等公司的实习offer，从2017年7月起在腾讯深圳实习，已拿到转正offer，2017秋季应届生招聘只投了阿里和华为两家公司，运气较好，有幸都拿到了offer，秋招也暂时告一段落。除了面经，想写一写学习和招聘的个人经验总结。学习和招聘都是和个人思维强相关的东西，我的经验也不一定对，我只是综合我个人以及周围相关同学的经验、踩过的坑，给后面的学弟学妹们一些启发。 

 2、正文 

 首先，我的相关经验仅限于技术/开发类招聘，产品、策划等方向我并不了解，不过我在腾讯和招聘过程中也认识了不少相关方向的小伙伴，如果有相关需求的同学也可以找我咨询他们的联系方式。 

 回到正题，招聘相关的经验，我准备从时间点、准备、方向和面试经验四个方面来说。 

 2.1、时间点 

 技术/开发类的招聘，对于本科生而言，需要重点关注两个时间点：实习生春季招聘和应届生秋季招聘，也就是大三下学期的那一年的3月开始（如我是2014届入学，也就是2017年3月左右开始的）的春季招聘，主要面向实习生招聘，实习时间一般为7—11月；和那一年9月开始的秋季招聘，主要面向应届生招聘，入职时间也就是毕业之后。这个3月、9月都不是精确地概念，只是集中在那个时间段。 

 这两个时间点对于招聘是相当重要的，因为这两个时间点，不论大、小公司都会集中进行招聘相关的工作，如果错过了这两个时间点，后面都会很困难，也就是说如果你想在招聘过程中顺利的找到心仪的工作，提前准备是必不可少的，特别是4月和9月都是招聘的高峰期，如果你在这两个高峰期没有准备充分，可能在面试中就不能发挥出自己的实力，错过很多进入大公司的机会。 

 对于春季招聘，我的建议是2月份左右开始规划和准备（我这里讲的准备是对以往的知识进行梳理和复习，并不是指2月份才开始学习）；对于秋季招聘，这个要看你个人的规划，一般在实习期间也可以进行适当的准备和复习，特别是对于实习不满意或者没有转正的同学，在实习期间复习也是必不可少的。 

 除了这两个时间点，也会有一些公司有补招、散招，不过还是抓住正式招聘比较有优势，特别是大家一起准备的话，效果会更好。另外，实习和秋招的机会都要好好把握，特别是实习的机会比较重要，找到一个好的实习可以为秋招的简历增色不少（特别是bat实习的转正率都会很高，可以避免秋招更激烈的竞争），如果对自己的基础知识不自信的同学，一定要提前准备，努力了都会有一个让自己满意的结果。 

 2.2、准备 

 对于一名本科生来说，如何准备笔试和面试是最棘手的，因为笔试、面试不像是某一门学科的考试，面试往往考察的是你的一个综合能力，但对于技术类面试来说，其实面试的考察还是比较有针对性的，按照以往的经验来说，准备可以从两个方面来准备：基础知识和岗位方向准备。 

 2.2.1、基础知识 

 基础知识不是别的，就是课本知识：操作系统、数据结构、数据库、计算机网络、常见算法等，这是基本上每个面试官或多或少都会提及的，并且 一定要记住，你项目做得再多，基础知识不掌握好肯定不行 。 

 对于基础知识的掌握最好可以去看一看相关面经，因为和考试不同，考试往往是一套比较成熟的试题，而面试对于基础知识的掌握往往在原理上，比如操作系统期末考试的考察往往是通过题目，而面试官往往会问你：和我说一说虚拟内存是如何在操作系统中实现的，这时你就要通过画图、口语表述的方式把这个原理说清楚，和做题的区别还是较大的。这里推荐给大家一个网站（应该很多人都知道）：牛客网，去搜一搜相关基础知识的面经整理，对于你复习有很大的好处，往往也能给你复习找一个方向。 

 对于基础知识的复习，不同岗位方向的重点也不一样，这也是我们需要注意的，举个例子，Java后台方向的基础知识可能更加侧重于Java、JVM、数据库等内容，Android方向的基础知识可能侧重于Java、操作系统等等，大家在复习的时候也需要进行相应的针对性的复习。 

 2.2.2、岗位方向知识 

 岗位方向知识就是与你所投递的岗位相关的知识，并且它和简历内容是紧密结合在一起的，因为面试官不会孤立地去问你问题，而是通过简历上的内容进行提问，这也要说到我们常见的一个误区，就是大学生项目一定要做精、做深入而不是做多，特别是对于你岗位方向的知识进行一个深入的了解而不是只停留在表面。因为对于面试官来说，大学生项目只不过是小孩子过家家（针对绝大多数普通本科生来说），他肯定不会对项目有特别大的兴趣，而是希望看到你在这个项目或者说实践中的学习能力、解决问题的能力的体现。 

 举个例子，针对安卓方向，也就是我面试的时候选择的方向来说，很多同学学习安卓有很多或大或小的Demo和App，可能使用了很多市面上很流行的框架，比如Retrofit、RxJava，但面试官往往会问，你有没有深入了解过Retrofit？有没有了解过它的实现？又比如对于安卓这个方向来说，面试官往往会问你Android触摸机制的实现你有没有了解过？这些都是常见的Android端面试问题，往往就考察了我们学习的深入程度，所以我才说同学们在做项目的过程中，可能你的项目不是很大，只是个个人作品，但你一定要在学习和做项目的过程中进行深入的学习和探索，比如可以对项目中使用到的框架啊的源码进行学习和总结，往往了解的越深入，越能让你在众多求职者中脱颖而出。 

 对于不同方向的准备，这里我也建议大家上网搜集一些相关岗位的面经（前面提到的牛客上资料很丰富，也有很多网站上也有相关资料），对于其他方向我也没有什么经验，Android方向的同学可以参考我自己在牛客上发的贴，其实多搜索搜索，基本上都有很多相关资料。 

 最后强调一下，一定不要陷入我一定要做项目的误区，哪怕你项目很少，只要你在某个领域了解的很深入，比如C++、数据库、JVM这些大家耳熟能详的东西，不怕找不到好的工作，所以自己在平时的学习中一定要多钻研多了解一些深入的东西。 

 2.3、方向 

 这也是很多同学会疑惑的问题，感觉自己什么都好像挺喜欢，而岗位方向却很多（常见方向可以参见bat招聘方向），这里对于方向的选择我不发表看法（和个人兴趣强相关），但一定要尽早定下自己的方向，因为不论什么方向，你只要掌握的够深入、够好，找工作不成问题，就拿我身边的同学，进腾讯有做前端的、C++后台的、C++客户端的、Android的、IOS的等等，甚至有个牛人拿到了阿里的机器学习offer（这在本科生中之前都认为非常难），所以不论什么方向，一定要尽早确定下来。当然大一和大二的同学可能还没有必要，什么方向感兴趣就去学一学，充分试错，找到最适合自己的方向。大三的同学建议就认准自己的方向进行学习和准备，避免没有一个深入的方向，到时候招聘会比较麻烦，因为毕竟招聘对于广度的要求没有那么高。 

 2.4、面试经验 

 自从实习招聘以来，大大小小的面试可能有40+，对于面试也算积累了一定的经验，不一定适用于 每一个同学，大家可以当作一个参考。 

 好的准备是第一步 ：对于任何一场面试，一定要认真对待和准备，比如当时我们面试前都会把常见排序手写一遍（虽然我没被问到，只是举个例子），千万不要凭运气去面试，提前准备是成功的必要条件。 

 面试过程中的表达能力很重要 ：往往面试官一个问题你可能知道，但如何清晰的表述这个问题自己的看法是关键，尽量在大脑中简单构思一下（如果觉得尴尬就说自己太紧张了，思考一下），然后按点来说；另外对于原理性的问题，借助纸笔来表达也是一个好方法，这点在准备的时候也可以进行，对于一个知识点使用画图的方式来理解。我自己在面试中成功率较高的很大原因我觉得并不是实力，而是表达能力较强。 

 保持自信和谦虚，不懂的问题实话实说 ：面试不光是对你知识的考察，很多时候还会考察一些别的因素，比如思维能力、团队合作意识等等，所以尽量放开了说，保持自信，尽量多和面试官交流。比如面试官问一个问题你觉得比较模糊或者不太理解，就直接和面试官说明，多和面试官交流是没错的。另外如果问到一个确实不了解的问题，实话实说，切记不要在专业知识上撒谎，如果被面试官发现了会很不利，因为抛开专业知识不谈，诚信永远是企业选人的第一标准。 

 保持良好的心态，学会接受失败 ：最后这点是最重要的，在学习、招聘面试的过程中，一定要保持一个良好的心态。因为在面试的过程中，特别是一开始面试经验较少，紧张、焦虑、发挥失常等等情况是难免的，所以说面试不过是一个非常非常正常的现象，一定要能接受自己的失败，当你能够接受失败之后，慢慢的积累面试的技巧和经验，你会发现面试实际上并不难。我认识的人中，有面试了7次才进腾讯的（真人真事），有实习去美图没留下来反而秋招进了腾讯的，特别是大三下开始的那一年，你会经历准备、春招面试、实习、秋招面试等等一系列的事，你还要做很多选择，所以一定要能够保持一个良好的心态！当你坚持下来，你才会发现其实并不难。
