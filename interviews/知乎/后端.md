## 知乎后端开发-一轮面经

来源：牛客网 ｜ 类型：面经 ｜ 发布：2026-06-12 ｜ [原文链接](https://www.nowcoder.com/discuss/895065862061686784)

【岗位描述】

 公司 ：知乎 

 岗位 ：后端开发实习生-研发运营 

 

 

 【面试流程与题目】 

 腾讯会议-40min 

 自我介绍 ：常规流程，突出项目经验和对AI/大模型方向的兴趣。 

 Code Review（秒杀业务） ：面试官给了一段秒杀下单的代码，让找问题。 

 

 主要考察并发安全和事务： 库存扣减 和 订单创建 没有做并发控制，容易超卖；一人一单校验和库存校验存在竞态条件；@Async 异步通知如果抛异常没有兜底处理；事务方法内部调用异步方法，可能导致事务还未提交就发送了通知。

 

 3. SQL性能分析 ：给出建表语句、索引和三条查询 SQL，要求分析每一条的性能问题： 

 

 DATE(create_time) = '2026-06-01'：对 字段做函数运算会导致索引失效 ，建议改为范围查询；

 phone_number = 123456：隐式类型转换， 字符串字段传了数字，索引失效 ；

 多条件组合查询：考察联合索引的最左前缀匹配原则。

 

 4. 算法手撕 ： 

 LCR 076：数组中的第K个最大元素（快速选择/堆）

 977：有序数组的平方（双指针）

 5. Java基础 ：Java锁的底层实现原理（AQS、CAS、synchronized升级过程）。 

 6. 分布式中间件 ：实际项目中有没有用过分布式锁？详细讲讲Redisson底层原理（看门狗机制、RedLock等）。 

 7. AI/大模型方向 ： 

 如果让你设计一个AI Agent系统，数据存储层你会选什么数据库？为什么？

 向量数据库的Embedding Model一般用什么？

 

 【个人心得】

 Code Review 题是亮点也是难点 — 不是让你背八股，而是看你能不能从一个看似正常的代码里找出并发安全问题。

 SQL 优化万变不离其宗 — 核心就两条：「索引最左前缀」+「不在索引列上用函数」。搞懂这两个，90% 的 SQL 优化题都能应对。

 分布式锁要深入到源码级 — 只会 lock.tryLock() 是不够的，Watchdog 续期机制、Lua 脚本原子性、Pub/Sub 通知机制、RedLock 算法，这些都是高频追问点。

 AI Agent 方向的面试要体现系统性思考 — 数据库选型不是简单说「用 Milvus」，而是要结合业务场景分析不同类型数据的存储需求，给出一个完整的存储架构设计。

 后端工程师的高阶面试：从技术深度到问题解决能力

 在当今技术快速发展的时代，后端工程师的岗位需求日益增长。对于那些希望在这个领域取得更高职位或面临更高级面试的人来说，了解后端工程师的高阶面试要求至关重要。本文将深入探讨后端工程师高阶面试中所需的技术深度、问题解决能力以及如何准备应对这些挑战。

 一、技术深度

 数据库管理：深入理解关系型数据库（如MySQL、PostgreSQL）和非关系型数据库（如MongoDB、Redis）的原理、设计和优化。熟悉数据库查询语言（如SQL）以及索引、事务处理等关键概念。

 服务器与网络：了解常见的服务器架构（如LAMP、MEAN等），具备处理服务器和网络问题的能力。熟悉TCP/IP协议、HTTP协议以及相关最佳实践。

 缓存与性能优化：熟悉缓存技术（如Memcached、Redis）以及性能优化方法。了解如何通过缓存、负载均衡等技术提高系统吞吐量和响应速度。

 分布式系统：理解分布式系统的基本概念，如CAP定理、一致性哈希等。了解微服务架构以及相关的技术栈，如Spring Boot、Docker等。

 安全性：具备网络安全意识，了解常见的安全威胁（如SQL注入、跨站脚本攻击等）以及防范措施。了解加密算法和身份验证机制。

 二、问题解决能力

 故障排查：具备快速定位和解决系统故障的能力。能够运用日志分析、调试工具等手段，迅速定位问题并给出有效的解决方案。

 性能调优：能够通过性能测试工具（如Apache JMeter、Gatling等）对系统进行性能评估，并根据评估结果进行相应的优化。

 代码审查：具备良好的代码审查能力，能够快速理解代码逻辑，发现潜在问题并提出改进意见。

 系统设计：能够根据业务需求设计合理的系统架构，并考虑到可扩展性、可维护性和安全性等因素。

 团队协作：具备团队协作精神，能够有效沟通并与其他团队成员协作解决问题。

 三、如何准备应对高阶面试

 深入学习后端相关技术：持续关注后端技术的发展动态，深入学习相关技术栈，掌握前沿知识和技能。

 实践经验积累：通过参与实际项目，积累丰富的实践经验，提高问题解决能力。

 刷题与算法训练：定期刷一些经典的算法题和面试题，提高算法设计和问题解决能力。

 建立个人项目：参与开源项目或自己开发一些有趣的后端项目，展示自己的技术实力和实践经验。

 准备充分，展现自信：在面试前充分准备，熟悉常见的面试问题。在面试中展现自信和专业素养，与面试官保持良好的沟通。

 总结：后端工程师的高阶面试要求具备深厚的技术功底和出色的问题解决能力。为了应对这些挑战，我们需要不断学习新技术、积累实践经验，并做好充分的准备。通过不断提高自己的技术水平和问题解决能力，我们将在后端工程师的高阶面试中脱颖而出，实现自己的职业发展目标。

 总之，后端工程师的就业前景十分广阔，未来将有更多的机会和发展空间。随着技术的不断进步和应用领域的不断拓展，后端工程师需要不断学习和掌握新技术，以适应市场需求和发展趋势。通过不断提高自己的技能水平和综合素质，后端工程师将能够在职业生涯中取得更好的发展。

## 知乎面试(更新)

来源：牛客网 ｜ 类型：面经 ｜ 发布：2018-11-02 ｜ [原文链接](https://www.nowcoder.com/discuss/353154735849021440)

想了想，还是把全部面试经过补完，我现在还没收到offer。

 =======

 在9月中旬投的知乎，投了一直没有反应，过了很久才有测评题，就是笔试题，100分钟选择问答编程题，都不太难，另外笔试没有摄像头监控，这倒是我第一次见。另外知乎的状态也是很迷，搞不清楚。笔试完也过了很久hr才打来电话给我说要面试，由于在外地，所以都是电话面的。

 本人投的后端开发，我用python开发。

 一面:常规的自我介绍，然后计算机网络，操作系统，数据库都有问到，但是感觉有个题库之类的，全程大约40分钟，项目设计不深。

 二两:自我介绍，然后开始聊项目，包括项目设计的一些技术点原理，聊到redis数据结构底层，总共聊了20多分钟吧，之后就是提问，我问了有关职业的一些问题，面试官也超级好，给了我很多建议。

 三面: 直接开始说项目，对于项目里面的点问的还是很细，要详细理解简历上写的东西，然后开始一个系统设计题，如何设计类似朋友圈看动态这种表，包括表的字段，如何查询，分页，取最新的几条数据，在这期间当好友又发布了一条动态，如何查询，以及数据量大了之后的操作。

 我回答的很烂，因为这方面实在不会。最后问平时如何获取热门知识，我说看博客，也不知道如何回答了，总之感觉凉凉了。

 总共耗时38分钟
另外知乎面试很准时，当然了我没有遇到那种不准时的，只是在牛客上看到过一些公司不准时。

另外聊一下面试经验吧，其实只要基础复习到位了，一二面不是很难，我之前也经历过几次面试，也有走到终面的，但是最后都挂了，现在想想可能一二面都是紧张，对于一些点回答不好。后来面试放轻松了，会的就把自己知道的全部说出来，不会的也不害怕，直接说不懂这块。当然了后来面试华为也是，不过华为的面试真的玄，技术问题不多，这个估计看人吧，有些特牛的，面试官也懂就问的多，反正我那个面试官好像不太懂我做的东西，所以问题不多。华为笔试题也不太难，我ac两道，第三道看了就感觉不会，所以没做。我是先面试后笔试的，华为笔试100分就能进面试，至于后面录不录用就不知道了，可能华为有一套比较好的培训机制，对于应届生来说，可能基础好的经过他们的培训有能力胜任岗位，但是我对于华为随机分岗依然有点虚。
