## 献给2022年秋招

秋招战况

 211本软件工程 无实习 前端工程师 珠三角 水平一般 

 投递：111家 

 offer：6家 

 走完流程：9家 

 流程中：2家 

 无消息：46家 

 简历挂：8家 

 笔试挂（包括笔试后无消息）：20家 

 面挂：6家 

 拒笔面：18家 （不想要继续走流程or不满意职位） 

 学习时间线 

 在校学习后端开发和深度学习，从2月份开始自学前端。没有任何的实习经历，只有三个前端项目（一个小程序、一个nodejs、一个vue）和个人搭建的博客。

 
 

 2月份开始使用牛客，想赶上暑期实习的热潮，实则什么都没捞到，盲目的刷笔试题，知道了自己对前端知之甚少，3月份开始系统学习，学三件套、js高级、ajax、http、jquery、vue、nodejs，补算法题。5月底才投递了第一个暑期实习，二面挂。知道自己学习程度还不够，不再盲目找实习，开始做vue项目，6月份忙期末考试+做vue项目。7月份继续完善我的vue项目，8月份搭建自己的博客和将所有的项目上线。

 
 

 秋招之旅 

 8月中旬被字节hc捞起来投提前批hh，但是只能去北京上海，广深简历挂便拒绝面试。8.10秋招的第一份简历献给大疆，当然做完笔试就挂掉了hhh。8.22开始正式的秋招，一开始的目标是互联网中厂（知道自己水平有限），只找珠三角地区的工作，但是珠三角地区今年互联网中厂基本没有什么hc，8月底开始海投所有大中厂（不分行业）。笔试做到头昏眼花，面试也在9月初接踵而来，非常的忙。第一个走完流程的是广发银行，hr面完的当晚，我以为我要脱离秋招的苦海了，但是没想到只是进了第一个池子hhh。

 
 

 一直没有走完的流程，焦灼的我从9月底（9.17）开始海投全广深的小厂甚至是小公司。电话接踵而至，当然不是期待的公司，但是感受到了原来自己不会失业，还是有工作的。也是9.19-9.26这一个星期，我的四个offer都来了。先是9.20的美的线下群面，抱着见世面的态度去面试了，确实感受到了自己的水平有限和广州人才济济。第二天去线下面试了银行和一家外企，外企直接当场定下来要我，面试官非常友好，肯定了我的价值，可惜只是实习转正offer（该公司无开校招），所以仍让不是特别满意。没几天，竟收到了美的的二面，过后两天便收到了第一份正式offer，不管怎么样，它让我有底气勇敢面对秋招，第二天签约会鸽掉了两场面试。美的确定签约的第二天，富士康hr在面试时也当场定下来要我，可惜待遇不如美的，便拒绝了。月底又收到了线下面试银行的offer，9.27号正式开始摆烂。

 
 

 当过完国庆假期后，我打算打起精神继续秋招，10月份不如9月份热闹，隔三岔五的面试，我再也找不回我的秋招状态了，因为我已经进入了疲惫期。我开始了躺又躺不平，卷又卷不动的日子。

 
 

 10月27日申请完三方，我意识到我的秋招结束了。

 
 

 11月又收到了两个offer，一个深圳平安产险26w，一个广州东风日产20w-24w，大概率也不去了

 放在最后 

 秋招给我带来了什么呢？

 首先，寒气！深深的寒气，互联网并不欢迎我这种没有实习，不能解决任意场景题，算法题不能全a的人。这次秋招，我认识了许多研究生，在每个流程，每个池子中认识，我甚至觉得会不会本科生才是稀有物种呢？他们是暑期实习第一场战争的胜利者，但是却因为没有转正名额，被迫投入到秋招中。再者，我好久没有静下心学习了，上一次静心学东西已经是8月份了。我每天都很浮躁，我想这如何用最短的时间最大化的提升自己，秋招让我变得好迷茫，好丑陋。最后，我认识了很多好朋友来自五湖四海，我很开心！

 
 

 最后我想跟屏幕前的24届同学说，放低期望，静心学习（不要被别人影响你的节奏），早日投递，不用执着大厂，你会有你最好的归属，无论是哪里。（只代表我个人水平很一般一差的软工人，大神忽略！！！）

## 最好的推荐给最美的你

来源：牛客网 ｜ 类型：面经 ｜ 发布：2017-10-26 ｜ [原文链接](https://www.nowcoder.com/discuss/353154237578289152)

写在开始 

 我一路走来，不念过去，不畏将来。 

 感谢叶神创造了牛客网，受益匪浅，跟下面推荐的书籍、视频一起，表达谢意。 

 目前拿到的offer有，百度大搜（sp、上海）、美团酒旅（S级、北京上海可选，求职体验最好）、好未来学而思（SSP、北京）、招银网络（杭州）、携程机票（上海）。最后选择了百度。 

 既然写在开始，希望大家放平心态，不要装逼不止、不要妄自菲薄。有清北找工作成绩平平的，有一般学校找到很不错的工作的，人这一辈子，拼的是个时间，是份坚持，慢慢走，不要着急。 

 楼主本科东南，硕士北航，自动化专业，非科班出身，本没有想过会走上程序员这条路，也是机缘巧合吧，大四的时候，跟清华经管女友分手，重新思考人生，走着走着就习惯了。另外，也感谢东南的几个大哥，曾经的指导和帮助。 

 愿那个努力的你，终将收获所得。 

 心中无敌，无敌于天下（《毛骗》里的话，经典）。 

 资料推荐 

 为什么要写这样一个推荐？发现牛客太多的面经笔经质量参差不齐，但成体系的推荐资料不多，希望能来一波溯本清源的推荐。在这里不求最全，但求都是自己真正看完，最实用，最爽，最感动的。 

 那一堆面经笔经，列出一堆题目，想必你也不会一个一个看，看完你不去找答案也是浪费时间。最好的办法就是先自己系统的学，然后多面几家找找感觉，所以越早准备越好，晚了也别着急，我给你推的资料，怕是能起死回生[捂脸]。 

 想清楚自己找的岗位，到底是算法还是研发，面试区别不小。 

 另外，选研发岗的话，假如简历提到多种语言，面试官肯定会问你是要选C++，还是java面？说个小经验吧，我回答的是，本科时候接触过Java，不过后来用 C ++ 多些，熟一些，用 C ++ 来面吧。 

 注意：你针对的是找工作，不要看什么汇编了，自己有兴趣以后在研究，面试的时候真的不实用！！！

TreeNode* buildTree(int *preOrder, int & index) {
 int value = preOrder[index++];
 if(0 == value)
 return NULL;
 TreeNode* root = new TreeNode(value);
 root->left = buildTree(preOrder, index);
 root->right = buildTree(preOrder, index);
 return root;
}
