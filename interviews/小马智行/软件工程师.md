4. 反问

coding挺顺利，发散和优化也都写出来了，第二天就约了二面

二面（代码）：
1. 简单自我介绍
2. 吟唱项目，主包的自驾有关项目都是很早之前做的了，被狠狠批判是上一代的圣遗物了 
3. coding 不能透题，抽到了一个数学相关最短路径题
4. 反问

面试氛围挺平和，但主包太菜还是有点压力，
coding边画边说思路边修改，最后还是写出来了，但发散的问题没给出很好的回答，我的解法用来拓展的话复杂度太高
小马的coding都是自编题，第一次做这种题差点要凉了，还好绞尽脑汁还是记起来了函数名和用法
建议记一下sqrt atan2 asin之类的数学函数，需要走弧线... 

听潜意思是经历不够也不匹配，代码写出来了但也不是很完美，应该要止步于此了，可恶啊还是做不到吗 

update：
主包看广告复活了，二面居然第二天就给过了，惊为天人，下周三面继续蠕动

三面（项目+八股）：
1. 简单自我介绍
2. 吟唱项目，会深挖细节和相关机器学习八股，针对缺点问改进的想法
3. 没有coding
4. 跟项目方向相关的一个场景题/开放题
5. 简单的python八股
6. 反问

面试氛围挺好的，交流的时候很平和，三面已经没有coding了，但我看最近的面经还是有人有coding？可能因人而异
三面重点已经转向项目了，建议自己多走几遍项目内容，在介绍的过程中会问相关的八股和改进的想法
最后问了一些python八股，先问的是C++熟不熟悉，主包说本科常用但后来荒废忘完了，然后就问的python，所以感觉如果回答熟悉的是C++就会问C++八股？
还问了对大模型相关有没有了解？主包说没有上手微调过但是了解像LoRA之类的调参方法，也做过prompt/CoT/MoE之类的课程小项目，然后立马就被问了LoRA的具体内容（答上来了，主包没有乱说），所以说不懂的还是老实说不知道比较好

第二天就约了四面，继续蠕动！ 
好想进小马啊，马年进小马是对的，主包生来就是为了进小马的啊 

四面（项目+八股）：
跟三面差不多，依旧项目+机器学习八股，但后面还聊了会天
问了DETR相关，让介绍
算是四轮技术面？

然而四面完两天依然没给结果，问hr说是面试官回家过年了，要等年后出结果

2026/2/24 update：

2026/2/27 update：
