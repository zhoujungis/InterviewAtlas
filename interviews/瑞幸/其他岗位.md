群面：一个大房间里好多个人，分了四组，每个组8个人左右
无领导小组做案例，限时半小时，每个组旁边有HR观察打分。

我做的事儿主要包括：
1接HRBP递给我们组的案例Paper然后分发给成员，借笔给其他人
2率先自我介绍，然后指定顺序（了解了一圈，专科生居多，本科好像有两个，然后一个深大的研究生）
3用手机计时，给小组提建议先阅读五分钟再讨论
4指出case中的关键任务，然后引导大家发言
5后续讨论中多次主动发言➕总结他人发言然后推进讨论进展+多次指出时间紧张，拉回钻牛角尖的发言
6自荐上台发言
关键就是要多主动、礼貌地主动，体现你的领导力。
上台做pre的人会收到瑞幸给的小礼物，一个徽章。

单面可能是1v1，也有可能是1v2，2v2、2v3这种，因为深圳分公司的现场来了很多候选人，现场稍微有点混乱，看你的运气和眼力界了。
单面的内容，主要就是HR针对简历稍作提问，然后了解你住在哪，能不能提前实习，薪资、工作压力之类的能不能接受，主要就是聊天，你大方自然地回答就行。比较轻松。

## 如何偷偷在上班时参加面试

来源：牛客网 ｜ 类型：面经 ｜ 发布：2023-07-09 ｜ [原文链接](https://www.nowcoder.com/discuss/507505928200036352)

相信很多同学都会遇到如下情境：

 1、正在实习，但对目前的实习不太满意，想要骑驴找马。

 2、正在实习，但秋招 / 春招已经来临，想要赶快投递。

 然而，几乎所有的实习都是安排在工作时间，因为面试官通常都是正式员工。这使得想要在非工作时间参加面试基本变成了不可能。此外，即使下定决心在工作时间参加面试，面试的具体的时间也难以在工作时间内随意调换。因为正式员工往往会在某个时段有抽不开身的事情要做（比如：会议），作为实习生的我们也时常会遇到类似的情况（比如：开会、有ddl要赶）。所以，如何在工作时间闪转腾挪，找到参加面试的机会就变得什么重要。在此，我先介绍下自己的经验：

 首先， 心理建设这一关要过 。通常很多时候我们不敢在工作时间去面试，往往都是因为心理上觉得愧疚 / 恐惧。

 其次， 工位要选的好 。有的公司可能不会限制实习生的工位一定要在某处。如果你选择工位的权利比较大，可以选择一个尽可能避开mentor / leader的工位。

 再次， 时间要选的好 。通常面试时，hr都会先和你沟通一下具体的时间，此时你进行一定的调整是没有问题的。而在此时，除了确定自己的时间是否合理外，最好要打开你的内部沟通软件，看看你的mentor / leader的日程表，专挑他们要去开会 / 午睡 / 摸鱼 / 其他你总结出来的他们会离开工位的时间。这样可以尽可能的掩盖掉你不在工位的尴尬。

 此外， 地点要选的好 。最好的地点自然是公司内部的会议室。但是考虑到会议室资源普遍比较紧缺，且能看到是谁预定的，通常难以作为面试时的可选项。此时，还有哪些选择？就我个人经验而言：

 1、过道 / 楼梯间。此种场景适合你的面试是电话面试。缺点：可能会有人经过并发出声音。优点：可以借口自己只是去接了个电话，电话的那头可以是任何人，但就不是面试官。就亲身经历而言，我在楼梯间里电话面试过，只要不遇到熟人，整体上打个电话问题不大。而且电话面试通常不会太久，回来时可以假装出一副被便秘 / 窜稀折磨的表情，嘴上再说着：早知道昨天晚上不吃夜宵了的样子。如果你入戏了，还可以装模作样的询问你的mentor，xx哥 / 姐：公司有没有便民药箱，我的肚子要x了。相信我，如果你的演技够逼真，大家对你更多的是关心，而不是怀疑。

 2、茶水间。这种场景可以开展视频面试。缺点：可能熟人被看到 / 听到。优点：环境较好。但整体来说是一种冒险的选择，除非你能确定你的同事上班基本不喝水 / 不摸鱼 / 不到茶水间吹b。

 3、附近的餐厅 / 咖啡店。通常在非饭点，餐厅 / 咖啡厅的人会比较少，而且光鲜相对充足，又有位置可以坐下。点上一些吃的喝的，或跟店员沟ai通qiu一下，通常可以获得一个座位。此处推荐地点：麦当劳、肯德基、星巴克、瑞幸等存在贩卖空闲空间意识的连锁品牌。缺点：要花点小钱并且脸皮要厚；有的店会有bgm影响面试的安静度，时间长了会产生一种自己是精英的错觉。优点：环境通常较好、可行度较高（因为写字楼附近通常不会缺少快餐/咖啡厅），被发现了可以借口只是出去找个环境办公。就本人亲身经历而言，我自己就在单位旁边的麦当劳的天台上面试过，其实也还好。

 4、附近的公共座椅。有些写字楼的内部 / 外部会提供一些公共座椅供访客稍作休息。如果公司的楼层较高，那么可以选择跑路出来到这些座椅上参加面试。缺点：可能会遇到迟到 / 出差归来的领导 / 位子被占了 / 取外卖的同事；可能会吸到二手烟；户外的座位可能受到天气的影响；有噪音。优点：有个位子，而且通常没人管你在位置上干啥。我曾经在公司外面通道旁的小桌子上面过一次试，除了对面的大哥一直在抽烟外，整体还算ok。

 5、直接回家。如果你租住的挂逼房距离公司较近（骑车就能15min内到达），那么可以选个11.30这样的时间，以早去吃饭为理由直接11.10出发，回家参加面试。缺点：这种房子不一定好租。优点：环境基本无可挑剔，可以自由发挥。

 最后，其实 最理想的状态便是让你的mentor和leader同意你参加面试 ，但这需要凑齐以下几个条件中的某一条（重要性依次递减）：

 0、 有个好爹 / 干爹 / 妈 / 干妈 / 另一半 / 非正常关系的另一半或其他愿意帮你的人 。如果上述人群中的人足够牛逼，你只需在不经意间提及：我的xx是干xx的。此言一出，通常就可以大摇大摆的工位上做你想做的事情了。相信再没有情商的mentor和leader也会明白一个朴素的道理：生命只有一次。看到这，你可能会觉得这是爽文中才会发生的桥段。但是如果你在金融机构实习过，你就会明白， 这种事每天都在上演 。

 1、 mentor和leader或其他实权领导对你充分理解 。这也是最难的一点，这种情况需要靠 运气 实现。

 2、 和实权领导们的关系较好 。如何和人处理好关系，是一门深奥的话题，在此不做展开。据观察，通常能和人处理好关系的人，基本上不用发愁自己没有好工作。

 3、 工作能力极为出色 。通常职场人也不是傻子，大部分人都有一定的功利心，懂得扩展人脉的重要性。如果你的能力足够出色，大部分人会产生一种：我难为他，万一他以后牛b了，岂不是利用不上了的心理。此时，稍微聪明点的人都会睁一只眼闭一只眼。 人的势力和钻营通常会在看到潜在的利益时表现的淋漓尽致，哪怕这利益并没有那么大。 

 写在最后 ：

 说到底，真正影响你在上班时参与面试的还是自己的 思维方式 ，或者说 三观 。

 如果抱着 利己 的角度出发，成为一个现实主义的人，那么一切都不是问题，即使遇到领导的责难，心里也不会有一丝犹豫。如果选择成为一个遵守规则、道德的理想主义者，那么在工作时参加面试几乎是不可能的事情，那种恐惧和愧疚会不停的折磨着你，哪怕是秋招颗粒无收，也虽九死其犹未悔。毕竟这是从小到大，我们当中的大多数人被教育要成为的那种人。

 在是否要上班参与面试这个问题上，不同的选择通常代表着人与人之间不同的思维方式。

 这不禁让人想到黑客帝国里剧情：蓝色和红色两枚胶囊，你会选择哪一个？是残酷但真实的现实，还是温暖但虚假的理想世界。

 不同的选择累积起来，最终会带来不同的人生。

 但或许本质上，没有哪种选择是错的，也没有哪种选择是对的。

校招-南方区域BG-营销方向 10-17收到一面通知 

 10-18线上小组一面 

 我们组五个人，面试环节分为两部分。 

 第一部分是即兴演讲，形式是每个人四分钟时间，自我介绍加命题回答，题目是从一个题库里面抽取，有1-27个题目可以选择，我选的是7，题目是网红直播对青少年的影响，问题是是否支持青少年去直播，回答需要包括对问题的思考以及回答。大概时间分配我是一分钟自我介绍，剩下的去回答问题= 

 我是第一个回答，本来以为有思考时间，结果念完题目直接说你可以开始了，我真是有点懵，回答的感觉也不是很好。后面的人看了我的情况就有经验，在面试官念题后要求多念一遍面试官也答应了，感觉是一个不错的小技巧，给自己多点时间思考。 

 第一部分我们组其他人的命题有： 

 瑞幸咖啡丑闻事件你的看法 

 "房住不炒"问题的看法（第八题） 

 "舌尖上的浪费"问题的看法 

 目前90后95后在岗位上的跳槽几率远大于80，70后，说明你的看法（第十题） 

 第二部分是所有同一个命题回答，问题是你最近看到的有意思的短视频进行分享，并说明理由，时间两分钟。顺序是刚刚即兴演讲的顺序倒过来，我就是最后一个说，给了我一些准备时间😂还是比较庆幸的。最后我讲了一个王者荣耀得过年短视频广告hhhh其他的有讲汽车有讲奢侈品广告的，个人感觉言之有物即可，有东西有思想就好。

 一面晚上大概九点多来的二面通知，万科的速度还是蛮快的=

 案例分析后，面试官针对我的回答问了相关问题，比如我为何给出了这样的解决方案等等，之后是类似宝洁八大问的问题，对个人进行深入了解，并询问了意向城市和接不接受调剂。
