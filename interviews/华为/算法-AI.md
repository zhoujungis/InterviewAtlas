 1.算法岗投递、面试与考察情况

 目前来看的话，我还是集中在AD算法上进行投递，进一步细分，主要集中在决策、决策规划、决策规控、两段式端到端、一段式端到端上，后期有投递一些具身岗位来补充整个投递的岗位多样性，毕竟我海投才能入池，入池才有机会。

 对于一些公司为何简历挂，网络众说纷纭，我也不清楚究竟是何种原因，在有结果时，或许过程就不重要了。

 对于一些公司的面试后挂，我认为可能存在着公司转型、实际业务需求与求职者之间的不平衡矛盾。有的岗位表面上是写的算法岗，做模型、做数据、回测、conner case挖掘……，实际呢？也许就是功能的测试（大抵是与测开较为类似）、供应商对接、多部门协同（扯皮）的实际工作。而这些应该还是很难摆在台面上的。

 从当前已有的公司对算法岗在面试过程中的考察来看，需要兼顾深度和广度，深度是我的基本盘，我把我投递岗位上大部分主流论文过一遍，简历吃透，打造solid项目之后，基本上能深入聊的，我基本都过了，广度我觉得算小基本盘+大拓展盘，深度应该是决定了你的下限，而广度一定层面能拔高你的上限。小鹏的vla算法二面还有华子的技术一面二面就是很好的例子，经过沉淀后的广度还是很有用的。另一个方面，算法岗最不缺的就是技术了，对我来说，我认为技术要注重3个方面：

 首先是hot100 。基本功，从我经验来看，我建议至少2遍以上。力扣是要经常做的，保持手感。题单我跟的是灵神，我师兄建议我的代码随想录，不过很早就跟灵神题单了懒得换。尽量都会手撕。

 其次是Attention和Transformer 。Attention is All you need。伟大无需多言，经典的要能手撕，尤其是MHA，如果你用了不同的att变种，关键改进点要会手撕，大部分考察都是变量的计算过程和维度变化，少部分考察要用torch来写，个人感觉做到大部分差不多。

 最后是论文 。你投递岗位对应的最近的sota或者新的圣经论文，比如AD这边的UniAD，Pluto，Diffusion Planner等等，这些论文建议至少半精读过一遍，免得一些技术面中的发散性问题你面不够广而被刷（在AI时代，你个人的广度的重要性不必深度差，这点不多说了）

 简历考察情况的话主要是实习和项目吧，这两大方面感觉大佬们都说的七七八八，我的一个心得主要是以下几点：

 如果不够深入，不够solid，工作量不够多，其实简历上写最基本的没问题，但是需要自己沉淀，用ai来辅助学习你这段实习中未遇到但可能遇到的问题，比如LLM训推可能遇到oom/memery bound，不管你遇到没遇到，这种场景中算一个常见问题了，那么一些解决方法和技术原理需要知道。小鹏二面血泪史啊……

 其他就是瞄着solid准备吧，也就是你要清楚你做的这个东西，能力边界在哪，哪些是做不到的，这根线很重要。也许你会反驳我，大包装时代了，天天都是挑战者，solid何用只有？说的也对，关键是让面试官觉得你这个东西是solid就够了。这即是修行的过程，也是修行的结果。

## 分享4年经验面华为AI岗，OD机试过了，技术面差点挂

来源：牛客网 ｜ 类型：面经 ｜ 发布：2026-09-03 ｜ [原文链接](https://www.nowcoder.com/discuss/924967062357692416)

普通本科，Java/Python混栈，4年经验，上一家是某中厂AI平台组，负责过模型推理服务和大模型应用开发。

 华为AI岗面试从OD机试到技术面，过程非常标准化。三轮技术面全过了，结果HR面薪资没谈拢，又重新投了另一个部门才OC。

 📌 第一阶段：OD机试（6月）——过了 

 华为的机试和OD机试共用一套题库逻辑，重点在数组、字符串、栈队列、双指针、动态规划这些常规内容上。我提前刷了LeetCode Hot 100，又找了华为OD机试的模拟题过了一遍。

 机试3道题，2道AC了，1道过了80%。过了。

 📌 第二阶段：一面（7月）——差点挂 

 一面（60分钟） 

 1️⃣ 项目深挖：你们AI推理平台的QPS多少？怎么保证高可用？ 

 💡 思路参考 ：4年经验的面试，面试官默认你负责过核心系统。日均推理请求300万，峰值QPS约800。高可用靠三层——多节点部署（负载均衡）、熔断降级（大模型API超时走规则引擎）、故障自动恢复（K8s健康检查+自动重启）。重点说 你作为负责人是怎么设计的，不是只参与了 。

 2️⃣ 追问："如果大模型API调用超时，怎么保证用户体验？" 

 💡 思路参考 ：超时处理分三层——调用层超时（设置合理timeout，如5秒）、业务层降级（超时后返回"正在为您处理"的异步模式或走规则引擎兜底）、用户体验层（异步任务轮询，用户不阻塞等待）。核心是 用户体验优先+异步化 。

 3️⃣ 华为AI岗特色：日志字段识别 

 💡 思路参考 ：华为AI岗面试官关心的是你拿到一批设备日志时知不知道哪些字段值得喂给大模型。实操中先做字段分类——结构化字段（时间戳、设备ID、错误码）直接解析，非结构化字段（错误描述、堆栈信息）做文本预处理后喂大模型。关键不是所有字段都喂，而是 根据业务价值选择喂哪些字段 。

 4️⃣ 手撕：LRU Cache + 并发追问 

 💡 思路参考 ：HashMap+双向链表。追问并发时用ConcurrentHashMap+读写锁。华为面试官会追问"线上场景中LRU的淘汰策略怎么选"——LFU适合热点稳定场景，LRU适合时效性强的场景。

 一面面完感觉一般，项目答得还行，等了三天，过了。

 📌 第二阶段：二面（7月）——过了 

 二面（60分钟） 

 1️⃣ 系统设计：设计一个智能运维告警系统 

 💡 思路参考 ：日志采集（Filebeat/Flume）→日志解析（正则+结构化提取）→异常检测（规则引擎+AI模型）→告警聚合（按设备/时间窗口聚合，减少告警风暴）→通知推送（邮件/短信/钉钉）。核心难点： 告警降噪 （用AI识别真正需要人工介入的告警，过滤掉误报）、 根因分析 （关联多设备日志，定位故障根因）。4年经验要能说出 告警聚合策略 ——按设备ID和时间窗口（5分钟）聚合，相似告警合并。

 2️⃣ 追问："如果告警系统挂了，怎么保证运维不瘫痪？" 

 💡 思路参考 ：告警系统挂了走降级——核心告警走硬编码规则引擎（不依赖AI），非核心告警延迟处理。同时触发告警通知运维人工介入。核心是 核心链路优先+人工兜底 。

 3️⃣ 线上故障排查 

 💡 思路参考 ：说一个真实的P0级事故。某次模型更新后推理延迟飙升，排查过程：看监控确认故障范围→查模型推理日志（发现新模型参数量是旧模型的3倍）→查GPU利用率（从60%涨到95%）→回滚到旧模型→恢复。事后复盘：模型上线前没有做性能压测、没有设置自动回滚策略。

 📌 第三阶段：三面（交叉面，60分钟）——过了 

 1️⃣ 系统设计：设计一个AI Agent智能客服系统

 首先华为这家企业，它是88年成立的。华为在市面上，在中国所有的企业里面，我认为综合实力，它没有上市啊，市值不知道多少，但是华为我认为在国内的企业绝对能够排第一。那很多朋友可能会看盈利，可能会看流水。我跟你讲讲华为有多强，你会发现互联网企业，就是市面上现在互联网企业确实薪资给的比较高，因为它的整个利润比会很高。那你会发现市面上互联网的企业后面会越做越像会越做越像，业务都是面向于所有的用户群体，你会发现所有的业务会越来越像，但是你会发现华为啊每一个都很强，你有见过华为哪个业务做的不行的吗？你比如说像显卡啊，然后包括像鸿蒙操作系统，乃至包括4G 5G的通信业务，乃至包括手机终端业务，乃至数通业务，每一个都很强。真的华为是很强很强的，美国率先制裁的就是华为，你要想一下，对于一个国家能够去制裁中国的一个企业，首先制裁的是华为，为什么没有像腾讯、字节？当然字节也有被针对，只是针对而已，但是你会发现制裁，只制裁的是华为。

## 华为产品行销经理 面经

来源：牛客网 ｜ 类型：面经 ｜ 发布：2022-03-18 ｜ [原文链接](https://www.nowcoder.com/discuss/353159367295967232)

目前测试全绿等offer，在牛客看了很多前辈的面经，于是也写面经攒攒人品

 背景：本科末流211非科班，22考研炸裂，参加春招。已拿到两个个小厂、两个国企和央企offer，基本都是产品、项目和运营方向。在校学生工作比较多，有几个学生干部经历，有编程基础，自学过机器学习nlp方向的一些东西，打过一些比赛，但没有什么好的成绩，无实习经历。（感觉自己经历稀烂，能过简历已经很不错了）

 
 

 时间线：

 3.10 华为来学校宣讲，宣讲结束就投了产品行销岗。

 3.11 下午打电话通知简历筛选过了，通知大概周一周二面试，当天发了性格测试和保密协议

 3.12 发了英语测试，5个句子朗读（会先让你看，时间充足），15个听力（听力材料很短，注意力要集中，很简单的）。2个topic（一分钟思考，2分钟说，这个真就看个人能力了，我就图流畅讲了1分钟就结束）

 3.14 群面 50min

 （建议面试认真对待，提前准备，穿正装，找个合适的场地） 
 

 群面是个两难题（经典题目），7人，先1min自我介绍后给材料，读题3min，讨论20min，最后由一个人汇报。整个面试的过程中最好做好记录，无论是自我介绍还是后面讨论，自我介绍的信息可以拿到一些个人特点，后面汇报的时候可以推举，同时还有一个发言顺寻问题，当是我们有个同学提议按照自我介绍顺序，我提前记录了所以前一段讨论基本是我两主导。我们是计划一人一分钟7min，讨论8min，最后总结给汇报人5min。时间把控很重要我们这一组在时间上极度拉跨，最后也是匆匆汇报，想要得分高一定要有效讨论，推动进程，不要车轱辘话翻来覆去，不要重复观点。我当时感觉我前期发言太多，后面更多的是记录和补充。我个人认为这个环节有几个关键点吧：1、框架搭建，如果能给出第一个给出料理清晰结构明确的框架，是一个两点，后面的事基本都是在补充和完善框架，所以如果有能力的话，发言靠前是很有优势的。2、进程推动和流程把控，根据时间和讨论情况适时的推动小组讨论进度。3、有效发言，不要老是跟随前面人的观点，要对现有观点进行补充和扩展，证明你有效参与讨论。4、观点变化，两难题一般可能有不同意见，前中期可以提出不同意见，但是中后期最好符合主流观点不要死磕了。最后注意发言举止得体！（最好不要抢角色，你的角色不是抢到了就是，你在团队中表现的什么样，你就是什么角色）。一天绿了

 3.16 专业面 45min

 面试官很和蔼应该是部门产品线上的人，就问岗位的理解、个人能力的匹配再深挖简历，面试过程中会抓你回答的漏洞或者感兴趣的地方追问，问了我5g相关应用，对我自学机器学习问了很多，比赛经历也问了很多。半小时绿了 
 

 3.17 主管面 30min

 面试官甚至比上一个还和蔼，整个提问层次明显高了，主要问了个人情况、外派、岗位相关，也是问了机器学习和比赛经历，感觉主要是考察岗位契合度和岗位忠诚度。他首先是问家庭，我基本猜到了它的意思（能不能外派，服不服从公司安排）然后从家庭、婚姻、个人规划三个层次给的答案。之前看了很多面经，他想问的基本我都直接就回答了。我是英语6级没过本来以为会考个topic，连夜写了15篇小作文，还没考，呜呜呜。 半小时绿了。当天全绿 
 

 
 

 全绿当天就询问hr英语测试和性格测试，也都是全过，能做的都做完了，后面就等offer了

 （写个面经攒人品，希望offer马上来）

 
 

 3.29 开奖了，当天oc+意向，同批其他人也拿到了offer。牛客真的牛，希望都有心仪的offer

 * }
 */
class Solution {
 public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
 ListNode head = null, tail = null ; 
 int carry = 0 ; 
 while (l1 != null || l2 != null) {
 int n1 = l1 != null ? l1.val : 0 ; 
 int n2 = l2 != null ? l2.val : 0 ; 
 int sum = n1 + n2 + carry ; 
 if ( head == null) {
 head = tail = new ListNode(sum % 10 ) ;

 tail.next = new ListNode(sum % 10 ) ; 
 tail = tail.next ;

 l1 = l1.next ;

 l2 = l2.next ;
