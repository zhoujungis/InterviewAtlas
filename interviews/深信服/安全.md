## 干 ICT 怎么找好工作？老司机经验全分享

来源：掘金 ｜ 类型：面经 ｜ 发布：2026-06-16 ｜ [原文链接](https://juejin.cn/post/7651882379419156506)

ICT行业涵盖网络工程、系统集成、云计算、网络安全、运维、数通设备调试等多个方向，岗位细分多、用人需求偏向 实战能力 ，和纯文职求职逻辑差异较大。结合行业特性、一线岗位要求以及圈内实操经验，阿祥从 自我定位、能力打磨、渠道选择、简历优化、面试通关、入职谈薪 六大维度，梳理一套可直接落地的高效求职方案，适合应届生、转行人员、在职跳槽的全体ICT从业者。

 一、第一步：精准自我定位，拒绝盲目海投

 ICT岗位分工明确，技能栈、工作内容、薪资门槛天差地别，先找准方向，求职效率至少提升一半。

 1. 梳理自身技能与从业方向

 结合掌握的技术、项目经验划分赛道，主流方向参考：

 
 数通/系统集成 ：主攻交换机、路由器、防火墙、负载均衡，擅长组网、堆叠、链路聚合、故障排查，适配集成商、政企运维、项目交付岗位，也是入行人数最多的赛道。

 网络安全 ：熟悉攻防、准入认证、安全策略、等保合规，面向安全厂商、政企安全运维、安全服务岗位，近年岗位需求持续上涨。

 云计算/服务器运维 ：精通服务器、虚拟化、云平台、存储设备，适配IDC、云厂商、大型企业运维岗。

 政企运维 ：偏向综合能力，兼顾网络、桌面、服务器、简单弱电，工作稳定，适合追求长期安稳的从业者。

 
 同时区分 工作场景 ：集成商（出差多、项目型工作）、厂商（技术支持/售后/售前，技术要求高）、甲方政企（坐班稳定，运维为主）、外包（门槛适中，过渡首选）。

 2. 划定目标城市与薪资预期

 一线城市ICT岗位多、技术氛围强，但竞争激烈；二三线城市以政企运维、本地集成商为主，出差少、节奏平缓。结合生活成本、职业规划锁定1-2个核心求职城市，同时根据自身水平划定合理薪资区间，避免高不成低不就。

 3. 匹配岗位层级

 
 零基础/应届生：优先 初级工程师、运维助理、技术实习生 ，侧重学习机会，不纠结起薪。

 1-3年经验：主攻 中级工程师、项目交付、驻场运维 ，突出项目实战能力。

 3年以上资深人员：瞄准 技术主管、售前工程师、项目经理、高级运维 ，侧重方案设计、项目统筹能力。

 
 二、第二步：打磨核心硬实力，打造岗位竞争力

 ICT行业 重实操、轻空谈 ，证书、项目、实操能力是三大核心加分项，也是企业筛选候选人的核心标准。

 1. 补齐必备技术栈，聚焦主流厂商

 国内政企、集成商主流设备以 华为、华三、锐捷 为主，其次是深信服、迪普等安全设备，不用盲目学习全品类厂商，优先深耕1-2个主流品牌。

 
 入门必学：VLAN、静态路由、OSPF、VRRP、链路聚合、交换机堆叠、基础防火墙策略，掌握标准配置命令与常规故障排查。

 进阶提升：VPN、ACL、安全策略、802.1X准入、设备巡检、网络拓扑梳理、全网摸排，这些是系统集成、驻场运维的高频工作内容。

 工具加持：熟练使用IP计算器、终端仿真工具、流量分析工具，日常多用行业工具提升效率，也是面试隐性加分项。

 
 2. 证书按需考取，不盲目堆证

 证书是求职敲门砖，不同岗位适配不同证书，拒绝无效考证：

 
 入行/初级岗： HCIA、H3CIA 性价比最高，难度低、认可度广，适合应届生、转行人员。

 进阶/项目岗： HCIP、H3CIP ，集成商、厂商技术岗优先认可，薪资溢价明显。

 安全方向：CISP、等保相关证书，政企安全岗位硬性加分项。

 补充说明：证书只是辅助， 有证无实操 极易在面试实操环节被淘汰，务必做到“证书+实操”同步。

 
 3. 沉淀项目经验，整理实战案例

 企业招聘ICT人员，最看重 落地项目经验 。没有全职工作经验，也可以通过实训、模拟项目、自学实验积累案例：

 
 整理过往参与的项目：标注项目名称、客户类型（政府/学校/企业）、负责工作（设备调试、组网、排障、巡检）、用到的技术与设备。

 自制模拟项目：利用模拟器搭建园区网、中小型企业网络环境，完整复刻组网、配置、排障全流程，可作为面试案例。

 记录故障案例：日常遇到的网络卡顿、SSH连接异常、堆叠分裂、广播风暴等典型问题，整理排查思路与解决方案，面试高频提问。

 
 三、第三步：选对求职渠道，精准触达岗位

 不同渠道适配不同岗位类型，结合自身方向组合使用，告别低效海投。

 1. 主流综合招聘平台（通用首选）

 
 BOSS直聘 ：沟通效率最高，可直接对接HR、技术负责人，适合应届生、初级工程师、跳槽人员，优先筛选“直聊”岗位，主动发起沟通。

 智联招聘、前程无忧 ：大型集成商、国企、政企外包岗位居多，岗位体量大使，适合追求稳定工作的求职者。

 技巧：每天定点刷新简历，岗位筛选时勾选“近期活跃”，避开长期挂岗的无效职位。

 
 2. 行业垂直渠道（精准度最高，推荐重点使用）

 这是ICT圈内求职的“隐形捷径”，岗位匹配度远高于综合平台：

 
 技术社区与博主社群 ：CSDN、掘金、行业公众号、网工交流群。像ICT系统集成、网络工程师类垂直博主，粉丝群体以企业IT负责人、集成商技术主管为主，常有内部岗位、内推信息发布，内推通过率远高于社招。

 厂商官方渠道 ：华为、华三、浪潮、深信服等厂商官网、招聘公众号，原厂岗位薪资、福利、培训体系完善，技术成长空间大。

 行业微信群/QQ群 ：本地集成商、运维交流群，大量驻场、项目外包、临时项目岗位，入行过渡期首选。

 
 3. 线下与内推渠道（高阶首选）

 
 内推 ：ICT行业圈子小，熟人内推是最高效的方式。联系前同事、实训老师、技术网友，企业对内推候选人优先面试、放宽筛选条件。

 线下招聘会 ：各地软件园、电子信息产业园专场招聘会，直面企业技术面试官，适合应届生。

 
 渠道使用策略

 初级求职者：综合平台+行业社群 组合投递；
资深/技术岗：优先内推+厂商直招，减少海投；
想进政企单位：重点关注国企、外包服务商招聘公告。

 四、第四步：定制化简历，让HR一眼锁定你

 ICT简历拒绝模板化、空话套话， 内容围绕“技术+项目+实操”展开 ，一页纸最佳，重点信息前置。

 1. 基础信息简洁明了

 姓名、电话、求职意向（明确：网络工程师/系统集成工程师/运维工程师）、意向城市，照片可选，无需多余装饰。

 2. 技能清单：分等级罗列，贴合岗位

 不要只写“精通网络技术”，精准描述能力，参考格式：

 
 精通：华为/华三交换机、路由器、防火墙配置，VRRP、链路聚合、堆叠部署，故障排查；

 熟练：企业网络巡检、拓扑梳理、802.1X准入认证、VPN部署；

 了解：虚拟化、云平台、等保基础。
同步标注所持证书，放在技能板块上方。

 
 3. 项目经验：STAR法则，突出实操

 这是简历核心，每一条项目经验写清 场景+工作+技术+成果 ，示例：

 
 项目名称：某园区网络改造项目
负责内容：现场设备上架、VLAN划分、全网组网调试，处理网络卡顿、端口异常等故障；
使用技术：OSPF、Eth-Trunk、防火墙策略；
项目成果：完成30+点位网络部署，项目顺利验收，网络运行稳定。

 
 应届生/无全职经验：将 实训项目、模拟器实验、自学案例 当作项目填写，如实说明即可。

 4. 避坑要点

 
 不夸大技能：面试会有实操提问、设备配置考核，夸大能力极易露馅；

 剔除无关内容：文职、兼职等和ICT无关的经历简写或删除；

 针对岗位改简历：投递集成商，突出项目交付、出差、现场调试经验；投递甲方运维，突出日常巡检、故障处理、桌面运维能力。

 
 五、第五步：面试全流程通关，攻克技术核心关卡

 ICT面试分为 初面（HR）+技术面（技术主管） ，部分企业增设 机试/实操考核 ，技术面是决定成败的关键。

 1. HR初面：侧重稳定性与沟通能力

 常规问题：自我介绍、为什么离职/求职、能否接受出差、加班、驻场。
应答思路：如实回答，集成商岗位明确表示 可接受短期出差、现场驻场 （该岗位核心要求）；政企运维强调稳定性，表达长期发展意愿。 

 2. 技术面试：分基础、项目、排障三大题型

 （1）基础理论题（必问）

 高频考点：OSI七层模型、VLAN作用、路由协议区别、VRRP与链路聚合原理、防火墙基础概念。不用死记硬背书面语， 结合实操理解作答 。

 （2）项目经验提问

 面试官会深挖简历上的项目：“你在项目中具体做了什么？遇到过什么问题？怎么解决的？”
应答技巧：按照“问题现象→排查思路→解决方案”作答，结合真实经历，条理清晰即可。

 （3）故障排查（重中之重，区分能力层级）

 这是ICT面试的核心，高频场景：SSH连接设备缓慢、网络不通、广播风暴、堆叠分裂、部分网段无法上网。
作答逻辑：遵循 从物理层到应用层逐层排查 的行业标准思路，先查线路、端口，再查配置、路由、策略。

 （4）实操/机试

 大中型集成商、厂商基本都会安排实操，现场使用模拟器或真机，完成基础配置、简单组网。
应对：面试前1-2天复盘常用命令、基础组网案例，熟练复制配置模板，保证命令书写无误。

 3. 反问环节（加分项）

 面试结尾可主动提问，体现求职诚意：

 
 岗位日常工作内容、对接的项目类型；

 团队技术栈、新人培训体系；

 岗位晋升路径。

 
 六、第六步：谈薪与复盘，稳步落地offer

 1. 薪资谈判：结合市场行情合理议价

 提前了解所在城市同岗位薪资范围：应届生/初级岗以行业均值为底线；1-3年经验可根据技术能力、项目经验上浮10%-20%。
薪资构成重点确认：基本工资、绩效、出差补助、社保公积金、加班制度，集成商务必问清 出差补贴、食宿安排 。

 2. 多轮求职复盘，持续优化

 投递简历后记录：投递岗位、面试时间、面试问题、未通过原因。

 
 简历石沉大海：优化技能与项目描述，匹配岗位要求；

 技术面试失利：针对性补薄弱知识点，强化故障排查、命令实操；

 面试沟通紧张：提前模拟自我介绍、高频问题应答，积累临场经验。

 
 七、不同人群专属求职建议

 
 
 应届生/转行新手 
优先选择中小型集成商、外包公司、政企驻场岗，放下薪资执念，以积累项目经验、练手实操为核心，证书+模拟器实验作为求职主力背书。

 
 1-3年在职跳槽 
主打“项目经验”，瞄准中高级工程师、专项技术岗，利用内推、行业社群获取优质岗位，优先选择能接触大型项目、主流设备的平台。

 
 资深技术人员/想转管理 
减少基础运维岗投递，主攻售前工程师、技术主管、项目经理，重点突出方案撰写、项目统筹、客户对接能力。

 
 个人建议总结

 ICT行业求职， 技术是根基，定位是方向，渠道是捷径，简历和面试是临门一脚 。这个行业不唯学历、不唯口才，扎实的实操能力永远是核心竞争力。先找准自身定位，打磨技术与项目案例，善用行业垂直渠道与内推，再针对性优化简历、备战面试，就能大幅提升求职效率，快速匹配到适合自己的岗位。入行后持续深耕技术、积累项目，职业发展也会越走越宽。

 2. 网络故障的排查流程，以及如果QQ，微信能用但是打不开网页是哪里除了问题？ 

 1. ping 127.0.0.1，排查本机 TCP/IP 协议是否正常；
 2. ping 本机IP 排查网卡或网卡驱动是否正常；
 3. ping 同网段IP，排查交换机端口工作模式、vlan划分
 4. ping 通网段网关；排查主机到本地网络是否正常；
 5. ping 公网IP 排查路由是否正常；
 6. ping 公网某个域名 ，排查DNS服务配置是否正常
 
 QQ，微信能用但是打不开网页一般是DNS出了问题（比如在win，mac上的话，把系统自动生成的关于DNS生成文件删除一般就能解决）

 3，XSS漏洞和防范 

 人们经常将跨站脚本攻击（ Cross Site Scripting ）缩写为 CSS ，但这会与层叠样式表（ Cascading Style Sheets ， CSS ）的缩写混淆。因此，有人将跨站脚本攻击缩写为 XSS 。

跨站脚本攻击（ XSS ），是最普遍的 Web 应用安全漏洞。这类漏洞能够使得攻击者嵌入恶意脚本代码到正常用户会访问到的页面中，当正常用户访问该页面时，则可导致嵌入的恶意脚本代码的执行，从而达到恶意攻击用户的目的。

攻击者可以使用户在浏览器中执行其预定义的恶意脚本，其导致的危害可想而知，如劫持用户会话，插入恶意内容、重定向用户、使用恶意软件劫持用户浏览器、繁殖 [XSS蠕虫] ( https : //baike.baidu.com/item/XSS蠕虫/22777013)，甚至破坏网站、修改路由器配置信息等。 
 
 原理

 HTML 是一种超文本标记语言，通过将一些字符特殊地对待来区别文本和标记，例如，小于符号（ 与 之间的字符是页面的标题等等。当**动态页面**中插入的内容含有这些特殊字符（如 攻击者事先制作好攻击链接, 需要欺骗用户自己去点击链接才能触发XSS代码
 **存储型** XSS： 代码是存储在服务器中的，每当有用户访问该页面的时候都会触发代码执行。
 **DOM** 型XSS：通过修改页面的DOM节点形成的XSS，称之为DOMBasedXSS。

防范方法：过滤关键词和符号，对<>等进行转义，对重要cookei实行httponly等

 3、如何看待web前端安全，简述前端安全存在的风险有哪些，并用具体例子说明 

 解：我理解的web前端指的是客户端，也可以说是浏览器端。前端安全是一个很大的分支，如cookie安全，flash安全，dom渲染（dom型xss），字符集，跨站（csrf），钓鱼，信任等。Cookie安全方面，如果过分相信cookie且没有进行其他处理，那么可能造成csrf。字符集可能造成宽字节问题，如逃逸特殊符号

信任方面，实际上安全的攻防都是以信任为基础，如同源策略，实际利用中有： 1 . A 站防护很高，但同服务器同文件系统下的 B 站因安全问题被入侵，那么如果文件权限没有配置好，则 A 站也会被成功拿下，因 A 与 B 过分信任，没有做好分离。 2 . A 网站嵌入和 B 网站的javascript脚本，方式是以 标签引用，实际也等于建立了信任关系，那么如果此脚本被黑客动了手脚，那么 A 站也会被危及。另外，我认为社会工程学也应说一下，通过google hacking，SNS垂直搜索（人人网，Facebook等）和其他各种信息收集方式，这使得攻防的过程变成了一个斗智斗勇的过程，在成功的入侵中，社工可能扮演着非常重要的角色。

 7、问：了解http协议吗？有什么字段？ 

 HTTP协议是Hyper Text Transfer Protocol（超文本传输协议）HTTP是一个基于TCP/IP通信协议来传递数据（ HTML 文件, 图片文件, 查询结果等）。
 
 主要特点 

 1 、简单快速：客户向服务器请求服务时，只需传送请求方法和路径。请求方法常用的有**GET、HEAD、POST**。每种方法规定了客户与服务器联系的类型不同。由于HTTP协议简单，使得HTTP服务器的程序规模小，因而通信速度很快。

 2 、灵活：HTTP允许传输任意类型的数据对象。正在传输的类型由 Content -Type加以标记。

 3 .无连接：无连接的含义是限制每次连接只处理一个请求。服务器处理完客户的请求，并收到客户的应答后，即断开连接。采用这种方式可以节省传输时间。

 4 .无状态：HTTP协议是无状态协议。无状态是指协议对于事务处理没有记忆能力。缺少状态意味着如果后续处理需要前面的信息，则它必须重传，这样可能导致每次连接传送的数据量增大。另一方面，在服务器不需要先前信息时它的应答就较快。
